# Задание для dot: видео для Медиатеки — учебный материал из готового ASR

_Обновлено: 2026-11-27._

## Где эта инструкция и как узнать, что она изменилась

- Актуальный текст всегда здесь: https://linguistpro.kolosei.com/api/media-queue/dot-task.md (без ключа).
- В ответе `GET /api/media-queue/editor/jobs/next` есть поле `task`: `task.version`, `task.updated`, `task.url`. Запомни `task.version`. Если в очередном ответе он другой — **сначала перечитай инструкцию**, потом работай.

## Что это

Владелец LinguistPro ставит видео YouTube в очередь Медиатеки. Его домашний ПК сам скачивает звук и делает распознавание речи (ASR, ivrit.ai large-v3, оконный режим). Тебе достаётся **готовый ASR-ZIP** — тот же, что владелец раньше присылал тебе вручную. Ты собираешь из него учебный архив для Медиатеки **точно так же, как уже делал для Медиатеки**, и загружаешь его. Сервер сам публикует материал в подборку «Видео дня». Видео остаётся на YouTube; на сервер попадает только учебный материал.

Ключ — **твой обычный ключ редактора** (тот же, что для Новостей): `Authorization: Bearer lpne_…`.

## Цикл работы

1. `GET /api/media-queue/editor/jobs/next` — следующее видео. Если `job: null` — работы нет.
   - `job.job_id`, `job.url` (ссылка YouTube), `job.title`, `job.channel_title`, `job.duration_sec`.
   - `job.asr_zip` — адрес ASR-ZIP, `job.archive` — куда загружать результат.
   - `job.retry: true` — ты уже брал это видео больше 4 часов назад и не загрузил результат: возьми заново и доделай.
2. `GET <job.asr_zip>` под своим ключом — скачать ASR-ZIP. С этого момента видео 4 часа закреплено за тобой.
   Внутри: `transcript.txt/.srt/.vtt`, `raw/segments.json(l)`, `raw/windows.jsonl` (тайминг по окнам), `review.json` (пропуски VAD, перекрытия), `qc.json` (технические флаги), `manifest.json`.
3. Собери учебный архив (ниже) и загрузи: `POST <job.archive>` с телом — ZIP-файлом, `Content-Type: application/zip`, до 512 МБ.
   - Ответ `{ ok: true, job, material }` — материал опубликован в «Видео дня». Готово.
   - Ответ `{ ok: false, error: "<код>" }` — архив не прошёл проверку. Исправь по коду и загрузи снова (видео остаётся за тобой). Тот же архив повторно не создаёт второй материал.
4. Если сделать материал нельзя (речь не на иврите, ASR непригоден, видео — музыка без речи): `POST /api/media-queue/editor/jobs/<job_id>/fail` с JSON `{ "reason": "коротко, почему" }`. Владелец увидит причину.

## Учебный архив

Как в твоих архивах для Медиатеки (образец — `Kan-Docu-Children-of-Hebron-context.learning.zip`):

- строгий LPLP v2 с `content_root_sha256` и хэшами всех файлов;
- в строках таблицы: `he_plain`, `he_niqqud`, `translit`, `translit_ru`, `ru` (точный перевод строки, близко к тексту), `en` — желательно; у каждого поля `field_meta`;
- слой «в контексте (ИИ)» `learning/word-gloss-ai.json` в схеме `word-gloss-ai-layer-v1`;
- `quality/report.json` с честными ограничениями (тихая речь, смешанный иврит/арабский, места, где ASR сомнителен);
- **источник воспроизведения — ссылка YouTube из `job.url`** (сервер сверяет: архив другого видео не примет — `MATERIAL_SOURCE_MISMATCH`);
- **тайминг строк — из ASR-ZIP** (`raw/segments.json` / `windows.jsonl`); не сдвигай и не угадывай время; пропуски VAD из `review.json` не заполняй выдуманным текстом;
- текст исправляй по смыслу (ошибки распознавания), но не пересказывай.

## Коды ошибок загрузки

- `MATERIAL_SOURCE_MISMATCH` — в архиве ссылка не на это видео.
- `MATERIAL_ARCHIVE_INVALID`, `PACKAGE_…`, `ZIP_…`, `MANIFEST_…`, `CANONICAL_…`, `GRAPH_…` — архив не прошёл проверку; код называет дефект.
- `MEDIA_JOB_NOT_TAKEN` — видео не за тобой (не скачан ASR-ZIP или закрепление истекло и его взял другой): начни с `next`.
- `MEDIA_JOB_STATE` — материал уже опубликован; другой архив для него не принимается.
- `MEDIA_PUBLISH_RETRY` (HTTP 409) — сбой на стороне сервера, **архив в порядке**. Ничего не меняй: пришли **тот же самый архив** ещё раз через несколько минут. Повтор доведёт публикацию до конца и не создаст второй материал.
- `MEDIA_DAILY_DRAFT_BUSY` (HTTP 409) — у владельца в корпусе «Видео дня» незавершённые импорты. Подожди, пока он их разберёт, и повтори позже; архив не меняй.
