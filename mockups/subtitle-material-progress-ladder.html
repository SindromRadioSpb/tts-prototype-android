Лестница этапов для «Материала из субтитров»

Три варианта того, что человек видит, пока компаньон и браузер собирают учебную таблицу. Данные взяты из реального прогона Ushpizin.mkv 27.09: сейчас там 7 минут висит одна строка «Готовим материал…».

Вариант A

Вертикальная лестница

рекомендую
Все этапы видны сразу. Пройденные этапы помечены ✓ и временем, у текущего есть полоса, счётчик и «осталось ≈». Будущие этапы бледные, пропущенные (лёгкая копия выключена) зачёркнуты.
  • Плюс: честно, видно, где именно ждём и что уже сохранено.
  • Минус: занимает ~8 строк высоты.
Вариант B

Сегментная полоса

Одна полоса, поделённая на этапы по их реальному весу. Под ней строка «сейчас · осталось». Полный список спрятан в «Подробнее».
  • Плюс: компактно, общий ход виден одним взглядом.
  • Минус: названия этапов скрыты, при ошибке нужно раскрывать список.
Вариант C

Цепочка + крупный счётчик

Этапы идут строкой-чипами, под ними крупная карточка текущего этапа с большим числом.
  • Плюс: самое заметное «живое» число.
  • Минус: на узком экране чипы уезжают вбок, прокрутка прячет конец цепочки.

Вариант A на телефоне (380 px)

Пройденные этапы сворачиваются в одну строку, текущий и следующие остаются видны. Слева огласовка, справа ошибка.

Что общее для всех вариантов

  • Этапы из реального кода: передача файла (новый счётчик байт) → чтение дорожек → подготовка видео (job.progress компаньона) → лёгкая копия (если включена) → сохранение в браузере (байты потока) → сборка таблицы → огласовка (реплики, onProgress уже есть в enrich) → открытие таблицы.
  • «Осталось ≈» показывается только когда скорость устоялась (≥10 с данных). Раньше пишется «считаем…», чтобы не врать.
  • Ошибка остаётся на своём этапе, всё пройденное помечено как сохранённое. «Повторить» продолжает с упавшего этапа: код уже держит готовое видео (preparedJob, stored), заново готовить не придётся. Текст по коду ошибки человеческий: «перезапустите компаньон» вместо LOCAL_ASR_HTTP_503.
  • Экранные читалки: aria-live="polite" объявляет смену этапа, но не каждый тик счётчика.
  • Строки ru/en/he, RTL-зеркалирование для иврита, тёмная тема.

Не входит в эту работу, а записано отдельно (O-029): не передавать файл повторно, если у компаньона уже есть готовая копия, и медленная локальная передача 4–6 МБ/с.
