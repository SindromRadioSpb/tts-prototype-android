Загрузка на iPhone

Chrome остаётся вашим браузером. Проверим, может ли бесплатный помощник скачать файл на самом телефоне, без нашего медиа-сервера.

Это проверка, не готовая функция «По ссылке». Сейчас нужны a-Shell mini и несколько команд. Сам файл пока не передаётся автоматически в LinguistPro. Основной импорт не изменён.

  1. Установите помощник

    Установите бесплатное приложение a-Shell mini из App Store. Отдельная подписка, компьютер и аккаунт YouTube для этого теста не нужны.

    Открыть App Store

    Нужны обычный интернет и свободное место на iPhone. Медиа и промежуточные файлы занимают дополнительную память.

  2. Сохраните проверочный комплект

    Скачайте ZIP, сохраните в «Файлы» и нажмите на архив, чтобы распаковать. Откройте a-Shell mini и выполните:

    Скачать комплект · 24 КБ
    pickFolder

    Выберите распакованную папку LinguistPro-iPhone-probe. Подтвердите доступ только к ней. Команда ls должна показать run.py. Если папка не сменилась — остановитесь и сообщите версию a-Shell mini.

    Установите три закреплённые зависимости в эту папку:

    python3 run.py --install-runtime

    Ожидаемый ответ: "runtime_install": "COMPLETE". Это ещё не проверка скачивания. Повторная установка не перезаписывает существующую папку.

  3. Проверьте возможности телефона

    python3 run.py --preflight

    Продолжайте только после NATIVE_PREFLIGHT_PASS. Проверяются Apple WebKit и обработка короткого аудио на устройстве.

    При ошибке или зависании сохраните код либо снимок экрана и остановитесь. Не меняйте VPN, cookies, пакеты или настройки телефона наугад.

  4. Скачайте один разрешённый ролик

    Вставьте публичную ссылку YouTube и укажите основание для сохранения. Открытый доступ сам по себе не означает разрешения.

    Выберите основание — появятся команды.

    Сначала — только аудио

    Затем — видео со звуком, 360p

    Вставляйте и запускайте команды по одной в a-Shell mini. Оставайтесь в помощнике до завершения; не блокируйте экран. Возобновление после выгрузки приложения пока не проверено.

    Ожидаемый результат: LOCAL_BYTES_VERIFIED. Файл verified.m4a или verified.mp4 и report.json появятся в results/<job_id> внутри выбранной папки.

    Не более 3 часов и 300 MiB итогового файла. Не запускайте два скачивания одновременно. Расшифровка не запускается: у облачной ASR отдельная стоимость.

  5. Вернитесь в Chrome и откройте файл

    Из отчёта скопируйте значение job_id без кавычек — 32 символа.

    Введите job_id — появится команда возврата.

    Выполните её в a-Shell mini. Должен открыться Chrome с LinguistPro; возможна новая вкладка. Ответ REQUESTED означает только отправленный запрос, не передачу файла.

    В LinguistPro: «Добавить материал» → «С устройства» → выберите verified.* через «Файлы». Проверьте начало, середину и конец, звук и видео. Пока не запускайте облачную расшифровку.

    Открыть LinguistPro

Что прислать по результатам

Модель iPhone, версии iOS, Chrome и a-Shell mini; файл report.json; получилось ли вернуться в Chrome, выбрать файл и воспроизвести его. При ошибке — этап и видимый код.

Медиа присылать не нужно. Отчёт содержит ID ролика — просмотрите его перед отправкой. Тестовые файлы остаются на телефоне; удаляйте только выбранную тестовую папку после проверки сохранности медиа.
