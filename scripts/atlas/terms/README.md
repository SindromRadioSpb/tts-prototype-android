# Дополнения словаря атласа

`a97002-additions.jsonl` — термины, которых не хватило при учёбе (план P5 §G2). Одна строка — один термин в формате
словаря dots плюс `id` и `sections` (`[]` — каждый раздел, где термин встречается):

```json
{"id":"a97002:term:u-1a2b3c4d","lemma_he":"כוח היקפי","niqqud":"כֹּחַ הֶיקֵּפִי","translit":"","translit_ru":"","senses":[{"sense":"main","ru":"окружная сила","context":"s09-belt"}],"sections":["s09-belt"]}
```

Новое значение термина, который в атласе уже есть: `{"id":"a97002:term:belt","add_senses":[{"sense":"strap","ru":"лента"}],"sections":["s09-belt"]}`.

Строки «Мои термины → Выгрузить файлом» в «Тренировать» уже в этом формате: нужные строки переносятся сюда как есть,
ключ повторения у ученика при этом не меняется.

Применение после каждой пересборки данных ридера (`build_reader_data.py`):

```
node scripts/atlas/apply-term-additions.cjs --data=<data/atlas/a97002> --check   # отчёт без записи
node scripts/atlas/apply-term-additions.cjs --data=<data/atlas/a97002>           # записать разделы
```

Строка, которая не проходит проверку (нет иврита, огласовка не совпадает с леммой, нет перевода, такой термин или
`id` уже есть, значение уже есть, нет ни одного места в указанных разделах), отклоняется с причиной и ничего не меняет;
код выхода 2. Изменённые разделы затем выкладываются на том, как обычные данные ридера. Поиск по книге видит новые
термины только после пересборки `search.json`.
