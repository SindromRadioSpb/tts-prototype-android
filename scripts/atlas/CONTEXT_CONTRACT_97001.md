# Атлас 97001: подготовленный контекст, контракт v2

Окончательный AI-контент готовится отдельно после стабилизации текста. Этот экспорт не содержит ответов модели и не означает научную приёмку.

## Стабильный источник

`node scripts/atlas/export-context.cjs --data=data/atlas/a97001 --out=.tmp/atlas97001-context-final`

Архив содержит `manifest.json`, `rows/<section>.jsonl` и этот контракт. Manifest фиксирует commit экспортёра, чистоту отслеживаемых файлов, SHA256 каждого JSON раздела, SHA256 JSONL, source_revision, числа строк/слов по типам и явные исключения. Для генерации используйте экспорт окончательного commit и сверенные production JSON. Изменение текста, перевода, порядка, ограничений или редакторских пояснений требует нового экспорта.

Строки включают исходные блоки, ячейки таблиц, заголовки таблиц и подписи рисунков, которые можно открыть в карточке reader. Старые блоки сохраняют свой order_index. Новые объекты добавляются после них. ID: `<table-id>:cell:<row>:<col>`, `<table-id>:title`, `<figure-id>:caption`. Индексы ячейки — нулевые. Пунктуационные строки без Hebrew-токенов не экспортируются; локализованные групповые значки отмечены в exclusions. Несопоставленная Hebrew-подпись области рисунка останавливает экспорт и требует явного адаптера.

Каждая строка: `row_id`, совместимый `block_id`, `order_index`, `key`, `row_type`, `page`, `he`, `he_niqqud`, `ru`, `words`, `source_context`. `words` получены штатным Hebrew-токенизатором, а не разделением по пробелам. `source_context` содержит страницу, объект/поле, scan, ограничения, coverage_notice и редакторские scientific_notes. Скан — адрес доказательства, а не доказательство прочтения его пикселей. Перед содержательной сертификацией нужно открыть соответствующий исходник. Не восстанавливать нечитаемые числа из общих знаний. Сомнительный перевод RU также не является независимым доказательством.

## Ответ: `<section>.json`

`source_context.reviewed_terms` передаёт только явно привязанные к этому объекту термины с их выбранным смыслом и определением. Это редакторская подсказка, которую следует проверить в контексте; состав словаря и уточнения также участвуют в `source_revision`.

```json
{
  "schema": "word-gloss-ai-layer-v1",
  "contract": "atlas-context-v2",
  "atlas": "a97001",
  "section": "<section>",
  "source_revision": "<точно из manifest раздела>",
  "coverage_mode": "complete",
  "provenance": {
    "kind": "prepared_ai",
    "producer": "<исполнитель и модель>",
    "review_scope": "<что проверено и что осталось неопределённым>"
  },
  "rows": [{
    "row_id": "<из экспорта>",
    "order_index": 0,
    "key": "<из экспорта>",
    "model": "<реальная модель>",
    "glosses": [{"gloss": "<русский смысл слова здесь>"}],
    "mwe": []
  }]
}
```

Нельзя менять ID, key или order_index. Дубли одной исходной строки запрещены; одинаковый key у разных исходных объектов допустим. Полный слой обязан отвечать на каждую экспортированную строку раздела ровно один раз. Количество glosses строго равно words.length; порядок неизменен. Каждый gloss — непустая строка до 120 символов без Hebrew. `wrong_hint: true` отмечает ошибочную общую словарную подсказку. Не выдавайте AI-ответ за ручную пользовательскую правку (`manual` запрещён). Для неизвестного слова: `{"gloss":"?","uncertain":true,"reason":"причина"}`. Это явная неопределённость, не догадка. Другие неопределённые ответы также отмечайте uncertain/reason. MWE использует включительные индексы `from`, `to`, в пределах words, и непустой русский gloss. Пустой список mwe допустим; пустой gloss MWE запрещён.

Частичный слой имеет `coverage_mode: "partial"` и принимается только с `--allow-partial`. Это не сертификат полного покрытия. Выбор отдельных разделов через `--sections=...` также не является приёмкой всей книги. Reader показывает происхождение и частичный статус только для покрытой строки. Редакторские ограничения выводятся отдельно от AI и остаются видимыми без AI-слоя.

## Проверка и импорт

Граница покрытия: огласованный вариант блока использует те же позиции слов и не создаёт вторую строку. Служебные названия разделов/оглавления интерфейса, русские переводы с Hebrew-цитатами и редакторское двуязычное предупреждение не являются отдельными предложениями источника. Заголовки книги на страницах входят через обычные блоки; научные пояснения и предупреждения передаются как доказательства в source_context. Для текущего атласа Hebrew-регионы рисунков и иные неучтённые исходные подписи отсутствуют. Это не обещание автоматического покрытия неизвестных будущих типов данных.

```text
node scripts/atlas/import-context.cjs --data=data/atlas/a97001 --answers=<dir-or-zip> --dry-run
node scripts/atlas/import-context.cjs --data=data/atlas/a97001 --answers=<dir-or-zip>
```

По умолчанию необходимы все разделы книги. Любая ошибка проверки отменяет запись всех проверяемых слоёв. Существующий локальный файл требует явного `--replace`; предварительно сохраните его копию. Не передавайте в answers посторонние JSON. Для диагностики используйте `--sections=<id>` и при необходимости явный `--allow-partial`. Эти команды не публикуют данные: production требует отдельной процедуры с резервной копией и проверкой SHA.

97002 сохраняет прежний контракт и загрузку. Идентификаторы старых карточек/SRS не меняются. Импорт не записывает browser IndexedDB/OPFS; ручные коррекции штатного WordGlossAI сохраняют приоритет. Технический accepted подтверждает структуру и точную версию, а не научную истинность.

## Защиты повторной приёмки 3.11.865

В подготовленном слое `manual` не может иметь истинное или не булево значение: строки `"true"`/`"false"` и числа отклоняются и для слов, и для MWE. Ручной статус в кэше определяется только `manual === true`; настоящие пользовательские исправления сохраняются.

Для `uncertain: true` обязательна непустая строка `reason`, в том числе у MWE. Причина выражения показывается в карточке каждого слова его диапазона и не вытесняет отдельную причину слова. ASCII-only gloss может быть структурно допустимым (например, обозначение); это не удостоверяет русский язык, перевод или научную правильность. Нужна отдельная смысловая приёмка.

Экспорт, импорт и загрузчик 97001 проверяют выравнивание `he` с `he_niqqud` до проверки ответов. Разные количества токенов и замена слова другим отклоняются. Для 23 строк раннего огласованного пилота сохранены 49 явно перечисленных пар полного/дефективного написания; универсального удаления букв ו/י нет. Новое расхождение требует предметной сверки и явного дополнения разрешённых пар. Проверка выравнивания не сертифицирует правильность всех огласовок. Legacy-экспорт 97002 не пропускается через этот новый gate.

Финальный AI-контент не создавался и не публиковался. Экспорт 3.11.865 устарел для следующего прохода: использовать только новый manifest и SHA окончательного commit после исправлений и следующей независимой приёмки.
