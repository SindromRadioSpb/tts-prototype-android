# Задание: ядро терминов атласа נוסחאון 97002 (вся книга)

Словарь собирается **до** массового перевода, чтобы одно значение термина переводилось одинаково во всех
разделах, кто бы и когда их ни переводил. Пилот принят в работу; разделы для перевода будут выдаваться
после утренней приёмки пилота владельцем.

## Что в архиве

| Файл | Что это |
|---|---|
| `term-candidates.jsonl` | {CANDIDATE_COUNT} кандидатов: заголовки, описания символов из таблиц обозначений, названия рисунков и частые словосочетания (≥ 4 раз) — с частотой, страницами, разделами и контекстом. Это сырьё с шумом: отбирайте. |
| `book-text.jsonl` | сырой ивритский текст всей книги по страницам (как извлечён из PDF: слитые слова и зеркальные скобки возможны). По нему проверяются цитаты. |
| `sections.json` | карта разделов книги (42 раздела по оглавлению) |
| `tools/atlas_validate.py`, `schemas/` | проверка словаря |
| `README.ru.md` | общий контракт (раздел 7 — термины) |

## Что сдать

Один файл **`a97002-terms-v1.jsonl`**: первая строка — заголовок

```json
{"type":"header","schema":"linguistpro.atlas-terms-pack.1.0.0","atlas_id":"a97002",
 "candidates_sha256":"{CANDIDATES_SHA256}","producer":"dots","produced_at":"<время UTC>"}
```

затем объекты `term` и в конце `report`. Термин — как в пилоте, плюс обязательные цитаты:

```json
{"type":"term","id":"a97002:term:galgal-mania","lemma_he":"גלגל מניע","niqqud":"גַּלְגַּל מֵנִיעַ",
 "translit":"galgal meni'a","translit_ru":"гальгаль мениа",
 "senses":[{"sense":"driving-pulley","ru":"ведущий шкив","context":"ременная передача"},
           {"sense":"driving-gear","ru":"ведущее зубчатое колесо","context":"зубчатые передачи"}],
 "occurrences":[{"page":197,"he":"בגלגל מניע"},{"page":236,"he":"גלגל מניע"}],
 "candidates":["c0123"]}
```

Правила:

1. **Объём** — около 300–500 терминов на всю книгу: инженерные понятия, величины, детали, операции,
   нормативные сокращения (ת"י, מה"ט — с расшифровкой). Общие слова языка не включать.
2. **Одно значение — один перевод.** Разные значения одного ивритского слова — разные `sense`
   (с `context`: раздел или область). Перевод — по русской инженерной традиции (ГОСТ-терминология,
   где она есть).
3. **`occurrences`** — от 1 до 3 цитат **из `book-text.jsonl`** с номером страницы, лучше из разных
   разделов. Цитата — ивритский фрагмент как в книге (можно с огласовками); проверка ищет его буквы на
   этой странице. Термин без настоящей цитаты не принимается — так исключаются выдуманные термины.
4. **`candidates`** — ID кандидатов, из которых термин получен (если есть).
5. `niqqud` — лемма с огласовками; `translit` латиницей как в пилоте; `translit_ru` — желательно.
6. Порядок внутри файла — по разделам книги; приоритет полноты: допуски и посадки (s24–s30),
   детали машин (s02–s17), экономика (s40–s41), обработка резанием (s18–s23), остальное.
7. 10 терминов пилота можно взять за основу и дополнить цитатами.
8. В `report` — спорные переводы, синонимия, термины, которые вы сознательно не взяли.

## Перед сдачей

```
python tools/atlas_validate.py --terms a97002-terms-v1.jsonl --book-text book-text.jsonl --candidates term-candidates.jsonl
```

Должно быть «ПРОВЕРКА ПРОЙДЕНА». Загрузите файл в папку обмена Google Drive (ту же, куда сдавали пилот),
ответ в чате — итоговая строка проверки, число терминов и смыслов, главное из `report`.
Статусы владельца не ставить; словарь утверждает владелец.
