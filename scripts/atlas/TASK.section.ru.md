# Задание: раздел {SECTION_ID} — {TITLE_RU} ({TITLE_HE}), стр. {FIRST}–{LAST}

Формат и правила — как в пилоте (`README.ru.md`, эталон `reference/`). Отличия раздела:

1. **Общий словарь книги** — `terms/a97002-terms-v1.jsonl` (ваш, 396 терминов). Блоки, символы и области
   ссылаются на его смыслы (`a97002:term:<slug>#<sense>`); термины заново **не определять**. Новый термин,
   которого нет в словаре, можно добавить объектом `term` с `occurrences` — и перечислить его в `report`.
2. **Пакет** — один файл **`a97002-content-{SECTION_ID}-v1.jsonl`**, заголовок:

```json
{"type":"header","schema":"linguistpro.atlas-content-pack.1.0.0","atlas_id":"a97002",
 "source_pack_sha256":"{SOURCE_PACK_SHA256}","producer":"dots","produced_at":"<время UTC>",
 "pages":[{PAGES}]}
```

3. **Покрытие** — все блоки текста всех страниц раздела; формулы (`display_latex` и `compute` или
   причина); символы таблиц обозначений (`formula_id` или `symbols` формулы — где связь видна); рисунки и
   подписи на них; растровые таблицы; примеры (шаги с подстановками как напечатаны); опечатки — из вашего
   списка кандидатов `a97002-errata-candidates-v1.jsonl` по страницам раздела плюс новые; `report`.
4. Страницы пилота (7, 197, 282, 284, 287–289, 485) переводятся заново в составе своего раздела:
   ID блоков могли измениться после доработки экстрактора. Текст пилота можно переиспользовать.
5. Решения по спорному принимайте сами и записывайте в `report`: владелец вычитает позже и поправит.

## Проверка перед сдачей

```
python tools/atlas_validate.py --source source-pack --content a97002-content-{SECTION_ID}-v1.jsonl --terms-core terms/a97002-terms-v1.jsonl
```

Должно быть «ПРОВЕРКА ПРОЙДЕНА». Файл — в корень папки обмена; в чате — итоговая строка проверки и
главное из `report`, затем сразу следующий раздел по списку очереди.
