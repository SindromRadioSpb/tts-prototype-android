# Урок курса иврита LinguistPro: задание для dots

В архиве один урок курса иврита для русскоязычных начинающих. Есть две задачи, они независимы.

## Задача 1. Слепая проверка урока (по желанию)

1. Прочитайте `lesson.ru-he.md` — это весь урок: сцена с ветками, учебный текст, задания с ответами, грамматика.
2. Ответьте на вопросы `review/form.ru.md` в файле `review/answers.md`, по номерам пунктов.
3. Нужен честный взгляд со стороны: естественный ли иврит, верны ли огласовки и род, понятны ли задания, учит ли урок тому, что обещает его цель.
4. Не правьте `lesson.json` и `lesson.ru-he.md`. Замечания пишите в ответах, с номером реплики или задания.

## Задача 2. Картинки и анимация

Места под медиа перечислены в `media/pack.json`, у каждого есть:

- `purpose` — зачем картинка в уроке. Чаще всего она несёт смысл задания: ученик понимает заказ по картинке, без перевода. Неточная картинка ломает задание.
- `brief` — что нарисовать.
- `alt` — подпись для экранного диктора.
- `aspect` — пропорции.
- `context` — строка урока рядом с местом.

Стиль — `media/style.ru.md`. Герои — `media/characters.png`, если файл есть; держите их одинаковыми во всех картинках. Мои версии мест лежат в `media/examples/` как ориентир по смыслу и стилю; можно сделать лучше.

### Запреты

- **Никакого текста на иврите внутри картинки**, и вообще никаких надписей: вывески, ценники, меню, логотипы без букв. Весь текст урока живёт на экране, а не в картинке.
- **Никаких чужих персонажей**: Человек-паук и другие герои Marvel, Дина и Давид из учебников Лерера, герои мультфильмов и игр, реальные известные люди.
- Никаких SVG, GIF, HTML, JS, Lottie. Только `webp`, `png` или `jpg`.

### Лимиты

- Картинка — не больше 400 КБ, длинная сторона не больше 1600 px.
- Анимация (`kind: "sequence"`) — 2–4 неподвижных кадра, каждый по тем же лимитам. Кадры сменяются в уроке сами, один раз, и останавливаются на последнем. Одно изменение смысла за раз, например чашка чая сменяется чашкой кофе.

### Как вернуть

Положите в `results/`:

- `<id>.webp` (или `.png`, `.jpg`) — для картинки;
- `<id>.1.webp`, `<id>.2.webp`, … — кадры анимации по порядку;
- `<id>.json` — для каждого места:

```json
{ "alt": { "ru": "Подпись к картинке" }, "containsText": false, "credits": { "ru": "Кто и чем сделал" }, "tool": "название инструмента", "prompt": "текст запроса" }
```

`containsText` должно быть `false`: вы подтверждаете, что на картинке нет надписей. Место, которое не получилось, просто пропустите.

Верните архив целиком. Приёмка проверяет каждый файл по содержимому, размеру и подписи; лист с вашими и моими версиями рядом увидит владелец курса и выберет по каждому месту.
