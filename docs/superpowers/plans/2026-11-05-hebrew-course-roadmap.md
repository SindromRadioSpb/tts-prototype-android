# Курс иврита: дорожная карта планов

Спека: `docs/superpowers/specs/2026-11-05-hebrew-course-corpus-design.md` (утверждена 2026-11-05).
Дизайн охватывает несколько независимых подсистем, поэтому реализация разбита на отдельные планы. Каждый
план даёт проверяемый результат сам по себе. Следующий план пишется, когда закрыт предыдущий и сверены
его точки подключения в живом коде (пункты [проверить] спеки).

| № | План | Результат | Зависит от |
|---|---|---|---|
| P1 | **Ядро данных курса** — `2026-11-05-hebrew-course-p1-core.md` | формат урока v1, пары огласовок, валидатор, проверки графа, проверяющий модуль с исправлениями H1, H3, H4, M1, M2 | — |
| P2 | Модель доказательств и прогресс | каналы, помощь, отпечаток новизны, перенос после перерыва, миграция прогресса при новой версии урока; локальное хранение | P1 |
| P3 | Урок в Зале | корпус `course:ulpan`, маршрут данных с тома, экран урока, задания (выбор, ввод, пары касанием, пропуск, сборка, сцена), ивритская клавиатура, микрокарта грамматики; телефон и ПК | P1, P2 |
| P4 | Звук | сборка аудио урока (WaveNet C/D, полная огласовка, метки слов), сверка локальным ASR, лист прослушивания, плеер со скоростью между повторами (H5) | P1, P3 |
| P5 | Сцены движком «Миров» | постановка сцены урока по `story.json`, свои герои, текстовая версия всегда | P3 |
| P6 | Конвейер dots | выгрузка архива урока с медиа-местами, приёмщик, импорт; урок работает без медиа | P1, P3 |
| P7 | Синхронизация и повторение | прогресс курса между устройствами; FSRS для слов, ситуационное возвращение | P2 + сверка синхронизации Зала |
| P8 | Содержание пилота | «Кафе» + учебный текст, цепочка «врач» ×3, слой качества §6, прохождение владельцем | P1–P4 (P5, P6 — по готовности) |

Правила для всех планов: документы — в main сразу после этапа с `[skip cd]`; код — выпусками с lockstep
версий (`CACHE_VERSION` + `APP_VERSION` + `?v=`) только когда меняются подключённые файлы `public/`; прод —
только по решению владельца; пилот на проде виден только роли owner.
