# Задание для Codex: выпуск P3 (курс в Зале, только для owner)

**Выполнять только после явного «выпускаем» владельца.**

1. `git fetch origin`. Если `origin/main` ушёл вперёд от базы `feat/course-room`, влить `origin/main` в `feat/course-room` и пересчитать lockstep на следующую версию после `origin/main` (`CACHE_VERSION`, `APP_VERSION`, footer, `?v=` изменённых файлов). Затем `npm test` целиком — зелёный.
2. Влить `feat/course-room` в `main` (fast-forward или merge-коммит), пуш в `main` **без** `[skip cd]` — это выпуск.
3. До пуша проверить свободное место на проде по `docs/architecture/AGENT_OPERATIONS_GUIDE.md` (порог для сборки там). Если места мало — остановиться и сообщить владельцу, не чистить самостоятельно сверх уже разрешённого (кэш сборки и старые образы).
4. Данные курса на томе: `node scripts/course/build-course-data.cjs tests/fixtures/course/mini <out>` и залить `<out>/ulpan/` в `<volume>/course/ulpan/` на проде так же, как данные атласа (R§2 разведки). Если запись на сервер требует прав владельца — подготовить скрипт для запуска владельцем через `!` и остановиться.
5. Проверка на проде после деплоя:
   - живая версия = новая;
   - `GET /data/course/ulpan/manifest.json` → 200;
   - под owner корпус «Курс иврита» виден, урок «Кафе» открывается, огласовки на месте;
   - без входа корпуса не видно;
   - в `review_log` новых записей нет.
6. Отчёт `docs/research/hebrew-course/2026-11-05-p3-release.md` в main с `[skip cd]`: версия, коммит, итоги проверок, что не проверено.
