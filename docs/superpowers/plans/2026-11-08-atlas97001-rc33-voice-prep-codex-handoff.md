## 3. Задача A — правки корпуса (новая ревизия RC3.3)

### A1. Таблица решений по каждой записи

`docs/research/engineering-atlas/2026-11-08-rc32-audit/dispositions.json` — по одной строке на каждую из 213 записей:
`finding_id`, `class`, `action` (`fix` / `hold` / `no_change`), `targets`, `voice_blocking` (bool), `reason`.

Классы:

- `V` — **влияет на чтение**: огласовка или транслитерация меняют звучание (שֶׁטַח вместо שְׁטַח «штах»,
  דֶּגֶם вместо דְּגַם «дгам», בְּדֶגֶם вместо בַּדֶּגֶם, מְטוֹסִים, זָוִית מָעוֹף, артикль перед חֳ и т. п.),
  а также пропущенные или лишние слова исходного текста. `voice_blocking = true`.
- `N` — нормативная огласовка без разницы в современном звучании (סֵמֶל вместо סֶמֶל, дагеш в מִדָּה…).
- `R` — перевод, смысловые подмены, заглушки в RU (стр. 157 «[מאסרים: …]», 162 «[מנימלי: …]», 169 «[נתוכת: …]»,
  стр. 186 «до 0.2%C», 123 определения усталости и химических свойств).
- `S` — структура и привязка к скану (bbox подписей/формул, таблица обозначений стр. 67, выделения полужирным, легенда стр. 197).
- `U` — интерфейс (п. A4).
- `L` — разбор слова в карточке (стр. 124: «образец» — существительное, מתיחה — «растяжение»).
- `T` — термины (стр. 154 «мягкость», flight-angle, fixed-pulley, canonical dimension…).

Ни одна подтверждённая запись не остаётся без решения. `hold` — только с причиной из аудита
(например, «первое слово спорное, реконструкцию не выдумывать» на стр. 170).

### A2. Файл правок с защитой

`scripts/atlas/corrections/a97001rc33.json`: каждая операция = `finding_id`, `target` (ID строки или вложенного
варианта), `field`, `expect` (текущее значение целиком), `value`. Сборщик — по образцу `build-terms-v2-edition.py`:
читает проверенный неизменяемый источник, применяет операции, пишет **новую** промежуточную папку, затем
`stage-edition.cjs` → новое пространство `atlas-editions/a97001/<revision>`.

- Если `expect` не совпал — сборка падает (никаких «примерно»).
- Правка поля огласовки исправляет согласованно `he_niqqud`, `translit`, `translit_ru` и вложенные варианты,
  а также карточку канонического термина, если запись её называет.
- После сборки — заново поисковый индекс, банк «Найди в книге», производные структуры (штатные сборщики).

### A3. Повторы той же ошибки

Аудит адресный: та же ошибочная форма может встречаться и там, куда он не смотрел.
Сделать `scripts/atlas/rc33-sweep.cjs`: для каждой исправленной формы в классе `V`/`N` найти по всему корпусу
такие же написания (тот же `he`, та же ошибочная огласовка). Вывод — список кандидатов с контекстом.
Применять автоматически только при совпадении и слова, и роли (то же сочетание, та же форма);
остальное — в отчёт как «кандидат, не применено». Ориентиры: `שְׁטַח` в единственном числе, `דְּגַם`,
`בַּדֶּגֶם` в сопряжённой цепочке, `מֻשָּׂגֵי`, `נָיָחַת`.

  статус `needs_review`.

  Каждая запись ссылается на `finding_id` или правило.

  диктору — полные формы через «אוֹ»: «כּוֹחַ נָטוּי אוֹ כּוֹחוֹת נְטוּיִים», «זָוִית אוֹ זָוִיּוֹת»; учебные поля не менять.
- **Не озвучивать** с причиной: строки с заглушками и редакторскими вставками в огласовке
  (например, «בְּמָקוֹר: … ; תִּקּוּן: …» на стр. 5 — диктору только исправленное значение либо исключить),
  строки из `unresolved_candidate` и `hold` класса `V`, повторы логотипов/колонтитулов, неразборчивые фрагменты.
- **Формулы** — через словарь; стр. 81/85 по D5. Сокращения и единицы читаются словами по словарю.

### B3. Ворота «готово к озвучке» (проверка в `inventory`)

1. Нет озвучиваемого текста с косой чертой между еврейскими буквами, с `[`…`]`-заглушками, с кириллицей/латиницей
   вне словаря, с «במקור/תיקון» (с огласовкой или без).
2. Каждая строка класса `V` с `action = fix` — озвучивается исправленной формой; с `hold` — исключена.
3. Все причины «не озвучено» перечислены и объяснены; `NO_NIQQUD` у читаемых блоков — 0 или каждый объяснён.
4. Оценка стоимости: число символов на всю книгу и по разделам (без сетевых вызовов).
