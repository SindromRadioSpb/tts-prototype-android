# Словарь терминов интерфейса LinguistPro

**Создан:** 2026-09-26, релиз R9 программы UI (`UI_RELEASE_PROGRAM_2026_09_25.md`; находки аудита P1-2, P1-3).
**Правило:** одна сущность — одно имя на всех поверхностях и во всех языках. Новая строка интерфейса с одним из этих понятий берёт имя отсюда. Если нужного понятия нет, сначала запись здесь, потом строка в `ru/en/he`.
