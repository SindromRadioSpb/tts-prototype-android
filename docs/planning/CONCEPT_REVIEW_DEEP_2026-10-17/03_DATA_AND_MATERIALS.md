## 6. Тесты для независимого измерения

| Тест | Что измеряет | Статус |
|---|---|---|
| STAMP 4S для иврита (Avant Assessment) | Чтение и аудирование (автоматическая проверка), письмо и говорение (обученные оценщики); с 13 лет | ФАКТ: существует для иврита; цена — ПРОВЕРИТЬ |
| Экзамены уровней ульпана | Внутренняя шкала ульпана | ПРОВЕРИТЬ форматы; разные ульпаны — разные шкалы (`docs/ULPAN_DIAGNOSTIC_QUIZ_v1.md`) |
| Тест «Яэль» (NITE) | Владение ивритом для поступления в вузы | ПРОВЕРИТЬ доступ для исследования |
| ACTFL OPI / AAPPL для иврита | Устное интервью / школьный тест | ПРОВЕРИТЬ наличие иврита |

ФАКТ: исследование Jiang, Rollinson, Plonsky, Gustafson, Pajak (2021, *Foreign Language Annals* 54(4)) измеряло результат Duolingo внешним тестом ACTFL у 225 взрослых. В аналогичной работе 2024 года (*CALICO Journal*) использовали STAMP 4S. Все авторы, кроме Plonsky, — сотрудники Duolingo. Это образец, как продукт доказывает результат, и одновременно пример конфликта интересов, которого нам надо избежать (см. 05).

Правильная стратегия — сначала доказать результат на концентрированном рынке, потом масштабироваться на диаспору.

## 8. Наши данные, которые ничего не доказывают

| Данные | Почему не доказательство |
|---|---|
| `review_log`, `learner_events`, `llm_usage_ledger` | Один пользователь — сам автор продукта. Нет контрольной группы, нет внешнего измерения |
| Калибровка i+1 «на первом реальном профиле» | Профиль автора: подогнать порог под одного человека — не калибровка |
| Сравнение морфологии с Dicta (`smoke:reader-morph:audit`) | Dicta — один из источников той же морфологии, а не независимый эталон. Июльский пакет это уже отмечал |
| Сложности заданий входного теста | Заданы экспертной оценкой ИИ, не оценены по ответам |
| «Owner-live verified» | Проверка удобства и отсутствия ошибок, а не обучения |
| Оценки, выставленные LLM | Модель, которая учит, не может быть экзаменатором (R17-B) |
