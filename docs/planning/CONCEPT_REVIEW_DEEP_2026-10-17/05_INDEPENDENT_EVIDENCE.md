# 05 — Независимые доказательства

**Статус:** исследование; все пороги — ПРЕДЛОЖЕНИЕ для фиксации в предрегистрации · **Дата:** 2026-10-17

## Что считается независимым

Доказательство независимо, если его производит не владелец, не ИИ-агент, который строил продукт, не модель, которая учит в продукте, и не наша телеметрия без контрольного условия. Пороги успеха и провала фиксируются **до** сбора данных: в предрегистрации на OSF и в этом документе после решения владельца.

**Не являются доказательством:** проверка владельцем на своём профиле, оценки LLM, отзывы друзей, рост активности без контроля, сравнение с Dicta, когда Dicta — источник тех же данных.

## Как читать расчёты выборки

Все расчёты — ВЫВОД по стандартным формулам: α = 0,05, двусторонний тест, мощность 0,8.
- Две независимые группы, эффект d = 0,5 → около 64 человек на группу. При d = 0,3 → около 176.
- С предтестом (ANCOVA), корреляция предтеста и посттеста r = 0,6 → выборка умножается на 1 − r² = 0,64. При d = 0,5 это около 41 на группу.
- Классы вместо отдельных учеников: эффект дизайна = 1 + (m − 1) × ICC. Для классов по 12 человек и ICC = 0,1 это 2,1. Значит, около 86 учеников на группу, то есть 7–8 классов в каждой.
- ВЫВОД: полноценное сравнение классов — задача второго года. В первый год работают схемы, где **ученик сам себе контроль**: слова или тексты случайно распределяются между условиями внутри одного ученика. Это даёт сотни наблюдений на человека и мощность при 20–40 учениках.

## Гипотезы и их проверка

### H1. Ульпан может работать с продуктом (выполнимость пилота)

| Параметр | Значение |
|---|---|
| Внешний измеритель | Записи ульпана о посещаемости; анкета учителя; агрегаты продукта как вспомогательные |
| Кто проводит | Учитель и директор ульпана; анализ — владелец, проверка — внешний статистик |
| Контроль | Не нужен: это проверка выполнимости, а не эффективности |
| Выборка | 1–2 класса, 20–40 учеников |
| Успех | Согласие на участие ≥ 70%; еженедельно активны на 4-й неделе ≥ 60%; полнота данных тестов ≥ 90%; время учителя ≤ 30 мин в неделю; учитель готов продолжать |
| Провал | Согласие < 50% или активность на 4-й неделе < 30% → эффективность не изучаем, сначала чиним продукт |
| Срок | 8 недель после старта |
| Цена | Время владельца; благодарность учителю — ПРЕДПОЛОЖЕНИЕ 2–4 тыс. ₪ |

### H2. Морфологическая тренировка улучшает запоминание слов (ученик сам себе контроль)

| Параметр | Значение |
|---|---|
| Суть | Для каждого ученика целевые слова случайно делятся на две половины: с тренировкой семьи корня (02, П9) и без неё. Через 7 и 30 дней — тест без подсказок |
| Внешний измеритель | Отдельный тест из банка заданий. Задания делает лингвист, не видевший условий. Проверка детерминированная (точное совпадение формы или выбор значения), не FSRS и не LLM |
| Кто проводит | Тест выдаётся в продукте, но банк и ключи заморожены и хранятся у независимого исследователя |
| Контроль | Слова того же ученика без тренировки; распределение уравновешено между учениками |
| Выборка | 20–40 учеников × 40 слов. Смешанная логистическая модель со случайными эффектами ученика и слова |
| Успех | Отношение шансов ≥ 1,3 на 7-й день, 95% интервал не включает 1 |
| Провал | Верхняя граница интервала < 1,15 → тренировка не даёт пользы, её место в продукте пересматривается |
| Срок | 6 недель |
| Цена | Банк заданий — 5 чел-дн плюс 1 день лингвиста |

Так же, по схеме «ученик сам себе контроль», проверяются угасание огласовки (02, П8) и беглое чтение (02, П4).

### H3. Ученики с LinguistPro учатся лучше, чем только в ульпане (эффективность)

| Параметр | Значение |
|---|---|
| Внешний измеритель | STAMP 4S для иврита: чтение и аудирование оцениваются автоматически Avant, письмо и говорение — их обученными оценщиками. Дополнительно — экзамен уровня ульпана |
| Кто проводит | Avant (тест), учителя ульпана (экзамен), внешний статистик (анализ) |
| Контроль | Классы того же ульпана и уровня без LinguistPro, либо поэтапное подключение классов (stepped wedge), чтобы каждый класс в итоге получил продукт |
| Выборка | Около 86 учеников на группу (см. выше) |
| Успех | d ≥ 0,3 по чтению, 95% интервал не включает 0 |
| Провал | Верхняя граница интервала < 0,2 → публично не утверждаем, что продукт ускоряет обучение |
| Срок | Год 2, один полный курс ульпана (около 5 месяцев) |
| Цена | STAMP — ПРОВЕРИТЬ цену за ученика; статистик — ПРЕДПОЛОЖЕНИЕ 5–10 тыс. ₪ |

ФАКТ: так Duolingo измеряла свой результат внешним тестом (Jiang et al., 2021; CALICO 2024). Отличие, которое делаем мы: анализ ведёт человек без доли в продукте, данные и код — на OSF.

### H4. За это платят

| Параметр | Значение |
|---|---|
| Внешний измеритель | Деньги и подписанные документы, а не ответы в опросах |
| Успех | Из первых 10–15 частных ульпанов, с которыми был разговор, ≥ 2 подписывают платный пилот или письмо о намерениях; среди внешних активных пользователей (n ≥ 30) тест Шона Эллиса даёт ≥ 40% «очень расстроюсь» |
| Провал | 0 из 15 ульпанов → сегмент выбран неверно, переходим к диаспоре или исследовательскому режиму |
| Срок | 90 дней |

### H5. Морфология и огласовка верны (качество данных)

| Параметр | Значение |
|---|---|
| Внешний измеритель | Независимый золотой набор: тестовая часть UD Hebrew плюс 500–1000 токенов современного текста, размеченных двумя лингвистами (согласие — каппа Коэна ≥ 0,8) |
| Контроль | Не нужен: сравнение с эталоном |
| Успех | Точность бейджа «точно» ≥ 99%, нижняя граница интервала Уилсона ≥ 98%. Огласовка: доля слов без ошибок — порог фиксируется после первого замера (ПРЕДПОЛОЖЕНИЕ: ≥ 97%) |
| Провал | Точность «точно» < 98% → бейдж снимается до исправления |
| Срок | 4 недели |
| Цена | Разметчики — ПРЕДПОЛОЖЕНИЕ 20–30 часов работы |

### H6. Перенос знания в новый контекст (июльская метрика)

Июльская метрика — доля учеников, которые через ≥ 24 часа без подсказки применили слово в новом контексте с независимой проверкой — остаётся верной. Её спецификация уже есть в `ai_agent_education_strategy_2026_07_11/18_CONFIRMED_CONTEXTUAL_TRANSFER_SPEC.md`. Её стоит сделать главной метрикой пилота, а не отдельной программой.

### H7. Ученики возвращаются

| Параметр | Значение |
|---|---|
| Внешний измеритель | Когортные кривые внешних учеников вне ульпана (с лендинга) |
| Успех | ≥ 30% активированных учеников активны на 4-й неделе (ПРЕДПОЛОЖЕНИЕ; уточнить после интервью). Для общей ориентации: DAU/MAU у Duolingo — 39,6% (10-K FY2025), но это другой продукт и масштаб |
| Провал | < 15% на 4-й неделе → самостоятельный сегмент не держится без учителя |

## Внешняя экспертиза и повторяемость

- **Рецензируемые публикации.** CALICO или EUROCALL — для результатов обучения. Семинар BEA при ACL — для NLP в образовании (морфология, огласовка, оценка). LREC — для ресурсов (золотой набор, корпус ошибок).
- **Повтор на второй площадке.** Второй ульпан или вуз повторяет H1–H2 по тому же протоколу.
- **Открытость.** Протокол, банк заданий (после завершения), обезличенные агрегаты и код анализа — на OSF.
- **Конфликт интересов.** Владелец указывается как автор продукта; анализ проводит внешний статистик.
