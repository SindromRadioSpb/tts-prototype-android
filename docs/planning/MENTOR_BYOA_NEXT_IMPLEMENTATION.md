## Сохраняемые решения

- BYOA: собственный агент/подписка каждого пользователя. Owner Hermes уже подключён
  через ChatGPT OAuth; не вводить API key или платный fallback.
- Windows прежде macOS/Linux. Пилотный установщик неподписанный; clean-machine
  установка Hermes и массовый onboarding ещё не приняты.
- Редактора иврита пока нет. Непроверенные семантические задания не меняют mastery.
- DB/исходники/оплаченные provider artifacts сохранять; owner probes read-only.
- Scoped commit/push и поэтапный production разрешены; каждый выпуск проверять
  по ancestry, served bytes, повторному health и фактическому image. Main push
  запускает deploy. Evidence-only commits можно оставлять на рабочей ветке.
- Открытые ограничения O-046/O-047/O-050/O-051 — в журнале наблюдений.

## Выбор модели

Пользователю предложен Sol как основной исполнитель последовательных срезов.
В текущей работе субагенты не использовались. Выбор модели в интерфейсе не меняет
этих контрактов и gates. Не запускать агентов без явного поручения и не обещать
экономию подписочного лимита по API-тарифу.
