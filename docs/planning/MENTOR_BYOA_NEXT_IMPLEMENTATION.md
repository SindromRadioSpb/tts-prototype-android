служебные tutor-хэши; локальные IndexedDB-копии остаются управляемыми на самом

проверено через Kapture на одном реальном материале: окно субтитров, пауза,
источник и позиция после закрытия.
3.11.697 не считается опубликованной версией до отдельного release evidence.

1. Спроектировать и реализовать общий жизненный цикл принятого объяснения:
   идентичность источника/версии, account binding, backup/export/import/delete.
   Прежде чем включать в общий backup, проверить существующий формат и не менять
   канонические заметки/слова/оценки через отдельный writer.
2. Связать объяснение с предложением практики: явное принятие, состояния
   proposed/accepted/completed/dismissed, отмена и идемпотентное продолжение.
   Не считать ответ модели независимой редакционной проверкой.
3. Добавлять MCP только после проверки scopes/consent/версионированного контракта.
   `get_agent_connection` содержит закрытый старый 15-scope enum; не расширять его
   молча. Новые tutor capabilities должны получить собственный контракт.
4. Проверить owner-video: фактический фрагмент, пауза, источник и позиция после
   закрытия наставника. Автоматические exact-caption fixtures не заменяют эту проверку.

## Сохраняемые решения

- BYOA: собственный агент/подписка каждого пользователя. Owner Hermes уже подключён
  через ChatGPT OAuth; не вводить API key или платный fallback.
- Windows прежде macOS/Linux. Пилотный установщик неподписанный; clean-machine
  установка Hermes и массовый onboarding ещё не приняты.
- Редактора иврита пока нет. Непроверенные семантические задания не меняют mastery.
- DB/исходники/оплаченные provider artifacts сохранять; owner probes read-only.
- Scoped commit/push и поэтапный production разрешены; каждый выпуск проверять
  по ancestry, served bytes, повторному health и фактическому image. Main push
  запускает deploy. Evidence-only commits можно оставлять на рабочей ветке.
- Открытые ограничения O-046/O-047/O-050/O-051 — в журнале наблюдений.

## Выбор модели

Пользователю предложен Sol как основной исполнитель последовательных срезов.
В текущей работе субагенты не использовались. Выбор модели в интерфейсе не меняет
этих контрактов и gates. Не запускать агентов без явного поручения и не обещать
экономию подписочного лимита по API-тарифу.
