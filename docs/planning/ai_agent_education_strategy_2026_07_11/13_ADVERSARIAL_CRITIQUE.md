## Refutation findings

| Claim attacked | Finding | Severity / adjudication |
|---|---|---|
| Multi-agent is necessary | live useful behavior is already deterministic; splitting modules adds tokens, permissions and partial failure without new information | BLOCKER: plain function/single control wins by default |
| AI is the moat | models/prompts/tools are purchasable; moat is Hebrew resolver/corpus/context/evidence | MAJOR: AI is replaceable leverage only when it uses consented longitudinal evidence |

| Integrated platform replaces five tools | it may instead contain five incomplete loops and obscure reading | MAJOR: maximum three bets, one dominant reading action |
| Cheap inference makes strategy viable | human review, support, security/ops and TTS dominate; WTP unknown | BLOCKER: fully loaded cost/CCT and contribution margin required |
| Explainability prevents automation bias | confident explanations may still shift correct user decisions to wrong ones | MAJOR: abstention/manual alternatives/undo and harm measures required |

## Cross-agent agreement

All eight lenses agree on deterministic truth/scheduling/grading, optional reversible AI, delayed independent transfer, manual/degraded mode, human semantic publishing approval and reading-led positioning. They agree speaking/writing certification, mental-state inference, generic chat and agent memory as truth are prohibited.

## Disagreement and resolution

Architecture/product lenses allow thin M-B after measured specialist advantage; adversarial lens would fund only S1. **ADJUDICATION:** S1 is the funded scenario; an M-B component can exist only as a preregistered experiment and is removed if it fails. Content lens supports extensive backstage candidates; governance/economics require human review and immutable release manifests, limiting claimed automation savings.

## Rejected ideas

`DO NOT BUILD`: generic free chat; learner-facing agent society; multi-agent consensus as fact verification; autonomous curriculum/content publishing; agent memory; mental-state inference; speaking/writing certification; teacher dashboard now; MCP/A2A/event bus for internal modules; premium-model-always; telemetry without a named decision; OS/AI-first marketing.

`RESEARCH ONLY`: adaptive scaffolding, next-text ranking, modality recommendation and specialist explanation, each shadow-first with deterministic control.

## Portfolio kill tests

Kill multi-agent if quality gain <5pp, cost >1.5× or p95 >2×. Kill AI positioning if a generic frontier model with the same exported context is noninferior. Kill planner if 14-day ITT CCT lower confidence bound ≤0 or due debt/hint dependency worsens. Stop expansion if <80% of 15 target users identify the primary action or median first value >10 minutes. Kill any feature whose fully loaded cost/CCT exceeds owner cap for two cohorts. Stop external pilot on any tenant/privacy/deletion residual or untraceable write.
