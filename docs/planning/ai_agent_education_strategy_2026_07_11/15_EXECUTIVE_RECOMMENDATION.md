# 15 — Executive recommendation

**Status:** PROPOSAL — NOT PRODUCT CANON · **Date:** 2026-07-11

## Recommendation

LinguistPro should remain a **reading-led Hebrew learning system with an optional evidence-grounded Mentor**, not become an agent-native chat product. The platform should use the least-agentic sufficient solution:

`authoritative Hebrew evidence + canonical learner events + deterministic FSRS/grader + bounded AI explanation/recommendation + independent delayed transfer evaluation`.

The transitional architecture is one deterministic controller/Mentor with typed model functions. The target is a thin learner orchestrator plus isolated backstage content/evaluation agents only where controlled evidence proves advantage. Event-driven multi-agent infrastructure is deferred.

## Top three product bets

1. **Context-Preserving Reading Loop (NOW).** Demo: an ambiguous word is resolved with provenance, reading continues, and the same construct is later retrieved unassisted in a new sentence. Kill if it does not beat translator+Anki on fragment completion/CCT.
2. **One Explainable Next Action (shadow NOW, pilot NEXT).** One bounded recommendation cites actual evidence, offers alternatives and opens the exact anchor. Kill if it does not beat deterministic due/weak-channel ordering on ITT delayed transfer and cost.
3. **Learner-Controlled Scaffold Fading (NEXT).** Previewable/undoable suggestions for niqqud, translation, hint or modality. Kill on hint rebound, abandonment, accessibility harm or absent no-hint transfer lift.

Speaking/writing, full personal curriculum and autonomous semantic publishing are not mature product bets.

## Top five platform investments

1. Versioned knowledge-unit, transfer, novelty, hint and missingness contracts.
2. Independent gold/human review, assignment/exposure/probe and policy replay platform.
3. Typed scoped tool/policy/idempotency/audit control plane.
4. Consent-aware trust-labelled context packs and approved provider/model gateway with cost attribution.
5. Public privacy/security/lifecycle/backup/deletion and operational proof for an external pilot.

## Top five experiments

1. Deterministic due vs personalized bounded planner.
2. Generic/local explanation vs evidence-grounded explanation.
3. Fixed/manual vs previewable adaptive scaffolding.
4. Curated rail vs personalized next-text candidate.
5. Premium-always vs small-model-first router; separately test single vs specialist only if architecture demands it.

All use delayed novel unassisted transfer scored independently; engagement is a proxy, not promotion evidence.

## Top risks

Invalid CCT denominator/MNAR; LLM linguistic or grading overreach; feature-supermarket/reading displacement; misleading privacy/provider eligibility and deletion-after-restore failure; human-review/ops cost dominating inference; curation and Hebrew-specific speaking-eval gaps; multi-agent context/permission leakage.

## First 90 days

Define and independently review CCT/knowledge/hint/missingness; establish locked gold and A/A/assignment design; specify typed policies/tools/context/provider registry and full cost ledger; create three curated starter paths; shadow grounded explanation and deterministic planner controls; perform tenant, prompt-injection, secret rotation, outage, billing kill, backup/restore/deletion and load drills; freeze a 20-adult-user pilot only if every blocker passes.

## Final answer to the research question

AI genuinely improves decisions when it can compare multiple valid contexts, modalities or explanations using evidence a static rule cannot compactly synthesize, while remaining bounded, inspectable and reversible. Multiple agents improve only independent criticism/validation or genuinely parallel backstage research—not learner truth or routine scheduling. Scheduling, eligibility, morphology, consent, identity, grading, canonical writes and rollback stay deterministic. The platform investment that matters is not an agent swarm; it is a trustworthy evidence-to-transfer control and evaluation plane.
