## O-001 · Новая версия не подхватывается обычной перезагрузкой
- **Дата / где:** 2026-09-24 (3.11.626 → 627) и 2026-09-25 (3.11.632 → 633), вкладка Студии владельца.
- **Что видно:** после деплоя две обычные перезагрузки оставляли старую `APP_VERSION`; помогла только `unregister()` регистрации service worker. `registration.update()` + `SKIP_WAITING` не помогали.
- **Почему важно:** обычный пользователь остаётся на старой версии, пока не закроет все вкладки; исправления до него не доходят, а stale-tab guard может блокировать действия.
- **Предполагаемая причина:** не проверена. Кандидаты: waiting worker не активируется (нет обработчика `SKIP_WAITING` или `clients.claim()`), либо `index.html` отдаётся из кэша SW до активации.
- **Предложение:** воспроизвести на одноразовом профиле: деплой → перезагрузка → какая версия; проверить `sw.js` (install/activate/message); показать «Доступна новая версия — обновить» с надёжной активацией.
- **Статус:** открыто.
