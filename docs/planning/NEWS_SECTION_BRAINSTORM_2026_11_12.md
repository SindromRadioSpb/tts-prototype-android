# Новостной раздел LinguistPro — мозговой штурм

Дата: 2026-11-12. Статус: **BRAINSTORM**, кода нет, решений владельца пока нет.
Следующий шаг: владелец выбирает вариант (см. §9) и отвечает на вопросы (§10), затем пишется проектный документ.

## 1. Запрос владельца

- Сделать «живой» раздел новостей на иврите. В Израиле много популярных изданий разных политических направлений и для разных социальных групп; это привлечёт новых пользователей.
- В новостях должно работать всё, что уже есть в учебных материалах: настраиваемая таблица (иврит, иврит с огласовкой, транслитерация, перевод), морфологическая карточка по тапу со слоем «в контексте (ИИ)», статус слов, подстрочник и прочее.
- Нужны дополнительные функции, которые дадут преимущество перед конкурентами.
- Пользоваться должно быть удобно и естественно. Пользователь выбирает направление новостей или конкретные издания.
- Источник материала указывается всегда, чтобы не было конфликтов.
- Интерфейс важен.
- Готовить материалы может ИИ-агент dot из подписки GPT Pro; по аналогии с Медиатекой он, возможно, сможет их и выкладывать.

## 3. Главный риск: авторские права

**Указание источника не даёт права на перепечатку.** Статьи Ynet, Haaretz, Israel Hayom и др. защищены авторским правом. Израильский закон об авторском праве (2007) допускает добросовестное использование, в том числе для обучения (ст. 19). Но **публичная перепечатка статьи целиком** в открытом приложении туда, скорее всего, не попадает. Это нужно проверить у юриста до публичного запуска. Чтобы не было конфликтов, нужна модель содержания, а не одна подпись «Источник».

Режимы содержания (каждый материал помечен одним из них):

| Режим | Что видит пользователь | Риск | Комментарий |
|---|---|---|---|
| **R-пересказ** | Собственный учебный текст LinguistPro **по материалам** издания (факты не охраняются), 1–3 уровня сложности, ссылка на оригинал | низкий | Основной публичный формат. Должно быть явно сказано «учебный пересказ, не текст издания» |
| **R-цитата** | Заголовок + 1–2 предложения оригинала + разбор + ссылка | низкий/средний | Для «одно событие — разные голоса» |
| **R-лицензия** | Полный оригинальный текст | нет при наличии разрешения | Партнёрство с изданием или открытая лицензия |
| **R-открытый** | Полный текст из открытых источников (пресс-релизы gov.il, Кнессет, Википедия/Викиновости на иврите под CC) | нет/низкий | Условия каждого источника проверить отдельно |
| **R-видео** | Встроенный YouTube-ролик издания + субтитры/расшифровка | низкий (встраивание разрешено правилами YouTube) | Расшифровку держать как учебный слой к ролику, не как самостоятельную перепечатку |
| **R-личный** | Пользователь сам принёс статью (ссылка/вставка/share) — материал виден только ему | минимальный | Как сейчас в Студии. Любое издание, в том числе платное |

Дополнительно:
- Логотипы изданий без разрешения не используем. Имя издания — текстом, нейтральный цвет-метка.
- Пересказ не должен выглядеть как оригинал издания: свой шаблон, подпись «LinguistPro по материалам Ynet».
- Провенанс в каждом материале: издание, URL, автор (если есть), дата публикации, дата получения, режим содержания, кто подготовил (агент dot / владелец), кто утвердил.

## 4. Издания и как их выбирать

Черновой список для обсуждения; правильность названий и ориентации проверить:

- Массовые и общие: Ynet / Yedioth Ahronoth, Walla, Maariv, N12 (Mako, канал 12), Kan 11 (общественная телерадиокомпания), i24 (иврит).
- Правее центра: Israel Hayom, Channel 14 (Now14), Makor Rishon (религиозно-сионистский), Arutz Sheva / INN.
- Левее центра: Haaretz, Davar.
- Харедимные: Kikar HaShabbat, Behadrei Haredim.
- Экономика: Globes, Calcalist, TheMarker.
- Спорт: Sport5, ONE.
- Лёгкий иврит: «Шаар ла-матхиль» (газета на упрощённом иврите) — ценнейший источник для начинающих; права проверить.

**Как подписывать направление, не превращая приложение в участника спора:**
- Не ставить свои политические ярлыки («левые/правые»). Вместо них: выбор **конкретных изданий** + нейтральные **круги**: «Общие», «Религиозные», «Харедимные», «Экономика», «Спорт», «Регионы», «Лёгкий иврит».
- Возможна мягкая ось «спектр» с объяснением, откуда она взята (внешний рейтинг, а не наше мнение). Решает владелец.
- Режим «сбалансированная лента»: по каждому сюжету минимум два издания с разных сторон.

## 5. Конвейер с агентом dot

```
dot находит новость → готовит пакет новости (текст по режиму + провенанс + уровень + тема/сюжет)
   → «Входящие новости» (черновики, видит только владелец)
   → автоподготовка на сервере: огласовка (Dicta), транслитерация, перевод, морфология, % частотной лексики
   → предпросмотр в учебном экране → «Опубликовать» (канонический писатель Медиатеки)
   → лента; через N дней — в архив сюжета
```

- Формат пакета — вариант существующего архива LPLP с полями новости (издание, URL, даты, режим, сюжет, уровень). Тогда dot может выдавать файл уже сейчас, а владелец загружает его так же, как в Медиатеку.
- Следующий шаг автоматизации — отдельное право агента «писать **черновики** новостей» (не публиковать). Это не нарушает правило W0, по которому агент не пишет в канон: публикует только человек одной кнопкой. Позже — пакетное утверждение «опубликовать всё утреннее».
- Проверки до публикации: ссылка на оригинал открывается; пересказ не дублирует оригинал дословно (порог совпадения n-грамм); есть дата; нет повтора уже опубликованного сюжета.
- Свежесть: у новости есть срок «горячей» жизни (24–72 ч). Потом она уходит из ленты в архив сюжета, но остаётся доступной и в «Моём словаре».

## 6. Паритет (обязательно, без исключений)

Новость открывается **тем же учебным экраном**, что и материал Зала/Медиатеки: таблица колонок (иврит / с огласовкой / транслитерация / перевод), подстрочник, морф-карточка по тапу + «в контексте (ИИ)», статус слов, озвучка с подсветкой, добавление в повторение (SRS), «Мой словарь», экспорт. Отдельной «новостной читалки» нет — иначе функции разойдутся.

## 7. Дополнительные функции — полный список идей

**A. Одно событие — разные голоса** (кандидат в главную особенность)
- Сюжет объединяет 2–5 изданий. Рядом заголовки и ключевые формулировки: как одно и то же событие называют разные издания (выбор слов, порядок фактов). Подсветка «слов-рамок».
- Это одновременно язык, медиаграмотность и уважение ко всем сторонам: приложение не говорит, кто прав, а показывает, как пишут.

**B. Под мой уровень**
- Один сюжет в 2–3 уровнях: «лёгкий» (как «Шаар ла-матхиль») → «средний» → «как в газете».
- Процент знакомых слов на карточке ленты и фильтр «подходит мне (≥85%)».
- «Новые для меня слова» — 5–7 слов статьи, которых нет в «Моём словаре».

**C. Газетный иврит**
- Тренажёр заголовков: сокращения и аббревиатуры (רה"מ, צה"ל, ח"כ, בג"ץ), смихут, пропуск глаголов в заголовках, газетные клише.
- Разбор аббревиатуры по тапу: расшифровка + произношение.
- «Слово недели в новостях» — частотность новостной лексики за неделю.

**D. Контекст**
- Карточки сущностей: кто это (политик, партия, место, организация) — коротко, нейтрально, с датой.
- Хронология сюжета: что было до этого.
- Объяснение реалий (что такое «ועדת חוץ וביטחון» и т. п.).

**E. Слушать и смотреть**
- Озвучка каждой новости + «утренняя сводка» (5 новостей подряд, как радио) с медленной скоростью.
- Видеоновости из YouTube изданий с учебной таблицей под роликом (путь Медиатеки).

**F. Упражнения**
- 3 вопроса на понимание, «перескажи в двух предложениях» (graded retell), cloze из новостной лексики.
- Статус «прочитал/понял» влияет на компас и «Мой словарь».

**G. Доставка и привычка**
- «Новость дня под твой уровень» в Telegram Mini App и push.
- Утренний дайджест из выбранных изданий.
- Серия дней чтения новостей.

**H. Бережность**
- Пометка тяжёлых тем (теракты, война, жертвы) и фильтр «без тяжёлых тем».
- Фильтр «без политики» (экономика, спорт, наука, культура).

**I. Принеси свою статью**
- Кнопка «Поделиться → LinguistPro» в браузере телефона или вставка ссылки → личный учебный материал из любой статьи, в том числе платной. Источник подставляется автоматически.

**J. Связь с остальным приложением**
- Мир «Israel Elections 2026»: выборные новости живут внутри мира.
- Слово из новости → «встречалось в Зале/Медиатеке» (кросс-корпусная связь).

## 8. Интерфейс — идеи

- **Место в навигации:** отдельная вкладка «Новости» рядом с Залом и Медиатекой (новости — повод открыть приложение каждый день; прятать их внутри Зала невыгодно).
- **Первый вход:** 20-секундный выбор «Какие издания читаешь?» — плитки с названиями, сгруппированные по кругам, плюс кнопка «сбалансированная лента». Потом меняется в настройках ленты.
- **Лента:** карточки. На карточке: метка издания (имя + нейтральный цвет), время («2 ч назад»), заголовок на иврите, перевод заголовка мелко, уровень, % знакомых слов, длительность чтения/прослушивания, значок режима («пересказ», «видео», «цитаты»).
- **Чипы сверху:** «Мои издания», «Сюжеты», «Под мой уровень», круги.
- **Карточка сюжета:** раскрывается в «разные голоса» — горизонтальная лента заголовков разных изданий.
- **Экран новости:** тот же учебный экран. Сверху плашка источника: «LinguistPro по материалам Ynet · 12.11.2026 · Открыть оригинал ↗». Внизу повтор плашки и провенанс полностью.
- **Mobile/RTL:** заголовки на иврите RTL, интерфейс по локали; видео + таблица на телефоне — как уже принято для учебного экрана.

## 9. Варианты (концепции целиком) и рекомендация

| # | Вариант | Плюсы | Минусы | Затраты |
|---|---|---|---|---|
| 1 | **Редакционная лента пересказов** (dot готовит → владелец утверждает → публикация) | Публично, безопасно по правам, работает на рост аудитории, полный паритет | Нужна ежедневная редакционная работа (dot снимает её основную часть) | средние: расширение Медиатеки |
| 2 | **Видеоновости** через YouTube изданий | Подлинный голос издания, права проще, путь уже есть | Зависимость от YouTube, не всё есть на видео | низкие |
| 3 | **«Принеси свою статью»** | Любое издание, ноль конфликтов, сильная функция для продвинутых | Не наполняет публичную ленту | низкие/средние: share target есть |
| 4 | **«Одно событие — разные голоса»** поверх 1 | Уникально, вирусно, медиаграмотность, нейтральная позиция приложения | Сложнее редакционно; цитаты требуют аккуратности | средние |
| 5 | Полная перепечатка с подписью источника | Просто | **Юридический риск**, конфликт с изданиями | — не рекомендуется |

**Рекомендация (моя оценка):** основа — **1 + 3**. Главная особенность — **4**, вводится вторым шагом, когда пойдёт поток. **2** — дешёвое дополнение в любой момент. Вариант 5 отклонить.

Предлагаемый порядок:
1. **N0** — модель материала «новость» (провенанс, режим, сюжет, свежесть) поверх Медиатеки; формат пакета для dot; «Входящие новости» с ручной загрузкой пакета.
2. **N1** — вкладка «Новости»: выбор изданий, лента, плашка источника, тот же учебный экран; % знакомых слов на карточке.
3. **N2** — «Принеси свою статью» (share/URL → личный материал с автоподстановкой источника).
4. **N3** — сюжеты и «разные голоса»; уровни сложности.
5. **N4** — газетный иврит (аббревиатуры, заголовки), сущности, хронология.
6. **N5** — доставка: новость дня в Telegram/push, утренняя аудиосводка; право агента писать черновики.

## 10. Вопросы владельцу (влияют на то, что строим)

1. Публичная лента — только пересказы/цитаты/видео (безопасно) или вы готовы искать разрешения изданий на полный текст?
2. Политическая ось: только выбор изданий и нейтральные круги — или нужна явная шкала «спектра»?
3. Кто утверждает публикацию: всегда вы вручную, или допустимо пакетное утверждение утренней подборки?
4. Как dot отдаёт результат: файлом (сразу, без доработок сервера) или через подключение агента (нужен новый доступ «черновики новостей»)?
5. Аудитория новостей: те же изучающие (RU-интерфейс) или отдельное продвижение (EN/другие языки перевода)?
6. Сколько новостей в день — ориентир (5? 20?), это определяет стоимость автоподготовки (огласовка, перевод ИИ).

## 11. Антицели

- Не стать агрегатором-перепечатчиком чужих статей.
- Не выдавать пересказ за текст издания и не прятать источник.
- Не навешивать собственные политические оценки изданиям.
- Не делать отдельную «новостную читалку» с урезанными функциями.
- Не показывать в ленте вчерашнее как свежее.
- Не позволять агенту публиковать без утверждения человеком.

## 12. Вариант владельца (2026-11-12, вторая итерация) и доработка

### 12.1 Что предложил владелец

- Вкладка «Новости» → перечень изданий → пользователь выбирает, например, Ynet.
- Внутри издания — не оригиналы, а **пересказы** статей. По возможности сохранять изображения из исходной статьи.
- dot готовит материалы бесплатно и **массово**, сразу по группе изданий.
- dot подключается **с правами редактора** (из своего облачного ПК или с локального ПК владельца) и выкладывает через браузер. Выкладывать может и сам владелец.
- Передача **одним архивом на всю порцию**, а не архивом на каждую статью.
- Цель — охватить **весь объём** изданий. Старое **автоматически уходит в «Архив новостей»**, чтобы не засорять учебные материалы пользователей.

### 12.2 Доработка — по пунктам

**А. Изображения — самое рискованное место.** Пересказ меняет текст, а фото пересказать нельзя: копия снимка — та же самая копия. Права на фото обычно у агентства или фотографа, а не у издания. Предложение по слоям:
1. **Превью-ссылка** (как в Telegram/WhatsApp): картинка `og:image` загружается браузером читателя с сайта издания, у нас не хранится, с подписью «Фото: Ynet», клик ведёт на оригинал. Риск низкий, диск не тратим. Минус: издание может запретить такую загрузку, тогда показываем запасную обложку.
2. **Свободные фото** (Wikimedia Commons, фотоархив Правительственного пресс-бюро — условия проверить) — хранить можно, с указанием автора и лицензии.
3. **Запасная обложка**: типографская карточка с цветом издания и рубрикой; при желании — иллюстрация ИИ с пометкой «иллюстрация».
4. **Не делать:** скачивать и хранить фото из статей у себя.

**Б. Один архив на порцию — «пакет новостей».** Один ZIP, внутри `manifest.json` и папка на каждую статью:
- Поля статьи: издание, рубрика издания, URL оригинала, дата публикации, дата получения, автор (если есть), заголовок оригинала (короткая цитата), пересказ (уровень 1–3), перевод заголовка, ссылка на изображение и его подпись, ключ сюжета (для «разных голосов»), теги, отметка «тяжёлая тема».
- Обработка **по одной статье**: брак одной статьи не валит весь пакет. В конце — квитанция: «принято 412, повторы 37, отклонено 9 (причины)».
- **Повторная загрузка безопасна:** ключ статьи = издание + URL оригинала. Тот же пакет можно загрузить дважды, а исправленная статья заменяет прежнюю версию.
- Автопроверки: ссылка ведёт на это издание; есть даты; пересказ не совпадает с оригиналом дословно (порог совпадения фраз); иврит в пересказе; размер.
- Пакет можно загрузить через браузер (перетащить файл) — одинаково для dot и для владельца.

**В. Права редактора для dot — отдельная роль, не ваш аккаунт.**
- Новая роль **«Редактор новостей»**: может только загружать пакеты новостей и управлять ими. Учебные материалы, Медиатека, Зал, личные данные и настройки — недоступны.
- У dot свой вход (отдельная учётная запись или приглашение со сроком). Отозвать можно одной кнопкой. Журнал: какой пакет, когда, сколько статей.
- Публикация: предлагаю **автопубликацию прошедших проверки** (иначе массовый поток упрётся в ваше ручное утверждение) плюс у вас кнопка «снять статью/пакет». Альтернатива — утверждать пакет целиком. Решать владельцу.
- Если dot работает в браузере вашего локального ПК, ему всё равно нужен свой вход — не под вашей сессией владельца.

**Г. «Весь объём» — честный расчёт нагрузки.** Крупное издание выпускает сотни материалов в день; 10 изданий — порядка тысячи в день.
- **Огласовка через Dicta массово недопустима:** уже был бан по IP за массовые запросы (журнал памяти). Решение: огласовку, транслитерацию и морфологию считать **при первом открытии** статьи читателем (лениво) с кэшированием, а не для всех тысяч заранее. Перевод и пересказ уже приходят в пакете от dot — это бесплатно для нас.
- **Диск прода** уже несколько раз заполнялся до 100%. Текст статьи — единицы КБ, это немного; тяжёлое — готовые слои и озвучка. Отсюда правило хранения (см. Д).
- Рекомендация: начинать не с «всего», а с главных рубрик 5–8 изданий, замерить реальный объём за неделю, затем расширять.

**Д. Автоархив — три яруса.**
| Ярус | Срок (предложение) | Что видно | Что храним |
|---|---|---|---|
| Свежие | 0–3 дня | лента издания | всё + готовые слои |
| Архив новостей | 3 дня – N месяцев | раздел «Архив новостей»: поиск по изданию, дате, рубрике, сюжету | пересказ + метаданные; готовые слои удаляются и пересчитываются при открытии |
| Глубокий архив | после N месяцев | по поиску | только метаданные и ссылка на оригинал (или полное удаление — решить) |

- **Главное правило:** новости вообще **не попадают** в «Мои материалы» сами по себе. В личное пространство статья входит, только если пользователь её сохранил, начал учить или добавил из неё слова. Такие статьи **не архивируются для этого пользователя**, и связи слов в «Моём словаре» не рвутся.
- Архивирование — по расписанию на сервере, без участия людей; в журнале видно, сколько ушло в архив.

**Е. Как это выглядит у пользователя.**
- «Новости» → плитки изданий (сгруппированы по кругам) → издание → **рубрики издания** (חדשות, כלכלה, ספורט, תרבות…) → лента карточек → статья в обычном учебном экране.
- Вверху ленты — «Мои издания» (закреплённые), чтобы не проходить выбор каждый раз.
- Плашка на каждой статье: «Учебный пересказ LinguistPro по материалам Ynet · дата · Оригинал ↗».
- Сквозная лента «Все мои издания» и сюжеты «разные голоса» остаются как следующий шаг: пакет уже несёт ключ сюжета, поэтому позже ничего переделывать не придётся.

### 12.3 Вопросы владельцу по этой итерации
1. Изображения: устраивает схема «превью-ссылка с сайта издания + запасная обложка», без хранения фото у нас?
2. Публикация от dot: автоматически после автопроверок (с вашей кнопкой «снять») или каждый пакет утверждаете вы?
3. Срок свежести (предложено 3 дня) и что делать со статьями старше N месяцев: оставлять метаданные или удалять?
4. Стартовый набор: какие 5–8 изданий и рубрик первыми?
5. Какие поля dot реально умеет отдавать в пакете (перевод, уровни, ключ сюжета) — образец одного пакета от dot сразу снимет половину неопределённостей.
