# Инженерный атлас 97002 — требования к качеству учебного пособия

Дата: 2026-10-31. Основание: приёмка владельца («прототип → зрелый продукт»; находки: значки 👍/👎/❗ вне
своего текста, «ждёт вычитки» в каждой строке, мишень 🎯 на стр. 62). Документ — чек-лист приёмки: каждая
страница книги проверяется по нему автоматически (`scripts/atlas/audit-reader.cjs`) и визуально (скан книги
рядом со страницей ридера). Перечень пополняется по ходу аудита — новые пункты помечены «(аудит)».

Уровни: **A** — блокирует выпуск; **B** — исправить в этом цикле; **C** — улучшение, в журнал.

## 1. Полнота: на странице ридера есть всё, что есть на странице книги

| № | Требование | Ур. |
|---|---|---|
| 1.1 | Каждый текстовый блок книги присутствует (иврит + перевод), ничего не потеряно и не задвоено. | A |
| 1.2 | Каждый рисунок книги показан (кроп скана), с подписью «איור N» и легендой, если в книге есть подписи. | A |
| 1.3 | Каждая таблица книги показана целиком; пустые служебные таблицы не показываются. | A |
| 1.4 | Каждая формула показана (MathML), с обозначениями, если они даны. | A |
| 1.5 | Каждый значок/пиктограмма книги передан понятным символом в своём месте (см. §3). | A |
| 1.6 | Страница без перевода честно помечена; страница без текста — помечена «нет текста», но не пустая. | A |
| 1.7 | Нет «мусорных» элементов: рисунков 1×1, пустых рамок, пустых легенд, пустых строк. (аудит) | A |

## 2. Порядок и связи — как в книге

| № | Требование | Ур. |
|---|---|---|
| 2.1 | Блоки идут в порядке книги (сверху вниз). | A |
| 2.2 | Рисунок стоит на своём месте, над своей подписью; подпись не дублируется. | A |
| 2.3 | Таблица стоит рядом со своим текстом (заголовком, вводной строкой); копия таблицы «в одну строку» не показывается вместо таблицы. | B |
| 2.4 | Значок обрамляет тот абзац/серию пунктов, к которой относится в книге. | A |
| 2.5 | Номера на рисунке совпадают с легендой; нажатие на номер подсвечивает связанный текст. | B |
| 2.6 | Опечатки книги показаны у своего блока, с пометкой «ждёт подтверждения». | B |

## 3. Значки и пиктограммы

| № | Требование | Ур. |
|---|---|---|
| 3.1 | 👍 Преимущества, 👎 Недостатки, ❗ Обратите внимание, 🎯 Цель/что проверяем — подпись ru + he, цветная полоса группы. | A |
| 3.2 | Значок без подписи у поставщика распознаётся по изображению (справочник значков книги), а не теряется. (аудит) | A |
| 3.3 | Два значка над одним блоком (поставщик слил текст) — обе подписи. | B |
| 3.4 | Символы допусков (⏤ ▱ ○ ⌭ ⌒ ⌓ ∥ ⊥ ∠ ↗ ◎ ⌖ ⌯ ⌰) показываются как символ рядом с текстом, а не как непонятная картинка. (аудит) | B |
| 3.5 | Мелкие подписи-числа на рисунке (маркировка 8.8, допуски ±0.05) остаются частью рисунка, не «значками». (аудит) | B |

## 4. Учебные слои строки

| № | Требование | Ур. |
|---|---|---|
| 4.1 | Строка 2×2: иврит \| транслит, огласовка \| перевод; на ПК и на телефоне. | A |
| 4.2 | «Колонки»: любой набор смыкается без дыр; выбор общий с Залом. | A |
| 4.3 | Нет служебных слов поставщика в тексте чтения (bbox, source_text, jsonl, «редакционное описание»…). | A |
| 4.4 | Нет сырого LaTeX (`\tau_S`, `\frac`) ни в таблицах, ни в легендах, ни в тексте. | A |
| 4.5 | Нет текстов `undefined`, `null`, `NaN`, `[object Object]`. | A |
| 4.6 | Направление текста верное: иврит RTL, русский/транслит LTR, числа и единицы не «прыгают». | B |

## 5. Таблицы

| № | Требование | Ур. |
|---|---|---|
| 5.1 | Шапка — только строка подписей; единицы — мелко рядом с числом. | B |
| 5.2 | Широкая таблица прокручивается в своей рамке, страница — нет. | A |
| 5.3 | Таблица без русского перевода ячеек помечена (иврит виден). | B |

## 6. Рисунки

| № | Требование | Ур. |
|---|---|---|
| 6.1 | На скане только номерки, не закрывающие подписи книги; легенда «№ иврит — русский». | A |
| 6.2 | Повторы в легенде (F, F, F…) не раздувают список: одинаковые подписи — один пункт с несколькими номерами. (аудит) | B |
| 6.3 | Рисунок не шире колонки; на телефоне читаем. | A |

## 7. Вычитка

| № | Требование | Ур. |
|---|---|---|
| 7.1 | Одна отметка на страницу; галочка — только владельцу; сохраняется на сервере. | A |
| 7.2 | Счётчик раздела и оглавления совпадает с отметками. | A |

## 8. Экран, доступность, темы

| № | Требование | Ур. |
|---|---|---|
| 8.1 | 390 / 768 / 1440 px — без горизонтальной прокрутки страницы. | A |
| 8.2 | Светлая и тёмная темы: контраст текста ≥ 4.5:1. | A |
| 8.3 | Интерфейс на иврите (RTL) и английском — подписи переведены, раскладка зеркалится корректно. | B |
| 8.4 | Цели нажатия ≥ 36 px на телефоне; фокус виден; у значков есть подпись для чтения с экрана. | B |
| 8.5 | Ошибок скриптов в консоли нет. | A |

## 9. Навигация и печать

| № | Требование | Ур. |
|---|---|---|
| 9.1 | Переход к странице, поиск (иврит/русский), адрес хранит раздел и страницу. | A |
| 9.2 | Печать раздела: значки как подписи, рисунки и таблицы присутствуют. | B |
