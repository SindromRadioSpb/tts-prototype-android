# Physics Year 1 — beginner pedagogy R11

Дата: 2026-08-28

## Результат

Добавить ко всем 74 локальным учебным производным самостоятельный
педагогический мост между условием и экзаменационным протоколом, а также
машиночитаемый prompt для пользовательского агента.

## Архитектура

- Существующие condition/answer/solution/exam ledgers остаются единственным
  источником чисел, формул, вычислений и статусов сверки.
- Новый `beginner-pedagogy-ledger.ru.json` содержит общие смысловые профили и
  74 task-specific пояснения без числового решения.
- Builder сливает профиль, пояснение и проверенное решение только при сборке.
- Markdown, HTML и agent guide генерируются детерминированно.
- Master prompt поставляется отдельным артефактом и включается в manifest.

Такой разрез исключает dual-write физического ответа: педагогический текст
можно улучшать, не меняя доказанный расчёт.

## Обязательный слой каждой задачи

1. Простая физическая картина.
2. Необходимый минимум знаний.
3. Глубинный принцип и условия его применимости.
4. Маршрут из трёх или более подцелей.
5. Главная ловушка именно этой задачи.
6. Два вопроса для самопроверки без раскрытия ответа.
7. Полный экзаменационный протокол из существующего ledger.

## Шлюзы

- Точный набор 74 задач и валидные ссылки на профили.
- Нет TODO, «очевидно», «просто подставим» и новых числовых ответов в
  педагогическом ledger.
- Все 74 Markdown и HTML-карточки содержат педагогический блок.
- Agent guide содержит режимы «намёк / разбор вместе / полное решение», порядок
  источников и поведение при нехватке данных.
- Детерминированная повторная сборка, unit tests, визуальная проверка desktop и
  mobile.
- Только локальные производные; production-публикация вне scope.
