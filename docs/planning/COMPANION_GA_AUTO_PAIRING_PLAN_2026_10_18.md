# Local AI Companion: из беты в постоянную функцию, сопряжение без копирования токена

Дата: 2026-10-18. Статус: **ПЛАН, ждёт решения владельца** (код не написан).
Повод: владелец одобрил направление: убрать ручное копирование токена, заменить вход в бету галочкой
«Использовать компаньон на этом ПК» и снизить порог входа.

## 1. Как устроено сейчас (замер по коду)

| Звено | Где | Поведение |
|---|---|---|
| Бета на сервере | `server.js` `LOCAL_ASR_BETA_ENABLED` → `/api/client-config` `localAsr.beta` | На проде `true` для всех |
| Вход в бету в браузере | `local-asr-client.js` `enroll()` → `localStorage["linguistpro.experimental.localAsr"]="1"` | Только по скрытой ссылке `#local-asr-beta`. Пропала запись — вернуть из интерфейса нельзя (случай 2026-10-18) |
| Видимость выбора «Local» | `MediaReadiness.deviceAsrPolicy(ua, enrolled)` | Без записи в бету выбор скрыт, файл молча идёт в Gemini |
| Токен | `ai-local/security.py` `pairing_token()` → `%LOCALAPPDATA%\LinguistPro\ai-local\pairing-token` (32 байта) | Пользователь копирует его кнопкой в окне компаньона и вставляет в Студию |
| Хранение токена в браузере | `sessionStorage["linguistpro.localAsr.pairingToken"]` | Теряется при каждом перезапуске браузера: вставлять снова |
| Защита /v1 | `require_companion_auth`: Origin из списка (прод + localhost:3000) **и** Bearer-токен | Чужой сайт получает 403 ещё до токена |
| Служба и окно | служба (uvicorn) — отдельный отсоединённый процесс; окно (Tk) открывается отдельно | Окно может быть закрыто, пока служба работает |

## 2. Что именно мешает пользователю

1. Вход в бету спрятан: новый пользователь не знает о ссылке, а у старого запись теряется (очистка данных сайта).
2. Токен приходится вставлять после каждого перезапуска браузера: он хранится только до закрытия.
3. Ручное копирование между двумя окнами — шаг, на котором отваливаются новички.
4. Ошибки разнесены по разным местам: «нужен Gemini-ключ» внизу окна, а не «запустите компаньон».

## 3. Предлагаемая схема

### 3.1 Сопряжение в один клик (вместо копирования)

1. Студия видит компаньона без токена: новый открытый эндпоинт `GET /v1/hello`. Он проверяет только Origin и
   отдаёт `{product, version, asr_ready, mt_ready, paired_origin_known}`, без каких-либо данных пользователя.
2. Студия: «Компаньон найден на этом ПК — Подключить». Нажатие → `POST /v1/pair/request` (Origin-проверка) →
   компаньон создаёт заявку `{id, code: 4 цифры, origin, expires: 2 мин}`.
3. **Подтверждение в окне компаньона:** «LinguistPro (https://linguistpro.kolosei.com) просит доступ. Код 4821.
   Разрешить / Отклонить». Код показан и в Студии: человек видит, что подтверждает именно свой запрос.
   Если окно закрыто — служба открывает его сама (или Студия пишет «Откройте окно Local AI Companion»).
4. Студия опрашивает `GET /v1/pair/status/{id}` и после «Разрешить» получает токен **один раз**.
5. Токен хранится в `localStorage` этого браузера (переживает перезапуск). Отключение: кнопка в Студии
   («Отключить компаньон») и в окне компаньона («Отключить все браузеры» = смена токена).

Кнопка «Скопировать токен» остаётся в окне компаньона как запасной путь (например, для localhost-разработки).

### 3.2 Из беты в постоянную функцию

- Вместо скрытой записи в бету — **галочка в настройках Студии** «Использовать Local AI Companion на этом ПК»
  (только Windows/desktop; на телефоне не показывается, там 127.0.0.1 — сам телефон).
- Галочка включена и компаньон отвечает → в «Медиа на иврите» по умолчанию выбран **Local**. Gemini — явный
  выбор в том же списке. Молчаливого перехода Local→Gemini нет (действующий принцип).
- Компаньон не отвечает → в блоке медиа строка «Компаньон не запущен — запустите Local AI Companion»
  и ссылка на установщик; выбор Gemini остаётся.
- Серверный флаг `LOCAL_ASR_BETA_ENABLED` остаётся как аварийный выключатель (kill switch), но больше не
  требует записи в бету в браузере. Для MADLAD (local MT) — та же схема, отдельной галочкой (качество MADLAD
  по-прежнему «LIMITED EVIDENCE», бетой остаётся до отдельного решения).

### 3.3 Что меняется в компаньоне

Новый релиз установщика (beta.12 → 0.4.0): эндпоинты `hello`, `pair/request`, `pair/status`, `pair/revoke`;
файл заявок в `state/`; окно опрашивает заявки и показывает диалог; кнопка «Отключить все браузеры».
Пользователи со старым компаньоном продолжают работать через вставку токена (Студия различает по `/v1/hello`:
404 → старый компаньон → старый путь + подсказка обновиться).

## 4. Разбор возражений по ролям (до кода)

| Роль | Возражение | Ответ / что меняем в плане |
|---|---|---|
| R14 Security | Автовыдача токена любому, кто прислал правильный Origin, обнуляет смысл токена | Поэтому не автовыдача: подтверждение человеком в окне компаньона + код сверки. Origin браузеры не подделывают; локальный процесс может подделать Origin, но он и так читает файл токена (тот же пользователь), так что модель угроз не ухудшается |
| R14 Security | `localStorage` переживает перезапуск, значит XSS на проде получает долговременный токен | Риск реальный, но и сейчас XSS на проде действует от имени пользователя во время сессии. Смягчение: токен даёт доступ только к loopback-API (распознать/перевести), не к файлам пользователя; есть «Отключить все браузеры»; CSP прода уже строгая (security headers). Записать в журнал рисков |
| R14 Security | DNS-rebinding к 127.0.0.1 | Проверка Origin по точному списку + PNA-preflight уже закрывают; `hello` не отдаёт данных |
| R4 Premium UX | Окно компаньона может быть закрыто — диалог некому показать | Служба открывает окно сама; если не может — Студия говорит, что сделать, а не крутит бесконечный спиннер (таймаут заявки 2 мин) |
| R4 Premium UX | Галочка + выбор Local + Gemini — три места решения | Одно место: галочка в настройках; в окне медиа только список «Распознавание: Local / Gemini» с Local по умолчанию, когда компаньон готов |
| R5 Product | «Постоянная функция» на Windows+NVIDIA — узкая аудитория; не путать новых пользователей | Блок показывается только на desktop Chrome; без NVIDIA компаньон сам говорит «устройство не подходит» (уже есть preflight `CUDA_DRIVER`) |
| R11 Do-no-harm | Молчаливый откат на Gemini тратит деньги пользователя | Сохраняем правило: Gemini только явным выбором; ошибка Local — честная строка, без автоперехода |
| R11 Do-no-harm | Старые компаньоны (beta.11) сломаются | Обратная совместимость: `/v1/hello` 404 → старый путь с вставкой токена |
| R16 Cost | Нет | Локальное распознавание бесплатно; меньше случайных платных ASR (сегодня файл без записи в бету уходил в Gemini) |
| R13 Migration | Пользователи с записью в бету и токеном в sessionStorage | При первом запуске: запись в бету → галочка включена; токен из sessionStorage → переносится в localStorage после успешной проверки |

Новых ролей не требуется.

## 5. Порядок работ (после одобрения)

1. **Студия без изменений компаньона:** галочка вместо записи в бету, хранение токена в `localStorage`,
   перенос старой записи, строка «компаньон не запущен». Одним этим убираются пункты 1, 2 и 4 из §2.
2. **Компаньон 0.4.0:** `hello` / `pair/*` / окно подтверждения / «Отключить все браузеры» + pytest.
3. **Студия:** кнопка «Подключить» с кодом сверки, опрос статуса, обратная совместимость со старым компаньоном.
4. Проверка вживую на ПК владельца: чистый профиль Chrome → подключение одним кликом → ASR → перезапуск
   браузера → без повторного подключения.
