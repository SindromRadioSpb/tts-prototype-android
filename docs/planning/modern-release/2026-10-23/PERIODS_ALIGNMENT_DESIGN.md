## 4. Предлагаемая модель — одна классификация

- **Навигация Зала:** 5 официальных периодов Бен-Иегуды в официальном порядке, с ивритским названием источника и переводом на язык интерфейса. Подпись раздела «по каталогу Бен-Иегуды» вместо «вычислен по автору».
- **Работы без периода у самого Бен-Иегуды** (около 510: 188 + открытые из 385) — честный раздел «Без периода в каталоге Бен-Иегуды». Это не ещё одна классификация, а отсутствие данных в источнике, названное прямо. Раздел показывается последним.
- **Удалённые с сайта работы** (404, около 64) — убираются из каталога. Читать их у нас всё равно нельзя: ни одна не опубликована. Каждая проверяется отдельно, по каждой сохраняется доказательство.
- **Разделы приложения** (`era` из Wikidata) из интерфейса уходят полностью. Годы жизни автора остаются информацией на странице автора, а не категорией.
- **Инструменты агента (MCP):** тот же словарь из 5 периодов + `none`. Старые значения принимаются один выпуск с явным сопоставлением и предупреждением в ответе, потом отклоняются. Это внешний контракт Hermes, поэтому переход двухшаговый.
- **Доказательство в карточке:** `source_period = { value, status:"known", source_label, source_url, snapshot:"sha256:…", fetched_at }`, как у нынешних 615 работ. У работы без периода — `status:"source-has-none"`.
- **Обновление:** снимок периодов пересобирается при каждом выпуске каталога; дата снимка видна в «О материале».

## 6. Опровергающий разбор по ролям

- **R6 Куратор-библиотекарь.** *Возражение:* раздел «без периода» (≈510) — свалка. *Ответ:* это правда источника. Прятать работы нельзя, приписывать период самим — значит снова строить свою классификацию. Раздел последний и прямо назван.
- **R7 Литературовед.** *Возражение:* «Тхия» Бен-Иегуды — 16 376 работ, включая авторов 1930–40-х. Раздел огромный, и мы теряем различение, которое давал «Подмандатный». *Ответ:* владелец выбрал одну классификацию источника. Внутри Тхии навигация идёт по автору, есть сортировка и поиск. Годы жизни автора видны на его странице. Вводить подразделы — снова своя классификация; если понадобится, это отдельное решение.
- **R9 Authority-control.** *Возражение:* классификация по снимку сайта может измениться. *Ответ:* снимок датирован, у каждой страницы есть sha256, пересборка — при каждом выпуске, расхождения между снимками попадут в отчёт выпуска.
- **R4 Премиум-UX.** *Возражение:* у читателя пропадут привычные пути «Подмандатный → автор», старые ссылки поломаются. *Ответ:* старые адреса открывают каталог с пояснением. Прогресс, закладки и «Продолжить» привязаны к тексту, а не к разделу, и не меняются.
- **R11 Регрессолог.** *Возражение:* массовая смена `era` у ~10,1 тыс. карточек сломает всё, что читает `era`: поиск, ссылки «ещё у автора», агента, sidecar-индексы. *Ответ:* полный перечень потребителей (§5), каждый — с тестом. Выпуск — отдельная версия каталога (v9) с откатом на v8.
- **R5 Продукт.** *Возражение:* «Хаскала» и «Тхия» иностранцу ничего не говорят. *Ответ:* название источника + перевод + короткое пояснение; диапазоны лет показываем, только если найдём их у самого Бен-Иегуды.
