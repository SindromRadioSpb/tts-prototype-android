# Слой слов учебной карточки: исследование и план (канон)

Дата: 2026-10-11. Статус: **OWNER-APPROVED** (решения D1–D3 ниже). **Ф0 выполнена 2026-10-11** — следующая Ф1.
Ветка: `feat/word-layer`. Отчёт Ф0: [word-layer/F0_REPORT_2026_10_11.md](word-layer/F0_REPORT_2026_10_11.md).

## 1. Потребность владельца

Учебная карточка сейчас даёт таблицу «иврит / иврит с никудом / транслит / перевод» и морф-карточку
по тапу (перевод начальной формы + спряжение/склонение при наличии). Во время чтения или просмотра
медиа нельзя тапать каждое слово. Нужен инструмент, который **без тапа** показывает слова и перевод
**именно встретившейся формы**, даёт интерактивный переход к полной парадигме (все формы с переводом,
текущая отмечена) и позволяет добавить единицу в словарь. Работать должно на ПК и телефоне.

Прототип-концепция (ручной, вне программы): `E:\Уроки\Методика и Пример_Мозг_v2\` —
три XLSX (Сопровождение / Подробный разбор / Учебный навигатор) + `04_Методика_и_ТЗ_LinguistPro.docx`.
Сделан вручную в ChatGPT по Word-экспорту карточки «До последнего имени: люди с военной базы Шура»
(730 строк, 5649 вхождений, 2417 типов, 1319 лемма-значений, 46 704 строки парадигм).
Ограничения прототипа — следствие Excel: клик не меняет выбор без макросов, INDIRECT ломается после
сортировки, мобильные редакторы XLSX поддерживают функции частично.

Что берём из ТЗ прототипа как требования: раздельные «форма в тексте / перевод формы в контексте /
лемма / значение леммы»; матрица «лицо × время» с ▶ текущей формой; перевод **каждой** формы
парадигмы; четыре вида учебных единиц (лемма-значение, трудная форма, сочетание, речевая формула);
статусы честности («по контексту / нужна проверка / не разбирать без аудио»; «не применяется» ≠
«не подтверждено» ≠ «неизменяемое»); ручная правка не перетирается перегенерацией.

## 3. Варианты и решение

| | Что даёт | Цена | Ограничения |
|---|---|---|---|
| **А. Без ИИ** | Dicta + Pealim: членение, лемма, признаки, полная парадигма с ▶ текущей формой | $0 | значение — леммы, а не контекста; сочетания не ловятся |
| **Б. Переводы форм без ИИ** | разовый офлайн-bake: признаки формы → русская форма через морфологию русского (pymorphy3) для всех парадигм | $0 разово | русский вид/управление не выводятся из иврита → спорные клетки = грамматическая подпись, выборочная проверка |
| **В. Gemini-глосса** | при создании таблицы — перевод каждого вхождения в контексте + сочетания; лемму/морфологию задаёт Dicta, ИИ её не переопределяет | оценка: центы–десятки центов на текст ~5.6K слов (замерить) | наследует ошибки ASR-исходника |
| Г. «Спросить ИИ» | разбор одного вхождения по кнопке | доли цента | только по запросу, не канон |

### Решения владельца (2026-10-11)

- **D1.** Гибрид: **А + Б + Gemini (В)**.
- **D2.** Перевод в контексте через Gemini — **опция, по умолчанию выключена**; включение по умолчанию
  пересматривается позже по данным.
- **D3.** Начинать с **Ф0** (замер качества). Это исследование — канон плана в `docs/planning/`.

Почему в ChatGPT было бесплатно: ручная работа в чат-подписке, не API; автоматизировать так в
программе нельзя. Бесплатный аналог для В — ключ AI Studio на free-tier (лимиты; на free-tier Google
может использовать данные для обучения). А и Б от ключа не зависят.

## 4. Архитектура хранения (артефакт не переносится вручную)

- **Слой слов текста** (`token → offsets, prefix, lemma, pos, binyan, feats, paradigm_ref, cell_ref,
  gloss_ctx?, status, provenance`) строится при создании/пересборке таблицы, хранится с карточкой
  в OPFS, синхронизируется и входит в ZIP-экспорт карточки (text-card-v2).
- **Парадигмы + переводы форм** — общий ресурс программы (Pealim уже офлайн; рядом — файл переводов
  форм из Б), не копируется в каждую карточку.
- **Личный словарь** — `word_status` / `word_context` / `review_log` по ключу `lemma-canon`; экран
  «Мой словарь» строится поверх них; экспорт Anki (есть) и, при желании, XLSX по образцу прототипа.
- Поля с provenance: `dicta` / `pealim` / `ru-morph` / `gemini` / `manual`. Ручная правка = lock,
  перегенерация её не перетирает.

## 5. UX (телефон и ПК)

- **Лента слов под видео**, синхронно с караоке: `ששמעתי → что я слышал(а)` — без тапов.
- **Подстрочник** в учебной таблице (переключатель в «Аа»; правило «на телефоне видео + таблица»).
- **Тап по слову** → пауза медиа + морф-карточка в три уровня: форма и её перевод → лемма/корень/биньян
  → матрица «лицо × время» (прокрутка) с переводом каждой формы и ▶ текущей.
- **«+ в словарь»**: единица с контекстом (лемма-значение / трудная форма / сочетание).
- ПК: то же в боковой панели рядом с таблицей.

## 6. Фазы

- **Ф0 — замер (DONE 2026-10-11).** Итог: А пригоден (80% верно / 10% честный пропуск / 9% вводит
  в заблуждение — почти всё омонимы и сочетания, т.е. зона В); стыковка Dicta→Pealim исправлена
  правилами join v3; Б осуществим (98% глагольных парадигм). Подробно — отчёт Ф0. Dicta + Pealim на тексте «Шура» против разметки GPT (второе мнение,
  НЕ эталон). Метрики: выравнивание токенов, членение приставок, лемма, POS, биньян, нахождение
  парадигмы и текущей клетки; разбор расхождений на стратифицированной выборке вручную.
  Выход: числа + список классов ошибок → решение о границах Ф1.
- **Ф1.** Слой слов при создании таблицы (А) + подстрочник + лента под видео.
- **Ф2.** Переводы форм (Б) + матрица в морф-карточке.
- **Ф3.** Gemini-глосса и сочетания (В), опция при создании таблицы (D2).
- **Ф4.** Экран «Мой словарь».

## 7. Правила качества (из канона проекта)

- Dicta-лемма — машинное чтение, provenance виден; ИИ-глосса не подтверждает сама себя
  (независимый оракул) и не перезаписывает более надёжный разбор (R11).
- Тихий пропуск запрещён: у каждого вхождения статус и причина, если разбора нет.
- Dicta bulk: конкурентность ≤2 + circuit-breaker (опыт 503-бана).
- Строки, помеченные как сомнительные (никуд-подозрения, второе мнение Dicta), не подаются как образец.
