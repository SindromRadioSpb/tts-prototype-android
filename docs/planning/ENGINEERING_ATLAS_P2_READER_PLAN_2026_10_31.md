# Инженерный атлас P2 — экран атласа в Читальном зале: план

Дата: 2026-10-31. Спека: `ENGINEERING_FORMULARY_ATLAS_DESIGN_2026_10_30.md` (§5, §8.1, §8.3).
Решение владельца 2026-10-31 утром: разработка идёт по решениям dots, вычитка и подтверждения владельца —
позже; всё помеченное «ждёт подтверждения» таким и показывается.

## Архитектура (решения исполнителя)

- **Данные** — статические JSON по разделам `DATA_DIR/atlas/a97002/` (`index.json`, `sections/<sid>.json`,
  `terms.json`, `assets/<sha>.png`, `print/<sid>.html`), отдаются маршрутом `/data/atlas` из тома сервера —
  тот же приём, что `/data/benyehuda/works`: не в git, публикация = выгрузка на том (решение владельца при
  выкладке). Локально — `data/atlas/…`.
- **Сборка** — `scripts/atlas/build_reader_data.py`: граф раздела → компактный JSON ридера; разделы без
  перевода публикуются сырым текстом с пометкой «нет перевода». Формулы LaTeX → MathML на этапе сборки
  (`scripts/atlas/render-math.cjs`, KaTeX как devDependency): без библиотеки в браузере и без сети.
- **Печать** — `print/<sid>.html` из `render_preview.py` (вариант Б), ссылки на ассеты — `/data/atlas/...`.
- **Экран** — новый модуль `public/js/atlas-reader.js` (`window.AtlasReader.render(container, {id})`):
  оглавление по частям и разделам с состоянием перевода → раздел постранично (оригинал страницы, блоки
  иврит/огласовки/транслит/перевод, формулы с обозначениями, рисунки с подписями и подсветкой, таблицы,
  примеры, опечатки «в книге → предлагаемое исправление · ждёт подтверждения»), переход к странице,
  поиск по ивритскому/русскому тексту раздела, кнопка «Печать раздела». Телефон — вертикальные блоки,
  оригинал по нажатию, без горизонтальной прокрутки.
- **Зал** — пункт «Инженерный атлас 97002» в переключателе корпусов (`atlas:a97002`) и ветка в
  `renderCorpus`; правки `library-ui.js` — минимальные. Строки интерфейса — во всех трёх локалях; SW,
  версия и `?v=` — синхронно при выпуске.

## Задачи

1. Сборка данных ридера + MathML (тесты Python; проверка MathML на формулах пилота).
2. Маршрут `/data/atlas` в `server.js` (тест маршрута).
3. `atlas-reader.js`: оглавление, раздел, страница, поиск, печать (тест разметки в jsdom/linkedom).
4. Подключение в Зал: переключатель корпусов, `renderCorpus`, локали, SW precache, версии.
5. Браузерная проверка: 1440 / 380 RU / 380 HE, без горизонтальной прокрутки; печать раздела в PDF.
6. Импорт поставок dots по мере появления: проверка → граф → данные ридера → PDF печати.

Выкладка в production — отдельное решение владельца (пуш в `main` + выгрузка данных на том).
