## Пошаговая работа
1. Серверный модуль nakdan-client: 1 req/s, таймаут, circuit-breaker по образцу существующего
   Dicta-пути, typed-ошибки.
2. Вызов из import-preview: кнопка «добавить никуд» → preview показывает результат как
   MACHINE_ADDED + disclosure; подтверждение импорта сохраняет никуд с провенансом.
3. Кнопка в Библиотеке для текста без никуда: тот же путь; derived-слой, выверенный не трогается.
4. Кеш: результат при тексте; повторная кнопка → кеш, не второй запрос (инвалидация — при
   изменении тела текста).
5. Smoke `scripts/premium/nakdan-integration-smoke.js` (с мок-сервером Nakdan, живой API — только
   один ручной тест): preview с никудом; NAKDAN_UNAVAILABLE → импорт работает без никуда; повтор →
   кеш; попытка перезаписи выверенного → отвергнута. + существующие гейты.
6. Деплой → прод-верификация: 1 живой preview с никудом; вывод в отчёт.
