Инженер-исполнитель одного слайса. Цель: локальный MCP-сервер субтитров YouTube (готовый OSS,
например kimtaeyoon83/mcp-server-youtube-transcript или живой эквивалент) → Hermes получает
сабы клипов/подкастов с таймстампами.

## Инварианты

выкачивания. Авто-сабы иврита агент ОБЯЗАН помечать «авто-субтитры, качество не гарантировано»
(R11-честность — добавить правило в скилл-дополнение). Privacy-правило H1 (только
URL/поисковые термины наружу). Импорт транскриптов в Библиотеку ЗАПРЕЩЁН (W1 — H2.3).

## Пошаговая работа
1. Установи выбранный сервер на Hermes-хост (node/python окружение хоста; фиксируй версии).
2. Секция stdio в config.yaml (аддитивно) → `docker restart hermes-agent hermes-webui` → новая
   сессия (listChanged:false). ⚠ если сервер на хосте, а агент в контейнере — проверь
   достижимость (запуск команды из контейнера или host-network путь); рабочий вариант зафиксируй
   в README канона.
3. Smoke (транскрипты в `hermes-side/h1.5/ACCEPTANCE_TRANSCRIPTS.md`):
   - A: видео с РУЧНЫМИ ивритскими сабами (например, Easy Hebrew) — сабы с таймстампами получены;
   - B: видео только с АВТО-сабами he — получены + агент выдал пометку качества;
   - C: видео без сабов — типизированный честный отказ, без выдумывания текста.
4. Канон-копия: `hermes-side/h1.5/README.md` (пакет+версия+команда установки, конфиг-фрагмент,
   проверка, откат) + транскрипты.
