## 5. Последовательность исполнения (нормативная)

```
H1.0 → (H1.1 ∥ H1.2 ∥ H1.3) → (H1.4 ∥ H1.5 ∥ H1.6 ∥ H1.7) → H1.8 closure
  → [owner go Д5] → H2 (порядок в 04_HORIZON_2) → H2.7 closure/monitor
                       ∥ обязательный 14-дневный H1-monitoring
  → [owner go Д6-A] → H3 R&D C1 ∥ C2 ∥ C3 ∥ C4 ∥ C5
       (priority/reporting C1→C5; evidence maturity набирается параллельно;
        hard action-gates + H2.7 consent/cost audit сохраняются; production не разрешён)
P11 — вне этой цепи, только по Д3.
```

Одна Codex-сессия = один слайс (11_HANDOFF). Следующий слайс не начинается до closure предыдущего,
кроме явно помеченных параллелизуемых групп (02_PROGRAM_DEPENDENCY §3).
У7 меняет только момент сбора longitudinal evidence: monitoring не заменяет
H1 engineering/owner smoke, consent, W0/W1 или явный Д5 и имеет stop-условия в 08 §3.
