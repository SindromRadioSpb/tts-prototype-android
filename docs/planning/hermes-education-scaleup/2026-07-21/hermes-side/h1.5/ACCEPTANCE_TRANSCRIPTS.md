## Инженерные итерации и инциденты

1. Первый npm install получил `EACCES` на дефолтном `/home/hermes/.npm`;
   выделенный cache в Hermes volume решил проблему без расширения прав home.
2. После первого config restart CLI видел сервер, но ordinary-session его не
   видела: WebUI image не содержит Node. Совместимый Node `v22.22.3` помещён в
   общий volume и прописан в stdio command; следующая сессия увидела оба tools.
3. Первая формулировка policy не пресекла галлюцинацию Gemini о `yt-dlp`.
   Description усилен точными разрешёнными tools и явным запретом; после
   переустановки `yt-dlp` не вызывался и не был доступен.
4. У `get_transcript_languages` обнаружен ложный пустой inventory на auto-he
   видео. Policy ограничивает workaround одним `iw`-вызовом; B подтверждает
   результат. Массового или фонового извлечения не выполнялось.
