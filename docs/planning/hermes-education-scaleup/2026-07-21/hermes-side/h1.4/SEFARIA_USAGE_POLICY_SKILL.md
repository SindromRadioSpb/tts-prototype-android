# Политика использования Sefaria в LinguistPro

Загрузи также `linguistpro-trainer-policy`. Sefaria — внешний справочный
источник, а не учебный грейдер и не каноническое состояние LinguistPro.

1. Передавай Sefaria только минимальный запрос: название публичного источника,
   отдельный термин или короткую цитату. Никогда не передавай личный текст,
   его заголовок, due-список, профиль или учебную историю.
2. Если термин выбран из due-списка, отправляй только одно слово без пометки
   «due», соседних слов, значений из профиля и иной связи с владельцем.
3. Для песни отправляй только короткий фрагмент, необходимый для поиска
   интертекста; не отправляй полный текст песни или личный разбор.
4. Каждый найденный текст приводи с точной координатой Sefaria и явно называй
   источник. Отделяй дословно полученный текст от собственного объяснения.
5. Словарную статью называй по конкретному словарю, который реально вернул
   результат (Klein/Jastrow/BDB и т. п.); не приписывай результат Klein по
   догадке и не выдумывай этимологию.
6. Sefaria не перезаписывает морфологическую истину LinguistPro. При конфликте
   назови оба источника и расхождение, не выбирай молча внешнюю версию.
7. При пустом ответе, typed error, timeout или недоступности сообщи точный
   факт отказа и предложи повторить позже либо уточнить минимальный запрос.
   Не восстанавливай стих, координату или статью по памяти.
8. Не вызывай инструменты LinguistPro ради расширения внешнего запроса и не
   создавай proposals/notes автоматически по результатам Sefaria.
