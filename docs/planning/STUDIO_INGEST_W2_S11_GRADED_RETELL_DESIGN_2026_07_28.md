## 1. Решения владельца (ЗАФИКСИРОВАНО 2026-07-28)

1. **Уровень — гибрид «метка правит, данные меряют»:** генерация промтом с меткой уровня
   (реюз набора A1/A2/B1/B2 из lessonBuilder) + частотное ограничение; после генерации —
   детерминированный расчёт «знакомо до/после» по `word_status` с КАНОН-определением
   `corpus-vocab.js` (CFG.KNOWN_STATES + classifyZone; четвёртого определения уровня НЕ вводим).
   Пустой профиль → только метка, без цифр (честно). Явный список лемм в промте — НЕ
   механизм (замер: соблюдение 60–75%, thinking ×8–10, искажения смысла).
2. **Транспорт — серверный эндпоинт класса translate-table:** BYOK per-request в теле,
   sha256-кэш, готовые валидация ключа/классификация ошибок/разбор 429.
3. **Кнопка — обе точки, один обработчик:** Студия (рядом с «Импорт» у поля ввода) +
   шорткат в превью диалога «Импорт».
4. **Сохранение — отдельный текст + `derivedFrom` в паспорте** (без миграции схемы);
   принудительный create (сброс `baseTextId` — обезвреживание мины UPDATE-поверх-оригинала);
   бейдж «Упрощено ИИ · уровень X» в панели «Происхождение».
5. **Анти-скоуп v1 подтверждён:** сегмент-караоке по ОРИГИНАЛЬНОЙ записи у пересказа НЕТ
   (пересказ — другой текст, соответствия его предложений отрезкам исходного аудио не
   существует — R11); word-караоке TTS-озвучки самого пересказа (playTTS → GCP TTS →
   studio-karaoke) работает из коробки, как для любого текста Студии; чанк-пересказа НЕТ
   (вход до ~100К символов
   ≈ 50К токенов одним вызовом, больше — честная ошибка); ре-ретрай «упростить ещё» — не v1.
6. **Смета R16 — в лейбле кнопки** (паттерн аудио-импорта), без confirm-модала (цена
   $0.01–0.03); без ключа — кнопка disabled с честной причиной.
7. **Провайдер:** пересказ независим от селектора провайдера (всегда Gemini BYOK) +
   ненавязчивая подсказка «для караоке/чанков включите Gemini» при медиа-импорте с
   провайдером ≠ gemini (мягкое закрытие S4-дыры google-free).

## 2. Почему дизайн такой (главные факты замеров)

| Факт | Следствие в дизайне |
|---|---|
| 0 выдуманных форм на ~150 вручную размеченных предложениях (10 выходов, включая иврит XIX в. и устную речь) | R1-риск ниже ожидаемого; гейт остаётся как страховка: OOV-скан офлайн-резолвером в live-смоуке + ручная выборка |
| Список разрешённых лемм: соблюдение 60–75%, thinking ×8–10 (15.7К ток.), 3 искажения смысла, NEW-декларация = словоформы | Data-driven уровень работает только как ИЗМЕРЕНИЕ после генерации, не как ограничение в промте |
| Метка уровня и частотное ограничение: чистый иврит, верный смысл, thinking 1.4–2.1К | Промт = метка (A1–B2) + «только частотная лексика, ≤5% редких» + R1-запрет выдумывать |
| «⅓ длины» → фактически 6–22%; «60–80 предложений» → 71 | Длина задаётся ЧИСЛОМ предложений (вычисляется из объёма источника), не долей |
| 48 514 ток. входа (≈3 ч подкаста) → один вызов, STOP, 26 с, $0.027; покрыты начало/середина/конец | Чанк-пересказ не нужен; лимит входа 100К символов с честной ошибкой; выход ≤80 строк → плоский путь таблицы (guard 250) не задевается |
| Coverage: 22.8К ток. за 51 мс (словарь 1.7 с разово) | «Знакомо до/после» считается на лету без прогресс-бара |
| Free tier прод-модели: 20 req/день; 2.5-flash для новых ключей закрыт | UX обязан переиспользовать классификацию 429/квоты (`gemini-error.js`); ошибки конкретные, не generic |

## 3. Архитектура и поток данных

Пересказ — «опция выхода» над любым текстом в поле ввода Студии. Он НЕ подменяет
оригинал (R11): результат приземляется в композер как НОВЫЙ derived-текст со своим
паспортом, дальше едет штатным конвейером «Собрать таблицу → Сохранить» с принудительным
create. Ни одного нового хранилища (CLG §5): текст → карточка Библиотеки, провенанс →
существующий паспорт `source`, лексика — штатные ②-заметки.

```
Студия: текст в #inputText (импортированный или вставленный)
  → кнопка «Упростить до моего уровня (≈$X)» [Студия у «Импорт» | превью Импорта]
  → мини-модал #v3RetellModal: уровень [A1|A2|B1|B2] (дефолт: последний, иначе B1)
      + «знакомо сейчас: ~N% (зона)» (если профиль непустой) + смета + [Упростить]
  → POST /api/retell {text, level, geminiApiKey}    (сервер: кэш → Gemini → кэш)
  → клиент: coverage ДО/ПОСЛЕ (канон-CFG) → показ «~N% → ~M% знакомо»
  → подтверждение «Заменить текст в поле пересказом?» (оригинал не сохранён → предупредить)
  → композер: value = пересказ + dispatch('input')
      + window.v3LastImportMeta = retell-паспорт (kind:"retell", derivedFrom, level, coverage)
      + v3SessionSet({textId:null, baseTextId:null, mode:"draft"})   ← мина обезврежена
  → штатно: «Собрать таблицу» → v3AttachImportSource (копирует retell-подобъект)
      → сохранение НОВОЙ карточки → панель «Происхождение»: «Упрощено ИИ · уровень X»
```

### Инвентарь переиспользования (снято с живого кода)
- `/api/translate-table` (server.js:6336) — образец эндпоинта: BYOK-валидация
  (`isPlausibleGeminiKey`), sha256-кэш `promptId||текст`, классификация ошибок
  (`ingest/geminiError.js`), разбор 429 с resetAt. Копируем класс, не трогаем сам эндпоинт.
- `corpus-vocab.js` — CFG.KNOWN_STATES + classifyZone = единственное определение
  «знакомо/зона» (НЕ меняется; smoke:corpus-vocab цел).
- Браузерный лемма-мост для произвольного текста: `ReaderMorph.tokenize` + резолв через
  `ensureEngine`/`resolveCore` (движок ②-заметок, уже в Студии) + `LemmaCanon.canonKey`
  + `localDb.getKnownWordStates()`.
- Паспорт/панель: `v3LastImportMeta` → `v3AttachImportSource` → `v3TextMetaRenderProvenance`
  (словари KIND/METHOD расширяемы; приём `source_meta_json.corpus` — прецедент под-объекта).
- Смета: паттерн лейбла кнопки аудио-импорта (`studio-import.js:285-294`).
- TTS/word-караоке пересказа: `playTTS()` работает с любым текстом поля — НОЛЬ изменений.
- `renderTable`/`reader-core` — НОЛЬ изменений (гейт `smoke:reader-parity`).

## 4. Контракты (точные схемы)

### 4.1 `ingest/retell.js` (новый серверный pure-модуль + тесты)
```js
LEVELS = ["A1","A2","B1","B2"]            // единый источник; UI-select строится из него же
                                          // (config-string-match: значение селекта == значение промта по построению)
RETELL_PROMPT_ID = "retell-he-v1"
targetSentences(text) → clamp(8, 80, round(estimateSentences(text)/3))
buildRetellPrompt(text, level) → строка    // метка уровня + частотное ограничение +
                                          // числовой диапазон предложений [t..t+20%] +
                                          // R1-запрет («אל תמציא מילים…») + «без никуда,
                                          // предложение на строке» + запрет добавлять факты
validateRetellInput({text, level}) → {ok}|{error}   // text ≤ 100_000 chars → RETELL_TOO_LONG
```
Числа/формулировки промта — из замера (`docs/research/studio-ingest-graded-retell/2026-07-28/`),
комментарии цитируют README замера, не память сессии (урок S12.1, R9).

### 4.2 `POST /api/ingest/retell` (ingest/routes.js, класс translate-table)

> Уточнение при написании плана: эндпоинт живёт в `ingest/routes.js` (не server.js) —
> там уже есть limiter 10/мин, `isPlausibleGeminiKey`, `classifyGeminiError` и
> `deps.geminiCacheDir`; серверный рост меньше, контракт тот же.
- Вход: `{ text, level, geminiApiKey }`. Валидация: ключ (401 `GEMINI_KEY_REQUIRED` /
  400 `GEMINI_KEY_INVALID` — `isPlausibleGeminiKey`), `level ∈ LEVELS` (400 `BAD_LEVEL`),
  `validateRetellInput` (400 `RETELL_TOO_LONG` / `RETELL_EMPTY`).
- Кэш: `sha256(RETELL_PROMPT_ID + "|" + level + "||" + text.trim())` → `geminiCacheDir`
  (уровень входит в ключ — разные уровни = разные записи). Хит → `{retell, fromCache:true}`.
- Вызов: `gemini-flash-latest`, temperature 0, maxOutputTokens 16384 (thinking входит в
  бюджет — замер M1: обрезка на 8192).
- Ответ: `{ retell, promptId, model, fromCache, cacheKey }`; ошибки Gemini →
  `classifyGeminiError` (429 → retryAfterSec/resetAt как в translate-table).
- Rate-limiter: `makeRateLimiter` 10/мин (как ingest-роуты; у translate-table лимитера нет —
  известный пробел, здесь не повторяем).

## 5. Честность (R11/R9) — правила целиком

1. Оригинал НИКОГДА не изменяется и не подменяется; пересказ = отдельная карточка
   с принудительным create; «Сохранить» после пересказа не может попасть в UPDATE оригинала.
2. Пересказ = derived, не asserted: бейдж + метод + модель + дата в провенансе; пересказ
   никогда не выдаётся за проверенный текст.
3. Сегмент-тайминг к оригинальной записи у пересказа отсутствует по построению:
   retell-паспорт без audio/captions; `v3AttachAudioTiming` штатно гасит медиа-сцену
   (ветка «паспорта нет»); защёлку `timingDropReason` оригинала не трогаем (паспорт не
   разделяется). Word-караоке TTS-озвучки пересказа — штатное, вне этого правила.
4. Coverage-цифры — «оценка с устройства» (формулировка next-text); пустой/тонкий профиль →
   цифры скрыты, не сфабрикованы («0%» запрещён — урок silent-empty).
5. R1-гейт: live-смоук прогоняет OOV-скан выхода офлайн-резолвером + фиксирует кандидатов;
   выдуманная форма = красный гейт (норма: 0, как в замере).
6. Уровень в промте и уровень в UI — один литерал из `LEVELS` (по построению).

## 6. Обработка ошибок

| Ситуация | Поведение |
|---|---|
| Нет Gemini-ключа | Кнопка disabled + причина (деградация без LLM осмысленная, R16) |
| Ключ невалиден / квота / перегрузка | `classifyGeminiError` → конкретные премиум-сообщения (как v3.11.243) + retryAfterSec при 429 |
| Текст > 100К символов | 400 `RETELL_TOO_LONG` → честная ошибка «слишком длинный для пересказа v1» |
| Пустой/неивритский вход | `RETELL_EMPTY` / пересказ любого языка в иврит — штатно (промт не требует иврит-входа) |
| Обрыв/повтор | Серверный кэш: повторный клик бесплатно возвращает готовый пересказ |
| Coverage-движок недоступен (нет словаря/профиля) | Цифры скрыты; пересказ работает (метка правит) |

## 9. Риски

| Риск | Контрмера |
|---|---|
| Free-tier квота 20/день у владельца — пересказ «съедает» бюджет таблиц | Смета+кэш; классифицированное 429-сообщение с resetAt; кэш-повтор бесплатен |
