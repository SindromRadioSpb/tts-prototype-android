# SCENE_BIBLE — «Мир выборов в Израиле» (пакет 0.2.0)

Координаты — логические пиксели относительно точки локации; длительности — мс.

## Путешествие (системное, из этапа Студии)

| Этап Студии | Локация | Освещение | Что происходит |
|---|---|---|---|
| `add` — «Этап 1 из 4» | Штаб кампании (x 120): пустой синий баннер, стена пустых плакатов, мегафон | по часам (день 7–17, закат 17–19, ночь) | Тимсах стоит у штаба, моргает. |
| `table`/`correct` | Типография бюллетеней (x 520): станок в окне, стопки бюллетеней | по часам | Переход: Тимсах идёт (1.2–3.2 с), камера следует. |
| `save` | Избирательный участок (x 920): школа, флаг без эмблемы, лента очереди, урна | по часам | По прибытии — сюжет **«Бюллетень в урну»**. |
| `learn` — «Готово» | Ночь подсчёта (x 1320): студия с экранами (абстрактные полосы) | **всегда ночь** | Переход в ночь: звёзды, луна, горящие окна. |

Reduced motion / пауза / скрытая вкладка: переход мгновенный, один кадр.

## Сцены

### ballot-drop — «Бюллетень в урну» (story, `arrive.polling`, 2800 мс)
0 idle → 300 blink → 500 hold (конверт в руке) → 1300 конверт летит по дуге к прорези урны → 1950 урна
вспыхивает, Тимсах прыгает → 2450 покой. Статичная замена: Тимсах моргнул, урна с бликом.
Проверка: `journey.js` кадр 4.

### stroll — «Прогулка по улице» (ambient, живой режим, 3000 мс)
Тимсах идёт вправо под флажками, моргает, возвращается (осознанное отражение). Не тратит бюджет
реакций, не стартует при вводе/диалоге, ждёт 22 с после любой сцены.

### tap — реакция на касание (без манифеста, движок)
Касание Тимсаха в уличной полосе → прыжок 420 мс + пузырь с репликой (по кругу), 2.6 с.
Пузырь — сбоку от головы, внутри полосы, не над панелями.

## Бюджет и приоритеты

story > auto > ambient; manual — по запросу. Авто-реакции ≤ 3 с, перерыв 120 с, ≤ 3 за сессию.
Нет очереди поздних событий. Во время ввода текста и открытых диалогов авто/фон не стартуют.
