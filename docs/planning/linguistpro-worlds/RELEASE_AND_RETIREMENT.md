# RELEASE_AND_RETIREMENT — «Мир выборов в Израиле»

## Включение

- С 3.11.710 (решение владельца 2026-09-30) мир выборов включён **по умолчанию** в живом режиме на
  всех трёх поверхностях. Classic — вручную: Студия → «Разделы и настройки» → «Оформление» →
  LinguistPro Classic; выбор хранится в `localStorage.lp_world_v1` как `{"id":"classic"}`.
- Выбор не зависит от языка, чтения, имени, места или взглядов — одинаков для всех.

## Отключение пользователем

- «Оформление» → LinguistPro Classic: слоты скрываются, canvas удаляются, цикл останавливается,
  переменные скина убираются, запоминается Classic (проверка B3 в `verify.js`).
- Пауза мира — кнопка на сцене (запоминается). Системное «уменьшить движение» — один кадр.
- Аварийно: открыть `/?world=off` — мир выключается, запоминается Classic (F1).

## Откат и снятие

| Ситуация | Действие | Когда действует |
|---|---|---|
| Сломан пакет | Движок сам падает в Classic (E1/E3) | сразу |
| Снять весь мир | `REGISTRY["israel-elections-2026"].retired = true` в `world-engine.js` + релиз (все без явного выбора → Classic) | после обновления SW у клиента |
| Вернуть Classic по умолчанию | `DEFAULT_WORLD` в `world-engine.js` и условие в `world-boot.js` | после обновления |
| Снять одну сцену | `expires: "YYYY-MM-DD"` в сцене + новая версия пакета | по локальной дате / после обновления |
| Заменить арт | новая версия пакета (`version` + `REGISTRY.pack`) | после обновления; старые PNG вытесняются runtime-кэшем |
| Откатить релиз | revert коммита в `main` → деплой | после обновления SW |

Честное ограничение: офлайн-клиент со старой оболочкой мгновенно не обновить; снятие действует при
следующем успешном обновлении.

## После выборов (27.10.2026)

- Не выключать мир у пользователей внезапно и не сбрасывать выбор.
- До 28.10.2026: пересмотр досье (FACTS_AND_MEMES), без автоматических сцен по результатам.
- Архивный режим (следующая версия пакета): «ночь подсчёта» → нейтральная сцена «после выборов»
  (улица без агитационных щитов), все сюжеты про «накануне» получают `expires`.
- Даты выборов в клиентском коде нет (кроме `expires`, который задаёт редакция пакета).

## Выпуск

- Ветка `feat/linguistpro-worlds-elections-2026` → `main` (push в `main` = деплой Coolify).
- Перед деплоем: диск прода (O-012) и при необходимости `docker builder prune` (разрешено владельцем).
- Lockstep: `CACHE_VERSION` = `APP_VERSION` = футер Зала; `world-engine.js`, `world-render.js`,
  `world-skin.css` — в `PRECACHE_URLS` с `?v=` релиза; локали `?v=278`.
- После деплоя: проверка живой версии в чистом профиле (`verify.js` с `AUDIT_BASE=https://linguistpro.kolosei.com`).
