# ENGINE_CONTRACT — LinguistPro World Engine v2

Код: `public/js/world-engine.js` (ядро + DOM), `public/js/world-render.js` (canvas, грузится по
требованию), `public/css/world-skin.css` (маппинг скина). Тесты: `tests/worldEngine.test.js`.

## 1. Пакет мира (`/worlds/<id>/`)

Только данные и пиксельные изображения: `manifest.json` (`schema: lp-world/2`), `atlas.json`
(`lp-world-atlas/1`, размеры/кадры/якоря/sha256), `*.png` (RGBA). Нет JS, HTML, CSS, SVG, внешних URL.
Совместимость: `engine: {min, max}` ⊇ 2. Версия пакета закреплена в `REGISTRY` движка
(`pack`), несовпадение → Classic.

Валидатор (`core.validatePack`) отвергает: незнакомые токены скина; цвета не `#rrggbb`; листы/кадры,
которых нет в атласе; тексты с `<`/`>` или без ru/en/he; слоты вне `SLOTS`; триггеры вне
`manual|ambient|tap|studio.table-ready|arrive.<loc>`; реакции длиннее 3 с (ручные ≤ 8 с); фазы
локаций вне `add|correct|table|save|learn`; актёров без `fictional: true` или ссылки на карточку.

## 2. Точки размещения (объявляет приложение)

Оболочка грузит только `world-boot.js`: он поднимает движок, если на устройстве выбран мир, открыт
«Оформление» или адрес содержит `?world=off`.

| Слот | Где | Что рисует |
|---|---|---|
| `studio-stage` | первый ребёнок `.classic-shell-head` | full-bleed canvas от верха страницы до уличной полосы; кнопка паузы; пузырь реплики |
| `page-backdrop` | сразу после `app-nav.js` в `<body>` | fixed canvas за страницей (`z-index:-1`): небо, холмы, город |

Мир не трогает другие элементы DOM. Скин (`world-skin.css`) действует только под `html[data-world]`;
учебная таблица, шрифты, размеры, фокус и 44 px — вне его области (тест).

## 3. Семантические хуки (без содержимого)

| Хук | Источник | Что читается |
|---|---|---|
| Этап Студии → локация | `MutationObserver` на `#classicNextStep[data-phase]` | только значение фазы |
| Таблица готова | `table-job-progress` (существующее событие) | только `detail.state === "done"` |
| Занятость | `document.activeElement`, открытые `dialog`/`aria-modal` | только факт ввода/диалога |

Текст материалов, переводы, имена файлов, аудио и база ученика в мир не попадают.

## 4. Движение и бюджет

- Тикер ~30 fps только при: мир включён, вкладка видима, не пауза, нет reduced motion.
  Иначе — один неподвижный кадр по событию (смена этапа, ресайз, прокрутка).
- Виды сцен: `story` (итог собственного шага пользователя, напр. прибытие на участок) — без
  бюджета; `auto` (спонтанные реакции) — ≤ 3 с, перерыв 120 с, ≤ 3 за сессию; `ambient` (живой
  режим) — не тратит бюджет, уступает всему; `manual` (превью/галерея). Поздние события не копятся.
- Сюжет прерывает фоновую прогулку; после любой сцены фон ждёт полный интервал (22 с).
- Пауза мира — видимая кнопка 44 px, `aria-pressed`, запоминается в выборе.

## 5. Приватность

Выбор мира — `localStorage.lp_world_v1 = {id, mode, paused}`; нигде не отправляется. Движок делает
только `fetch` манифеста и атласа своего пакета и загружает его PNG; рендерер не делает сетевых
запросов и не читает хранилище (тест). Product Pulse/телеметрия не читает выбор мира (тест).
Инфраструктурные логи сервера/CDN видят запросы `/worlds/...` — это известное ограничение (не
заявляем абсолютную анонимность).

## 6. Кэш, офлайн, откат

- `world-boot.js`, `world-engine.js`, `world-render.js`, `world-skin.css` — в `PRECACHE_URLS` (код, байты при установке SW).
- Арт мира **не** в precache: загружается при включении, попадает в runtime-кэш SW (SWR) → офлайн после
  первого включения. Грузятся только листы текущего освещения.
- Сбой загрузки/валидации → Classic, без ошибки приложения. `?world=off` — аварийный выход с забыванием выбора.
- Снятие мира/сюжета: `REGISTRY[id].retired = true` или `expires` у сцены → действует после
  следующего успешного обновления; офлайн-клиент мгновенно не обновить.
