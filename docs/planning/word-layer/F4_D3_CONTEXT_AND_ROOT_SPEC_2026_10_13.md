## 1. «Слово в новых предложениях» (перенос в новый контекст)
**Задача:** проверить, что слово узнаётся **не там, где его учили**. Обычная тренировка Зала уже вращает предложения
банка контекстов, но не ставит целью новое место: при пустом банке она подаёт то же предложение-якорь.

- Вход: «Мой словарь» → над списком «В новых предложениях (N)» по текущему виду (отмеченные слова) →
  `library.html?review=set&from=dictionary` с режимом `newctx` в той же передаче (`dict.trainSet_v1`).
- Сборка задания на каждое слово: место, где слово учили, = якорь расписания (`srs_text_key` + `srs_order_index`).
  Берём **другое** предложение: сначала из банка контекстов (другой текст важнее другой строки того же текста),
  иначе ищем по моим текстам тем же сканом и той же проверкой личности, что лестница R2 (`_r2VerifyCandidate`:
  токен формы → пропуск → `resolveWordLight` → `lemmaKey` = ключ слова; неогласованное — только «точно»).
  Найденное место пополняет банк (`insertWordContexts`).
- Слово без другого места **не подменяется** якорем: оно пропускается, после сборки — честная строка
  «Для N слов в ваших текстах пока нет другого места».
- Ответы — обычные повторения (FSRS, `review_log`): узнавание в новом контексте и есть повторение; отдельной памяти
  нет (R11). Заголовок сессии «Слово в новых предложениях», у задания — название текста.

## 2. «Корень как гнездо»
**Задача:** учить слова корня вместе, опираясь на уже знакомые (концепция: «известные слова корня как опора для
новых»). Сейчас в статье — список «Слова от этого корня» без статусов.

- Статья → «Слова от этого корня»: каждое слово — цветом моего статуса (живой статус, тот же канонический ключ
  `pid:N`, что у Зала), значение, тап открывает статью слова (если оно в словаре) или карточку.
- Строка «Опора: вы знаете …» — слова гнезда со статусом «почти знаю»/«знаю».
- **«Тренировать гнездо (N)»** (от 3 слов с переводом): раунд в статье — «значение → какое это слово корня?» и
  «слово → какое значение?», варианты только из этого же гнезда (различение родственников — то, что путает).
  Это практика без записи в расписание (как тренировка форм не трогает FSRS леммы); итог — «верно m из n».
- **«Учить гнездо в Зале (N)»** — обычное «Учить эти» по незнакомым словам гнезда (знакомые — опора, не в наборе);
  неразмеченные — тот же выбор «Отметить как „незнакомо“ и учить».

## Разбор по ролям
- **R2:** перенос в новый контекст — отдельная цель обучения (decontextualization); гнездо — морфологическое
  осознание (корень + шаблон), различение родственников полезнее, чем их разнесение по сессиям.
- **R11:** одна память слова; новое место проходит тот же гейт личности, что любое предложение тренировки;
  практика гнезда не пишет в расписание.
- **R10/R1:** родственники — только из словаря Pealim (`rootIndex`), значения — словарные; без «похожих» слов.
- **R4:** кнопки рядом с «Учить эти»; гнездо — в статье, где пользователь уже смотрит на слово; 380 px, RTL.
- **Риск:** у части слов нет второго места — честный счёт, без подмены; поиск по текстам ограничен бюджетом,
  как лестница R2.

  гнезда, без записи в расписание), «Учить гнездо в Зале» с выбором для неразмеченных прямо в статье.

  гнезда, задание «в новых предложениях» пришло из другого текста, а не из места, где слово учили. Смоук берёт
