# Ф4 · Д2 — учебные режимы «Моего словаря»

Дата: 2026-10-12. Основание: [F4_MY_DICTIONARY_CONCEPT_2026_10_12.md](F4_MY_DICTIONARY_CONCEPT_2026_10_12.md) §2.3, порядок владельца
(Д1 список + статья → **Д2 учебные режимы** → XLSX). Старт по команде владельца 2026-10-12.

## Д2.1 «Учить эти» — РЕАЛИЗОВАНО (3.11.750)

- В словаре над списком — «Учить эти (N)»: текущий отфильтрованный и отсортированный набор (без «не учить» и
  неподтверждённых записей) передаётся в Зал (`localStorage dict.trainSet_v1`, срок 10 мин) и открывается
  `library.html?review=set&from=dictionary`.
- Зал: `startSetTraining(keys)` — **та же** кросс-текстовая тренировка, что «Повторение» и раздел плана наставника:
  `localDb.getWordsWithSource(keys)` (новое: строки расписания по списку ключей, любое состояние, «не учить»
  исключено) → `_buildDueSourcedItems` (банк контекстов → сохранённое место → лестница R2 с поиском предложения
  и записью места → честное «только слово» для `pid:N`) → `_launchTrainSession`. Порядок словаря сохраняется,
  размер сессии — из настроек тренировки. Ответы — обычные повторения (FSRS, `review_log`).
- Роли: R2 (учить своими словами в своих предложениях, а не списком), R11 (одна точка записи памяти — та же
  тренировка; никакой параллельной системы оценок), R4 (одна кнопка, пояснение рядом).
- Гейт: `dictionary-smoke` D6 — «Учить эти (4)» → тренировка «Учить из словаря», 4 упражнения, первое — пропуск
  слова в своём предложении.

## Д2.2 Тренировка форм — РЕАЛИЗОВАНО (3.11.751), вход из статьи

Сделано: кнопка «Тренировать формы» под таблицей в статье слова. Раунд из 8 заданий «группа · лицо — русская
форма» → выбор из 4 форм ЭТОЙ ЖЕ таблицы (сперва другие лица того же времени — тренируется различение, не
угадывание слова). Порядок колоды: встреченные в моих текстах → их время/группа → остальные → освежить усвоенные
(давно виденные первыми). Клетки-омографы (תִּכְתֹּב = «ты (м)» и «она») засчитываются обе, вторая никогда не
дистрактор. Ошибка показывает правильную форму с транслитом и ▶. Память по клетке — IndexedDB `lp-form-drill`
(лемма → слот → seen/right/streak/last), FSRS леммы не трогается; «уверенно» = 2 верных подряд, отметка ✓ в
клетке таблицы и строка «Уверенно: m из t форм». Ядро `public/js/form-drill-core.js` (тесты
`tests/formDrillCore.test.js`), гейт D7 в `scripts/premium/dictionary-smoke.js` (ошибка → верная форма, 7/8 и
8/8, отметки, 380 px HE). Не сделано: ввод с клавиатуры / плитки букв и набор из словаря по фильтру биньяна —
после Д2.3, если понадобится.

Исходная постановка:

Задание по таблице спряжения/склонения слова из словаря: «мы · прошедшее — ?» → ответ (плитки букв / ввод),
проверка строго по клетке Pealim (R1: только реальные формы), начиная с форм, **встреченных в моих текстах**
(подсветка таблицы Д1), затем соседние клетки. Своя память по клетке (не трогает FSRS леммы, R11), итог — какие
клетки уверенно. Вход: статья слова («Тренировать формы») и набор из словаря (глаголы, фильтр биньяна).

## Д2.2+ зрелость тренировки форм — РЕАЛИЗОВАНО (3.11.752), проект 2026-10-13 (команда владельца)

**1. Способ ответа** (переключатель в панели тренировки, запоминается на устройстве `dict.drillMode_v1`):
«Выбор» (4 формы, как было) · «Плитки» (буквы формы вперемешку + 2–3 буквы-ловушки из соседних форм того же
времени; тап — в ответ, тап по букве ответа — вернуть) · «Ввод» (поле RTL). Проверка ввода/плиток — по буквам
без огласовки, конечные буквы приравнены (ם=מ). Полное написание принимается строго по правилу: лишняя ו только
после буквы с холамом/кубуцем или при удвоении ו; лишняя י только после хирика или при удвоении י (דיברתי к
דִּבַּרְתִּי — да; произвольная вставка — нет). Совпадение с ДРУГОЙ клеткой таблицы называется: «это форма „мы ·
прошедшее“» — ошибка объясняется, а не просто «неверно». Набор в русской или латинской раскладке на ивритских
клавишах переводится по клавишам (е→א, с→ב …) с пометкой. Память клетки: те же seen/right/streak; верные ответы
вводом/плитками считаются отдельно (`prod`) — «уверенно» не меняет смысла (2 верных подряд в любом режиме).

**2. Тренировка по набору из словаря.** Над списком рядом с «Учить эти» — «Тренировать формы (N)»: слова
текущего вида с подтверждённой таблицей Pealim (фильтры «глагол» + биньян уже есть). Раунд из 10 заданий по кругу
между словами: сперва слова с невыученными формами из моих текстов, затем по порядку списка; в каждом слове —
порядок Д2.2. Варианты/плитки — из таблицы ЭТОГО слова. Память — та же по клетке слова (статья и набор видят одни
✓). Панель открывается в области статьи (на телефоне — поверх списка).

**Разбор по ролям до кода.** R1: принимаем только формы клеток Pealim; полное написание — по правилу огласовки, не
«похоже». R2: производство (ввод/плитки) сильнее узнавания — поэтому отдельный счёт `prod`; объяснение «это другая
клетка» учит различению. R4: плитки — для телефона без ивритской клавиатуры; 380 px, RTL, крупные цели 44 px.
R10: ловушки из той же группы, иначе плитки угадываются по набору букв. R11: FSRS леммы не трогается, одна память
клеток на статью и набор. Риск: огласовка не проверяется при вводе — честно говорим «по буквам верно; огласовка: …».

## Д2.3 «Прогресс словаря» — РЕАЛИЗОВАНО (3.11.752), проект 2026-10-13

Вкладка «Прогресс» рядом со «Словами». Только «мои слова» (правило Д1).
- **Сейчас:** полоса по статусам + числа.
- **Как менялось:** статус на момент T восстанавливается из журнала отметок (`review_log kind='mark'`, статус в
  meta — та же истина, что у синхронизации). Таблица «сейчас / Δ за неделю / Δ за месяц» по статусам; строка
  «за неделю: стало „знаю“ +a, поднялись по шкале b, новых слов c». Слово без отметок считается в своём статусе с
  даты добавления (история неизвестна — так и пишем в сноске). 8 недель повторений: число и доля срывов.
- **Слабые места — память слов:** часть речи и биньян по доле срывов (оценка ≤1 из повторений `review`) при
  минимуме выборки (≥3 слова, ≥8 повторений); показываются группы заметно хуже среднего (×1.2 и ≥3 срыва) рядом со
  средним. «Тренировать это» → «Учить эти» по словам группы (самые слабые первыми); «Показать слова» → фильтр.
- **Слабые места — формы:** по памяти клеток (Д2.2): биньян и время с долей ошибок при ≥6 ответах →
  «Тренировать формы» по набору этого биньяна с упором на это время.

## XLSX «Мой словарь» — РЕАЛИЗОВАНО (3.11.752), проект 2026-10-13

Кнопка «Скачать XLSX (N)» над списком: текущий вид (фильтры + сортировка). Листы по образцу прототипа владельца
(«Учебный навигатор»): **Словарь** (слово, лемма, значение, мой перевод, часть речи, биньян, корень, статус, сила
памяти, следующее повторение, повторений, срывов, встреч, добавлено, последний раз, формы уверенно m/t, ключ) ·
**Формы** (лемма, время/группа, лицо, форма, транслит, перевод формы, встречена у меня, тренировка верно/всего,
уверенно) · **Прогресс** (сводка Д2.3). Шапка закреплена, колонки иврита справа-налево. Без сторонних сервисов:
файл собирается в браузере (свой писатель OOXML + JSZip, уже в precache).

## Д2.3 Прогресс словаря — исходная постановка

Сколько слов в каждом статусе и как менялось (неделя/месяц), слабые места по части речи/биньяну (доля срывов) с
кнопкой «тренировать это» (фильтр словаря + «Учить эти»).
