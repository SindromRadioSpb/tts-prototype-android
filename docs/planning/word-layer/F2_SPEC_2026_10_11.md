# Ф2 · Перевод каждой формы + матрица «лицо × время» — спецификация

Дата: 2026-10-11. Канон: [../WORD_LAYER_RESEARCH_AND_PLAN_2026_10_11.md](../WORD_LAYER_RESEARCH_AND_PLAN_2026_10_11.md).
Основание: [F0](F0_REPORT_2026_10_11.md) §3 (вариант Б), [F1](F1_SPEC_2026_10_11.md) (подстрочник и лента).

## Что меняется для ученика

1. **Подстрочник и лента** показывают перевод встретившейся формы, а не начальную форму:
   `כָּתְבָה` → «она писала», `שֶׁעָשִׂיתִי` → «что я делал(а)», `אֲחוֹתָם` → «их сестра»,
   `תָּבִין` → «ты будешь понимать / она будет понимать» (омографичные клетки — обе, как подпись Ф1).
2. **Морф-карточка**: строка «в тексте: она писала»; у глагола — матрица «лицо × время»
   (строки — лица, столбцы — прошедшее / будущее / повелительное), над ней полоса настоящего
   (род × число) и инфинитив. В каждой клетке — форма, транслит, перевод; текущая форма отмечена ▶.
   У существительных и прилагательных — перевод в каждой клетке существующей сетки.
3. Где перевода формы нет — остаётся подпись Ф1 (смысл леммы + «она, прош.»). Тихой подмены нет.

## Данные (вариант Б, без ИИ)

- Сборка: `scripts/word-layer/f2-ru-forms-bake.py` (pymorphy3 — только при сборке) из первого значения
  Pealim, тем же правилом, что `WordGloss.shortGloss`. Заменяет зонд `f0-ru-forms-probe.py`.
- Выход: `public/data/inflection/ru-forms-v1.json.gz` — **201 КБ** (gz), ключ `pealim_id`. Внутри
  только словоформы («писала», «пишет»); фразу собирает `public/js/ru-forms.js` по клетке. Полные
  фразы занимали бы 750 КБ gz / 7 МБ в памяти — для телефона дорого.
- Два независимых пути: сборка строит **полную фразу каждой клетки напрямую** (оракул), JS собирает
  её из компактного файла. Паритет на всех 218 122 клетках — 0 расхождений; закреплённый срез —
  `tests/fixtures/word-layer/ru-forms-oracle-sample.json` (тест `tests/ruForms.test.js`).
- Pealim-датасет не меняется (нет переимпорта OPFS у пользователей); общий ресурс, не копия в карточку.

Правила формы (каждое — из найденного дефекта):

| Правило | Пример дефекта |
|---|---|
| двувидовой глагол читается несовершенным | «вы характеризуете» как будущее |
| страдательные клетки — только от чисто совершенного глагола без предикатного хвоста | «перевожены», «сделана тусклым» |
| «быть + причастие» → краткая форма | «он был зарезанным» → «он был зарезан» |
| будущее «быть» без вспомогательного | «они будут быть» → «они будут» |
| настоящее «быть» и совершенного вида — нет формы | «есть / суть», «сделает» как настоящее |
| pluralia tantum: притяжательное во мн. | «твой вилы» → «твои вилы» |
| хвост значения сохраняется во всех формах, «чего-либо» отбрасывается | «вы будете принуждены» без «к посадке» |
| 1 л. ед. прош. — «(а)» только у простого глагола | «я был(а) раздавлен» |

Ограничение (известное с Ф0): русский вид не выводится из иврита — прошедшее совершённого действия
звучит несовершенным («я получал(а)» вместо «получил(а)»). Грамматично; контекст — Ф3.

Покрытие клеток: глаголы 96 256 / 126 256 (76%; действительный залог 92 415 / 96 563 = 96%,
страдательный 3 841 / 29 693 = 13%), существительные 89 599 / 96 653 (93%), прилагательные
3 073 / 3 925 (78%).

## Правило подстрочника (новое, общее со Ф1)

Предлог (`ב ל כ מ`) или артикль перед **личной** формой глагола иврит не допускает. Такое чтение
резолвера — ошибка: `בְּחָזְקָה` давало «в + она была сильной», `שֶׁלְּצַעֲרִי` — «к + огорчай!».
Если других чтений нет — подпись не показывается. Союзная приставка (`ו ש כש מש`) падеж не задаёт и
пишется слитно с формой («что она писала»); предложная — через «+» («в + упражнения»).

Ручная проверка подписей с переводом формы:

- Выборка 1 (seed 20261011, до правил): 3 ошибки формы из 60 — `בְּחָזְקָה`, `שֶׁלְּצַעֲרִי`, `יִהְיוּ`;
  все три закрыты правилами выше и перепроверены.
- Найден и закрыт общий для сборки и JS дефект: клетки настоящего времени (`AP-*`, род × число)
  отсеивались фильтром лиц в ОБОИХ путях, поэтому паритет его не видел. Закрыт тестом
  «у глагола несовершенного вида есть настоящее» (не паритетом).
- Выборка 2 (seed 777, после всех правил, независимая): **ошибок перевода формы 0/60**; вид звучит
  неестественно в 4 («он начинал», «он падал»). Вводят в заблуждение **5/60 (8%)** из-за чтения
  слова, а не формы: омограф (`מוּל` «напротив» → «проведи обрезание!», `הָאֶמְצָעִים` «средства» →
  «середины»), первое значение леммы (`אֲנָשִׁים` → «мужчины», `רַב` → «великий»), сочетание
  (`מִבְּחִינָה`). Это зона Ф3 (контекст); в Ф1 те же слова вводили в заблуждение смыслом леммы —
  Ф2 их не добавляет, но делает подпись конкретнее.

## Код

- `public/js/ru-forms.js` — загрузка (лениво, при первом подстрочнике/карточке) + `compose`/`formFor`.
- `public/js/word-gloss.js` — `cellForms`: перевод, только если он есть у **каждой** совпавшей клетки.
- `public/js/inflection-render.js` — матрица глагола + перевод в клетках; `opts.ruForm` = функция.
- `public/js/reader-morph.js` — строка «в тексте: …», прогрев `RuForms` в `ensureEngine`.
- CSS `reader-morph.css`, локали ru/en/he, SW precache, версия в lockstep.
