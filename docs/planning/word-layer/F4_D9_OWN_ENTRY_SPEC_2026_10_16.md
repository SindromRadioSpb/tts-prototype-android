# Ф4 · Д9 — своя статья сильнее чужой клетки; фильтр лексикона Dicta; отметки идут за словом; аудит слияний

Дата: 2026-10-16. Основание: независимая проверка личности слова
(`docs/research/my-dictionary-identity-audit/2026-10-16/RESULTS.md`): путь «вероятно» Pealim и лексикон Dicta (Д8-К) —
по 16 % ложных ключей. Решение владельца 2026-10-16: «Утверждаю. Реализуй в соответствии с рекомендациями» (правки 2 и 3,

## Д9.1 Правила (одно место — `ReaderMorph.resolveCore`; раскраска, тап, списки, Студия, карточки согласны)

Для чтения «вероятно» с номером статьи (`_preferOwnEntry`), по порядку:
1. **Решающее прочтение Dicta (A2).** Если преобладающее прочтение этого написания в лексиконе устройства (иных
   прочтений ≤ 20 %) указывает ровно на одного кандидата по ТОЧНОЙ части речи и лемме — он (מַכּוֹת → מכה «удары»,
   מַדְהִימִים → מדהים). Точная часть речи: «сущ.» Dicta не превращается в «прил.» Pealim (חַיִּים «жизнь» ≠ חי «живой»).
2. **Лемма Dicta между заголовком и родственником.** Форма — заголовок одной статьи и клетка родственной (сущ. ~ прил.),
   чья лемма = лемма Dicta (даже при раздвоенном лексиконе) — родственник (טוֹבָה → טוב «хорошая», не טובה «одолжение»).
   Наречие-заголовок не уступает (הַיּוֹם «сегодня», хотя Dicta делит ה+יום).
3. **Своя статья (A1).** Ровно у одного кандидата цитатная форма (лемма, ед. ч. / м. р. ед. ч.) = огласованная форма
   текста — он (נָחוּשׁ «непреклонный», שְׁנִיָּה «секунда», הַיּוֹם «сегодня» — заголовки без клеток тоже).
   **Вето Dicta:** преобладающее прочтение Dicta — текущее, не заголовок (בָּא «пришёл», צְרִיכָה «нужна»).
   **Исключение:** действительное причастие пиэль/хифиль/хитпаэль/пуаль/хуфаль (מְנַהֵל «руководит», מְעַנְיֵן) — замер:
   7 из 9 ошибок причастий; решает только Dicta (п. 1).

Фильтр лексикона Dicta (ветка `dicta-lexicon`, слово, которое Pealim не читает):
4. **Аббревиатура, которую Dicta свела к голым буквам** (פַתַ״ח → פתח «вход») — не слово, в группу «похоже на имя».
   Аббревиатура, которую Dicta держит как аббревиатуру (צה״ל, שב״כ, ממ״ד), — слово, как было.
5. **Стяжение ת׳ / ש׳** (תָּ׳דּוֹר = אֶת הַ+דּוֹר) — слово после гереша.
6. **Статья Pealim по скелету** (`dicta-pealim`): буквы без приставки Dicta — клетка ровно одной статьи родственной части
   речи; лемма та же (или Dicta лишь повторила форму: בדואים); **гласные текста — того же класса**, что у клетки
   (цере ~ сеголь, патах ~ камац; буква текста без гласного — любая): בֵּדוּאִים → בדואי, но צִיּוֹן (Сион) ≠ צִיּוּן «отметка»,
   עֲרָבִי «араб» ≠ עַרְבִּי. Сущ. Dicta → прил. Pealim только где Pealim сам даёт «как существительное». Неогласованное место
   читает огласовку записи Dicta (иначе одно слово получило бы два ключа: הָעָם и העם).

`resolveCore(eng, s, n, { noD9: true })` — чтение до Д9 (только для переноса; на всём корпусе владельца = старый код,
798 272 слова, 0 расхождений).

## Д9.2 Отметки идут за словом (`migrateIdentityD9`, один раз на устройстве, после Д7.2 и лексикона, Web Lock)

Ключ, ≥ 80 % мест которого в моих текстах теперь получают ОДИН другой ключ, отдаёт ему отметку (при конфликте —
более поздняя, как Д7.2); если ушли все места — старая отметка снимается. Меньше 80 % (יוֹם → הַיּוֹם 37 %) — ничего.
Расписание повторений не переносится (правило Д7.2). Итог и резервная копия — `localStorage lp.identityMigrationD9_v1(.backup)`.
Замер на профиле владельца (до выпуска): 965 ключей с отметками теряют места; 206 из них — частично с перевесом.

## Д9.3 Аудит слияний Д8-К3 (1219 активных)

Цель каждого слияния пересчитана тем же алгоритмом плана Д8-К3 с правилами Д9: оставить 1144, перенаправить 55
(ключ Dicta → статья Pealim: הקטן → קטן, השעה → שעה), отменить 20 (у написания больше нет одной цели; имена:
שלמה#propernoun → «целый», פרץ#propernoun). Применение — события слияния (новая цель / отмена «ключ → он же»), журнал
только дописывается; до применения — слепая проверка экзаменатором (`alias-validate.js`).
