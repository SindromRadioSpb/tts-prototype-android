## R10 — вычислительный морфолог (независимый эталон)

- **Опровержение:** правило А принимает факт Dicta, если ровно один кандидат совпал по части речи и лемме. На архаике
  Dicta верна на ~87 % (человеческая эталонная выборка Бен-Иегуды 2026-06-25: 143 из 165), на современном тексте —
  выше. Значит, правило на корпусе ошибается чаще, чем на своих текстах, и «112 : 16» Д10 сюда не переносится.
- **Что подтверждает замер:** правило меняет ключ у 1,7 % слов корпуса; по виду большинство — исправление известного класса ошибок офлайн-пути «вероятно» (аудит 2026-10-16, S2 16 % ложных; причастие глагола вместо своей статьи). Но две частые систематические ошибки (הַיּוֹם, אֱלֹהִים) — слова со своей статьёй, которую правило места обходит (Р2 → Д10.1).
- **Ответ плана:** страты (а)/(б)/(в) с порогом, записанным до прогона (Г2); экзаменатор калибруется на той же
  эталонной выборке архаики; страта ниже порога не раздаётся. Факты раздаются сырыми — правило можно ужесточить
  позже без повторной выпечки (R9: факты ≠ решения).

## R11 — регрессолог (не портить верное)

- **Опровержение 1 — лексикон.** `DictaLexicon.refresh` складывает **все** строки `sentence_morph`; «первое прочтение —
  ключ навсегда». Корпусная строка, записанная в ту же таблицу, сама уйдёт в лексикон и задаст ключи написаний в
  СВОИХ текстах ученика (у нового ученика корпус почти всегда первым). Объём корпуса (943 тыс. слов Бен-Иегуды) задавит
  доли «решающего прочтения» Д9. → **Р1-А**: лексикон пропускает `provider = 'corpus-dicta'`; Б — отдельным решением.
- **Опровержение 2 — свой разбор.** Сейчас `saveSentenceMorph` — UPSERT: корпусный файл перезаписал бы разбор,
  который ученик получил сам или который пришёл в снимке Медиатеки (3 065 строк «Учебных песен»). → запись только
  туда, где разбора нет (`…IfAbsent`).
- **Опровержение 3 — «точно».** Правило А не трогает `exact`/служебные слова по коду; но на архаике «точно» само
  ошибается в хвосте омографов (эталон: 18 из 68 в хвосте). Корпусный разбор этого **не исправит** — честно: К4 v2
  не лечит ложное «точно», это вне правила Д10. Гейт Г3 проверяет обратное: ни одно `exact` не меняет ключ.
- **Опровержение 4 — правленая строка.** Привязка по хешу `he_plain.trim()` + проверка скелетов токенов по
  выравниванию `placeUnits`; несовпадение — строка не применяется (а `_atPlace` ещё раз сверяет слово на месте).

## R7 — литературовед (регистр, эпоха)

- **Опровержение:** Dicta запрашивается в жанре `modern`; для поэзии Хаскалы это не её жанр. Можно выпекать архаику
  в жанре поэзии/раввинистики — но тогда факты корпуса и своих текстов приходят из разных моделей, а правило одно.
- **Ответ:** выпекаем в `modern` (одинаковые факты для одного правила); эпоха — отдельная страта Г2; если страта (а)
  не проходит — пробуем жанр Dicta для неё как отдельный эксперимент, решение владельца. В готовом каталоге v8 эпох
  medieval/biblical нет (архаика = Хаскала и Тхия, 120 работ).

## R2 / R8 — методист и graded reading (польза новому ученику)

- **Опровержение:** у нового ученика нет отметок — что он увидит? Раскраска «знаю/учу» пустая.
- **Ответ:** польза в ключе слова: тап открывает карточку нужного значения, «учу» ставится на нужное слово, тренажёры
  и «Мой словарь» с первого дня собирают правильные записи, а не исправляются переносом потом. Плата Д10 сохраняется:
  тренажёры, пересобирающие ответ по написанию, пропускают слово с ключом места (по замыслу).

## R4 — премиум-UX (вопрос при первом запуске)

- **Опровержение:** диалог при первом запуске мешает первому впечатлению; у нового ученика ещё нет своих текстов —
  вопрос без предмета.
- **Ответ:** спрашивать при первом **своём** тексте (импорт/вставка), не при открытии приложения; один раз; не модально
  поверх чтения — карточка-предложение в «Моём словаре»/после сохранения текста. «Да» — главная кнопка, без
  предвыбора; «Не сейчас» записывается и не переспрашивается. Корпусам вопрос не нужен. (Уточнение формулировки
  владельца «при первом запуске» — **на утверждение**.)

## R16 — стоимость

- **Dicta:** ≈ 83 тыс. запросов (из них 47 тыс. Бен-Иегуда), 3–4 ночи с IP компьютера владельца, ни одного — с IP прода. Медиатеку можно сократить разбором с устройства владельца (совпадение по хешу) — без Dicta.
- **Прод:** файлы ≈ 15 МБ на томе (диск прода сейчас 89 %, `disk_warn` — перед выкладкой проверить место, правило
  O-«диск 100 %»). Деплоя нет.
- **Устройство:** разбор ложится в `sentence_morph` только для скачанных работ (~0,5 КБ на строку в базе); набор «Мой
  словарь» из сотен работ — заметный рост базы: показывать объём перед скачиванием набора (существующий экран).
- **Свои тексты:** общий ограничитель сервера делает нагрузку на Dicta независимой от числа учеников; цена — очередь
  (ответ `rate_limited`), а не бан для всех.

## R12 / R13 — одна истина, синхронизация

- Корпусный разбор — производное серверного файла: в облачную синхронизацию не идёт (O-088: пакет состояния уже у
  предела), при восстановлении на новом устройстве применяется заново из файла. Экспорт сохраняет `provider` (сейчас
  переписывает в `dicta-morph` — потеря происхождения).
- Модель Dicta сменится → новая версия файлов (`model` в файле), старые строки на устройстве заменяются только
  корпусными (свой разбор не трогается).

## Синтез

План держится при трёх изменениях, внесённых в него: лексикон не трогается (Р1-А), запись только поверх пустого,
синхронизация не везёт корпусный разбор. Главный риск — точность правила на архаике; он закрыт порогом Г2 по стратам
до ночных прогонов, а не после раздачи. Новое после замера: правило Д10 на чистом профиле делает в 30 раз больше замен, чем на профиле владельца, — проверка экзаменатором обязана включать страту «своя статья» (Р2), иначе систематическая ошибка уйдёт всем ученикам сразу.
