# Ф4 · «Слова этого текста» — срез текста в «Моём словаре»

Дата: 2026-10-13. **Утверждено владельцем 2026-10-13**: доработка «Моего словаря» (не новая вкладка); порядок
Т1 → Т2 → Т3 → Т4; «Учить эти» с неразмеченными словами — выбор «отметить их как „незнакомо“ и учить»; лист
«Текст» в XLSX — в первой очереди. Связано: [F4_D1](F4_D1_DICTIONARY_SPEC_2026_10_12.md),
[F4_D2](F4_D2_LEARNING_SPEC_2026_10_12.md), [XLSX-книга](F4_XLSX_PREMIUM_SPEC_2026_10_13.md).

## Сценарий
Новый (или старый) текст → увидеть все его слова: с какими я уже работал и какие не размечены → быстро разметить
знакомые → оставшиеся незнакомые учить: всем набором или разрезом (глаголы, прилагательные, биньян) → выгрузить
учебную книгу по тексту → прочитать текст подготовленным.

## Что уже есть и что сохраняем (матрица до кода)

## Т1 — срез «Из текста»
- Переключатель «Мои слова | Все встреченные | Из текста ▾» (выбор из моих текстов); вход `dictionary.html?text=<id>`;
  из Зала (лист «Мои слова» и меню текста) — «Слова этого текста в словаре».
- Слова текста собирает **общая с Залом функция**: `ReaderMorph.scanRows(rows)` — те же пары форма/огласовка
  (`alignSurfaceNiqqud`), тот же `resolveCore`, тот же канонический ключ `statusKeyForCard`; `_scanWords` Зала
  переводится на ту же функцию разбора токена (одно место, без расхождения). Гейт: ключи Зала = ключи словаря.
- Статус в срезе — живой статус слова (как окрашено в тексте): «не размечено» (нет статуса) отдельно от «новое».
  Слова без уверенного разбора (имена, «подобрано», «не определено») — отдельная группа «не разобрано» с частотой.
- У слова: «в этом тексте N», первое место; сортировки «по порядку в тексте», «по частоте в тексте».
- Сводка: «Знакомо X% слов текста (как в Зале) · лемм: знаю a · учу b · новое c · не размечено d · не разобрано e».

## Т2 — быстрая разметка
- «Разметить (N)»: по одному слову неразмеченного/нового в текущем виде (порядок = сортировка): слово, перевод,
  предложение **из этого текста** с выделенным словом и переводом строки; кнопки/клавиши 1–5:
  «знаю · узнаю · не знаю · не учить · пропустить», «‹ назад» (вернуть прошлое слово). «Не знаю»/«узнаю» ставят слово
  в повторение (как тап в тексте) — с местом из этого текста, чтобы тренировка взяла это предложение.
- Массово: «Отметить показанные как „знаю“ / „не учить“ (N)» с отменой (10 с). Уровни l1–l4 массово не ставятся
  (засевают расписание — отменить нельзя); для учёбы — сценарий «Учить эти».
- «Учить эти» при неразмеченных словах в наборе: выбор «Отметить их как „незнакомо“ и учить (N)» / «Учить только
  размеченные (M)» / «Отмена».

## Т3 — XLSX по тексту
- «Начать»: «Слова текста „…“», знакомость X% (тот же движок), счётчики.
- «Словарь»: статус «не размечено» (свой цвет), колонка «В этом тексте», пример — из этого текста.
- Новый лист **«Текст»**: строка текста (иврит, rich: неразмеченные — оранжевым жирным, учу — цветом статуса,
  знакомые — обычным) · перевод строки · справа слова строки, которые не «знаю», каждое — ссылка на свою строку
  «Словаря» (в клетке Excel одна ссылка, поэтому слово — отдельная клетка).

## Т4 — учебные сценарии
- «Словарик к тексту»: самые полезные незнакомые леммы (по числу употреблений в тексте) и прогноз
  «выучите эти N → знакомость X% → Y%» — тем же движком (проекция с этими ключами как «учу»); порог 95%.
  Действия: «Показать эти», «Отметить незнакомыми и учить», «XLSX по ним».
- После чтения: «Учить эти» по словам, отмеченным в этом тексте (место отметки → предложение из текста).
- Разрезы: части речи / биньян / тренировка форм — существующие фильтры поверх среза.

## Разбор по ролям
- **R11 (истина):** один ключ слова, одна запись статуса (`MorphHost.markWordStatus`), одно число знакомости — никаких
  параллельных подсчётов. Гейт паритета ключей Зал ↔ словарь.
- **R10:** неуверенный разбор не выдаётся за «незнакомое слово» — отдельная группа «не разобрано».
- **R2:** разметка — с предложением из текста (узнавание в контексте), не голым списком; «не знаю» сразу привязано
  к месту в тексте для тренировки.
- **R4:** разметка клавишами и крупными кнопками; 380 px; массовые действия с отменой и честным числом.
- **Риск:** массовое «незнакомо» засевает много карточек — только через явный выбор с числом; «знаю»/«не учить»
  расписание не трогают (`markWordStatus`: уровни l1–l4 сеют FSRS, остальные нет).

## Реализовано — 3.11.754 (Т1–Т4)
- **Т1.** `ReaderMorph.scanRows(rows)` — разбор строк без DOM с той же функцией токена `_addScannedToken`, на которую
  переведён `_scanWords` Зала (лист «Мои слова», тренировка). Срез «Из текста» в `dictionary-ui.js` (`loadText`,
  `attachText`, живой статус `textStatus`, «не размечено» = `none`, сортировки `textOrder`/`textFreq`, «Скрыть
  возможные имена», группа «Не разобрано»). Знакомость — `LocalTextFamiliarity.createService` + `LearningCompassCore`
  (тот же кэш `mytext:<id>`). Вход из Зала: лист «Мои слова» → «Все слова текста в «Моём словаре» ›»;
  `dictionary.html?text=<id>`.
- **Т2.** «Разметить (N)» (`openTriage`, клавиши 1–5, «назад», уровни — с местом из текста через
  `markWordStatus(key, st, source)`), «Все показанные без отметки: ✓ знаю / не учить (N)» с отменой (тост с
  действием), «Учить эти» с неразмеченными → выбор (`chooseTrain`).
- **Т3.** Книга XLSX в срезе: заголовок «Слова текста «…»», знакомость, статус «не размечено», «В этом тексте»,
  пример из этого текста, лист «Текст» (цвет слова по статусу; незнакомые слова строки — ссылками на «Словарь»);
  `scanRows` отдаёт `rowKeys` для раскраски.
- **Т4.** «Словарик к тексту»: `DictionaryProgress.textPlan` — прогноз движком Зала (проекция + выбранные ключи как
  l1), шаги 10/25/50 и «до 95%» (бинарный поиск), только слова среза; «Показать эти» (фильтр `keys`),
  «Отметить незнакомыми и учить», «XLSX по ним».
- Гейты: `dictionary-smoke` D12 (паритет лемм Зал = словарь, живые статусы, знакомость, разметка с местом, массово +
  отмена, выбор при «Учить эти», 380 px HE), D13 (словарик, XLSX с листом «Текст»); юнит-тесты ядра, книги и плана.
- Не сделано: вход из Студии (у Студии нет своего списка слов текста — вход через Зал); срез по подборке текстов.
