# Ф4 · Д1 — «Словарь»: список + статья слова (СПЕКА + разбор по ролям)

Дата: 2026-10-12. Основание: [F4_MY_DICTIONARY_CONCEPT_2026_10_12.md](F4_MY_DICTIONARY_CONCEPT_2026_10_12.md), решения владельца 2026-10-12:
отдельный пункт нижней навигации «Словарь»; отмеченные слова по умолчанию + переключатель «все встреченные»;
первая очередь — список + фильтры + сортировка + статья слова; XLSX позже.

## 1. Источники записи (ни одного нового канонического хранилища)

Запись = лемма по ключу `lemma-canon` (как у статусов и повторений). «Моё слово» = ключ есть хотя бы в одном:

| Источник | Что даёт | Факт из кода |
|---|---|---|
| `word_status` | статус, состояние FSRS (`srs_*`) | `getAllWordStatuses`, `getSrsSchedule` |
| канонические заметки `notes_v2` (`gen_dedup_key`) | «Добавить в мои слова», ваш перевод, места (текст, строка, слово) | `morph-host.saveWord` → `createCanonicalNote` + `addNoteOccurrence`; `getCanonicalWordNotesAll` |
| `review_log` | история повторений, форма слова в `meta.surface` | `getReviewLog`, `getReviewLogSince` |
| `word_context` | места слова, собранные тренировкой | `getWordContexts` |

Форма и разбор записи (огласовка, значение, часть речи, биньян, корень, Pealim id) — **производные**: офлайн
`ReaderMorph.resolveWordLight(форма)` с проверкой личности (`card.lemmaKey === ключ`, R11: запись не получает чужой разбор).
Форма берётся по лестнице R2 повторения (`_r2DeriveSurface`): заметка → `word_context` → `review_log.meta.surface` →
разбор ключа `<скелет>#pos`. Ключ `pid:N` без записанной формы — разбор по Pealim id; если нет и его — запись
показывается честно «форма не записана» с ключом и статусом (не прячется, не выдумывается).

**Индекс словаря** — производный кэш в IndexedDB (`lp-dictionary-index`, как `lp-word-gloss-ai`): ключ → {форма, разбор,
счётчики мест, даты}. Строится в фоне порциями с уступками потоку (урок O-080: никаких бурь мутаций и полного
перебора на главном потоке), пересчитывается по изменению статусов/заметок/лога; его потеря ничего не стоит.

**«Все встреченные в моих текстах»** — второй уровень: леммы из строк моих текстов (не корпус), считаются в
Web Worker порциями с прогрессом и кэшируются по тексту (хэш строк). Не участвуют в повторении, пока вы их не отметили.

## 2. Экран «Словарь» (`/dictionary.html`, пункт нижней навигации)

### 2.1 Список
- **Шапка:** поиск (иврит с огласовкой и без, русский по значению, корень) · счётчики по статусам (тап = фильтр) ·
  переключатель «Мои слова / Все встреченные».
- **Фильтры** (панель, на телефоне — лист): статус (7 уровней) · память: «к повторению сегодня», «просрочено»,
  «трудные» (срывы ≥ 3), «ещё не повторялось» · часть речи · биньян · корень · источник (текст / подборка
  Медиатеки / Бен-Иегуда) · «есть мой перевод» · «есть перевод ИИ в контексте» · добавлено: неделя / месяц / всё.
  Активные фильтры — чипами над списком, каждый снимается тапом; сброс одной кнопкой.
- **Сортировка:** по алфавиту иврита (по скелету) · недавно добавленные · срок повторения · самые слабые (сила памяти
  FSRS, срывы) · чаще всего в моих текстах · недавно встреченные · по корню (группы).
- **Строка списка:** слово с огласовкой (крупно, RTL) · значение (ваше > словарное; провенанс цветом, как в карточке) ·
  часть речи · биньян · корень · статус (цвет как в тексте) · полоска силы памяти + «через 3 дня» / «сегодня» ·
  «в 4 текстах · 12 раз». На ПК — таблица со столбцами, на телефоне — двухстрочная карточка-строка.
- **Производительность:** виртуальный список (рисуются видимые строки), фильтр/сортировка по индексу в памяти;
  цель — 1000 записей: открытие < 1 с из кэша, фильтр < 100 мс.

### 2.2 Статья слова (тап по строке; на ПК — панель справа, на телефоне — отдельный экран с «‹ Назад»)
1. **Заголовок:** слово с огласовкой · ▶ озвучка · транслит · лемма · часть речи / биньян / корень · статус (те же 7
   кнопок, что в карточке) · «не учить».
2. **Значения:** ваш перевод (✎) · словарное (Pealim) · переводы в контексте ИИ из разных мест (уникальные, с числом мест).
3. **Места в моих текстах:** список предложений (форма подсвечена) с переводом строки и переводом слова в контексте ·
   «Открыть в тексте» (Зал на этой строке) · ▶ строки, если у материала есть медиа. Порядок: последние встречи.
4. **Спряжение / склонение:** та же таблица, что в карточке (`InflectionRender.renderParadigm`, Pealim + русский по
   клеткам, Ф2) с подсветкой **всех форм, встреченных в моих текстах** (не только одной). Нет таблицы — честное
   «не изменяется / нет таблицы» + ссылка на Pealim (R1).
5. **Семья корня:** леммы корня с вашими статусами; тап — статья той леммы.
6. **Память:** сила, следующий срок, число повторений и срывов, последние 10 ответов (дата · канал · результат).
7. **Заметка** (ваша, `word_study`), ссылка «Открыть в Anki-экспорте» позже (XLSX позже).

### 2.3 Действия Д1
Статус и «не учить» (те же `setWordStatus`, раскраска текстов обновится) · ваш перевод · «Добавить в мои слова» для
слов уровня «все встреченные» · «Открыть в тексте». **Учебные режимы («учить эти», тренировка форм, прогресс) — Д2.**

## 3. Разбор по ролям (до кода)

| Роль | Риск | Решение в спеке |
|---|---|---|
| **R1 лексикограф** | запись с чужим разбором (омограф); выдуманная парадигма | проверка личности `lemmaKey`; парадигма только Pealim; «нет таблицы» честно |
| **R2 методист** | словарь — свалка слов «ради информации», тупик без следующего шага | Д1 уже даёт «открыть в тексте» и статусы; учебные режимы Д2 — следующей очередью, место под них в шапке |
| **R4 премиум-UX** | перегруз статьи; 380 px; RTL | статья — разделы-аккордеоны (места и спряжение раскрыты, остальное свёрнуто); снимки 380 px RU/HE перед коммитом |
| **R5 продукт** | хуже Reverso/Pealim-«избранного» | места в СВОИХ текстах + перевод в контексте + сила памяти — то, чего нет у аналогов; офлайн целиком |
| **R9 связанные данные** | записи-дубли одной леммы (pid: и lemma#pos) | одна запись на канон-ключ; конфликт ключей — отдельный диагностический фильтр, не склейка вслепую |
| **R10 морфолог** | частотность/корень по неуверенному разбору | неуверенный разбор помечается «≈», не участвует в группировке по корню |
| **R11 не навредить** | словарь ≠ карточка ≠ раскраска; запись статуса из словаря расходится с текстом | один ключ записи (`lemma-canon`) для статуса из словаря и из текста (save == paint == review); снимок паритета в тесте |
| **R12–R15 платформа** | персональные данные уходят на сервер | словарь целиком локальный (OPFS + IndexedDB), ничего не отправляет |
| **O-080 скорость** | полный перебор на главном потоке, перерисовки | индекс в фоне порциями, виртуальный список, «все встреченные» — в Worker; гейт скорости на 1000 записей |

## 5. Реализация (3.11.747)

- `public/js/dictionary-core.js` — чистое ядро: `mergeSources` (статусы + время статуса, расписание FSRS, канонические
  заметки, агрегат `review_log`, банк `word_context`, **форма места разметки** `word_status.srs_surface`), `memory`
  (FSRS R(t) = (1 + t/9S)⁻¹), поиск (иврит без огласовки, конечные буквы, **любая форма таблицы слова**; русский по
  значению), фильтры, 7 сортировок, счётчики статусов. Тесты `tests/dictionaryCore.test.js`.
- `public/dictionary.html` + `css/dictionary.css` + `js/dictionary-ui.js`; пункт «Словарь» в `app-nav.js`
  (иконка `lp-icon-dictionary`); строки `dictionary.*` в ru/en/he.
- **Разбор записи.** Проверка личности: разбор по форме принимается только при `lemmaKey === ключ`. Ключ `pid:N`
  без подтверждённой формы получает разбор из **статьи Pealim с этим id** (личность доказана id; инфинитив
  глагола даёт другой ключ резолвера, поэтому «проверять» его формой нельзя). Неподтверждённая запись честно
  показывает «перевод не найден офлайн», статья не рисует таблицу («разбор не подтверждён»).
- **Места в текстах:** места «моих слов» → место разметки статуса → поиск по формам таблицы
  (`findSentencesForWords`) с допуском ≤3 приставок (ו ב כ ל מ ש ה) и доказательством каждого места разбором.
  Ссылка «Открыть в тексте» → `library.html?my_text=…&at=<order_index>` (новый параметр Зала).
- **Таблица** — `InflectionRender.renderParadigm` с подсветкой **всех** клеток, встреченных в местах
  (`WordGloss.matchCell`); перевод в контексте ИИ каждого места — `WordGlossAI.wordAtData` (по данным строки).
- **Статус из статьи** — `MorphHost.markWordStatus` (тот же канон, что тап в тексте); «Карточка слова» —
  `ReaderMorph.openWordCard` (мой перевод, заметка, Pealim).
- **Скорость (O-080):** разбор порциями ≤24 мс, кэш разборов в IndexedDB `lp-dictionary-index` (по ревизии
  резолвера), нормализованные формы записи кэшируются, **пока человек печатает, фоновый разбор ждёт**.
  Гейт `scripts/premium/dictionary-smoke.js`: 1000 записей — список 0,25 с, поиск 29 мс в покое и 16–32 мс во
  время фонового разбора; 380 px RU/HE без прокрутки вбок.
- Поправлено по ходу: ссылка «к словам» пряталась `left:-999px` — в RTL это давало прокрутку и пустой экран;
  `[hidden]` у панели фильтров перебивался `display:grid` (ловушка из памяти проекта).

## 6. «Мои слова» на реальном профиле владельца (3.11.748)

Первое открытие на рабочей базе зависло на «Ищу…»: в профиле **33 004** заметки `word_study` и **4 930** строк
статуса «новое». Разбор (Kapture, только чтение):

| Источник | Число | Чьё |
|---|---:|---|
| заметки `source='auto'` (автозаметки ②) | 23 583 | программы |
| заметки `source='user'` без канон-ключа, созданы 2026-06-02 в 82 текстах | 8 672 | тестовый импорт пакета (project_bundle_wordnote_test) |
| заметки `curated` («Добавить в мои слова») | 743 | владельца |
| заметки с моим переводом (`meaning_source='user'`) | 35 | владельца |
| статусы l1–l4 / знаю / не учить | 595 | владельца |
| статус «новое», единственный след — `review_log.source='mark-backfill'` | 4 925 | миграции |

**Правило «моё слово» (3.11.748):** статус l1–l4/знаю/не учить; «новое» — только при моём следе (отметка/повторение
не из `mark-backfill`, расписание); заметки `curated`, с моим переводом, или канонические (`gen_dedup_key`) с
`user_touched=1`; слова с моими повторениями. Автозаметки и импорт без канон-ключа — не «мои» (они — материал для
«все встреченные»). Ускорение: заметка с `pealim_id` и запись `pid:N` получают разбор прямо из статьи Pealim
(канон-ключ Pealim-слова = `pid:N`) — без разбора форм.
