# Ф1 · Подстрочник и лента слов — спецификация

Дата: 2026-10-11. Канон: [../WORD_LAYER_RESEARCH_AND_PLAN_2026_10_11.md](../WORD_LAYER_RESEARCH_AND_PLAN_2026_10_11.md).
Основание: отчёт [F0](F0_REPORT_2026_10_11.md) + разведка кода (ниже).

## Разведка: что поменялось против плана

1. **Рабочий резолвер не хуже зонда.** `NotesAutoGen.resolveContentUnit` (за морф-карточкой по тапу)
   на 2812 полнозначных словах Ф0: парадигма у 2555, совпадение с GPT 96.2% (зонд join v3 — 95.6%
   при чуть большем покрытии). Сомнительные выборы он сам помечает «вероятно» (ambiguous, 0.65).
   → **Слой строится на нём**, а не на копии логики зонда: подстрочник, лента и карточка по тапу
   обязаны показывать одно и то же. Находки join v3 (краткая запись леммы אשה≠אישה и др.) —
   отдельный шаг «качество резолвера» с parity-гейтом `smoke:autogen-parity`, не Ф1.
2. **Хранить слой не нужно.** Слова в таблице уже обёрнуты общим `ReaderMorph.attach` в `.rm-w`
   с `data-surface`/`data-niqqud`; раскраска статусов (`decorateWords`) уже резолвит каждое слово
   офлайн. Глосса — детерминированная функция (слово, огласовка, офлайн-Pealim) → вычисляется при
   показе, с мемо-кэшем. Нет миграций, нет роста ZIP-экспорта, нет рассинхрона при правке карточки.
   Контекстное уточнение Dicta уже существует отдельно (`sentence_morph`, согласие) и в Ф1 не
   меняется. «При создании таблицы» из плана выполняется буквально: подстрочник готов, как только
   таблица показана, без отдельного шага.

## Что показывается

Для каждого слова еврейской колонки (огласованной, если она есть, иначе обычной):

- **смысл** — первое значение леммы из Pealim, коротко (`слышать`);
- **форма** — если огласованная форма слова (или её основа после приставки) точно совпала с клеткой
  найденной парадигмы: подпись клетки (`я · прош.`, `мн.`, `мой`), из существующих подписей
  `InflectionRender.slotLabel` + сокращение времени;
- **приставка** — только когда совпадение с клеткой получено после отделения приставки:
  `ש` → «что», `ו` → «и», `ב` → «в», `ל` → «к», `כ` → «как», `מ` → «из», `ה` → артикль (не пишется),
  `כש` → «когда»;
- **честность** (метки резолвера): «точно» — как есть; «вероятно» — с префиксом `≈`;
  служебное слово — его функциональная глосса; «нет данных» — без подписи (в ленте — `?`).

Пример: `ששמעתי` → `что · слышать · я, прош.`. Перевод формы целиком («что я слышал(а)») — Ф2/Ф3.

## Интерфейс

- **Подстрочник** (тумблер «Подстрочник»): подпись мелким шрифтом под каждым словом. Реализация —
  атрибут `data-gloss` + CSS `::after` (DOM таблицы не перестраивается; parity-билдер не тронут).
- **Лента слов** (тумблер «Лента слов»): полоса над таблицей, прилипает к верху окна таблицы, то
  есть в учебном режиме стоит сразу под видео. Показывает слова текущей строки — той, что звучит
  (TTS `row-playing` или видео `smk-row-active`), иначе строки позиции чтения (`rm-row-current`).
  Чип = слово + подпись. Тап по чипу = тап по этому слову в таблице (та же морф-карточка).
  Горизонтальная прокрутка справа налево на узком экране.
- Тумблеры: Зал — панель «Аа» рядом со «Статус слов»; Студия — рядом с её «Статус слов».
  Ключи `room.wordGloss` / `room.wordRibbon` и `studio.wordGloss` / `studio.wordRibbon`
  (Студия при первом чтении наследует значение Зала — как «Статус слов»). По умолчанию выключены.

## Код

- `public/js/word-gloss.js` — чистое ядро (Node-тестируемо: короткий смысл, совпадение формы с
  клеткой, подпись клетки, приставка, сборка глоссы) + браузерный слой (проход по `.rm-w`, лента).
- `public/js/reader-morph.js` — экспорт `resolveForGloss(surface, niqqud)`: тот же `resolveCore`,
  что у раскраски, с мемо-кэшем; поведение существующих функций не меняется.
- `public/css/word-gloss.css` — стили обеих поверхностей.
- Подключение: `library-ui.js` (Аа + после `applyDecorations`), `studio-morph.js` + `index.html`
  (тумблеры + после refresh). Локали ru/en/he, SW precache, версия в lockstep.

## Результат реализации (3.11.738)

Замер полной цепочки (рабочий офлайн-резолвер + глосса) на тексте «Шура», 5641 слово огласованной
колонки (`scripts/word-layer/f1-gloss-eval.cjs`; полный TSV — вне публичного репозитория):

| | Слов | Доля |
|---|---:|---:|
| Подпись показана | 4314 | 76.5% |
| …из них с формой («я, прош.») | 1457 | 25.8% |
| …из них с приставкой («что +») | 532 | 9.4% |
| Без подписи (честно) | 1327 | 23.5% |

Ручная слепая проверка 60 показанных подписей: вводят в заблуждение ≈5% (не тот смысл омонима из
первого значения Pealim, напр. מִשְׁפָּטִים «суд» вместо «фразы»; сочетания вроде מוצאי שבת) — зона Ф3.

Правила честности, принятые по замерам (зафиксированы тестами `tests/wordGloss.test.js`):
1. `guessed` (догадка резолвера по значению) под словом не показывается: на выборке давал
   שֶׁיֵּשׁ → «радоваться», בְּבָתֵּי → «кукла».
2. «Вероятно» показывается с «≈» ТОЛЬКО без подписи формы: на выборке 40 из 40 «вероятных» 20 были
   ошибочны, и почти все — с конкретной формой (אַחֵר → «опоздать · повел.»). Карточка по тапу
   сохраняет такое чтение со своим бейджем и альтернативами.
3. Подпись формы — только при точном совпадении огласовки с клеткой (дагеш не различается:
   источники расходятся, напр. Pealim אִשְׁתִי ↔ текст אִשְׁתִּי); голый предлог = базовая форма
   (לְפִי ≠ «по мне»); сопряжённая форма, совпадающая с абсолютной, не подписывается.
4. Личные местоимения читают свою клетку набора Pealim (הֵם → «они (м)», не «я»).

Изменение резолвера (общего с карточкой по тапу): вариант без относительного `שֶׁ` с удвоением
(`relativeStrippedForm`, по образцу артикля). +84 подписи на «Шура»; человеческий эталон
`reader-morph-gold` (--regold) — без изменений с вариантом и без него, контроль 35/36 → 35/36.

Найдено и не исправлено (вне Ф1): `smoke:reader-word-status` красный на чистом main — O-079.
