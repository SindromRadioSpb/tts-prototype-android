## Д6.1 Общий модуль скачивания — `public/js/corpus-materialize.js`
Чистый (зависимости — аргументами: `db`, `fetch`, `Edition`, `Adapter`), тестируется в Node:
`ensureBenYehudaWork(card, deps)`, `ensurePublicWork(slug, card, deps)`, `publicWorkUrl`, `expectPublicSnapshot`,
`materializeMany(items, fn, { onProgress })` — по одной работе, без обрыва на ошибке, итог `{ ok[], failed[{item, reason}] }`.
Зал (`openCorpusWork`, `openPublicCorpusWork`) переходит на модуль — одна дорога скачивания (R11), поведение Зала то же.

## Д6.2 «Собрать набор» в словаре (срез «Из текста»)
Кнопка «＋ Собрать набор…» рядом с выбором текста → панель:
- **Источник:** «На устройстве» (все мои тексты и скачанные работы, группы как в выборе) · «Бен-Иегуда» · каждый
  публичный корпус из `/api/public-corpora` (по названию, в порядке сервера).
- **Поиск** по названию (и автору у Бен-Иегуды) без огласовки; галочки; работа, уже скачанная на устройство, помечена
  «на устройстве». Показ первых 100 совпадений и честная строка «показано 100 из M — уточните поиск».
- **Корзина:** «Выбрано: N · скачать: K» — выбор сохраняется при смене источника и поиска; ✕ убирает. До 200 текстов.
- «Показать слова (N)»: сначала скачиваются K работ по одной, с прогрессом «Скачиваю i из K: название»; затем срез
  `@ids:` по всем выбранным, что есть на устройстве. Итог: «Скачано K. Не удалось: F — название (причина)»; не
  скачанное в срез не подставляется. Набор сохраняется кнопкой «☆ Сохранить набор» (как любой вид).

## Разбор по ролям (до кода)
- **R11 (одна истина):** одна дорога скачивания для Зала и словаря; номер каталога — один источник; скачанная работа —
  обычный текст устройства (Зал её видит, прогресс и отметки общие).
- **R1/R9 (честность):** в поиске Бен-Иегуды только работы с текстом; несостоявшееся скачивание названо, не скрыто;
  «показано 100 из M» вместо молчаливой обрезки.
- **R4 (премиум-UX):** набор собирается в одном месте, корзина видна всегда, 380 px; скачивание с прогрессом и отменой
  через смену среза (эпоха).
- **R2 (методист):** набор под задачу — «рассказы одного автора», «серия курса» — словарик к набору даёт общие слова.
- **Риски:** каталог Бен-Иегуды ≈ 2,3 МБ — грузится только при первом выборе источника, не при открытии словаря;
  сеть/ограничение частоты — по одной работе, без параллели; большой каталог публичного корпуса — один запрос, как в Зале.
