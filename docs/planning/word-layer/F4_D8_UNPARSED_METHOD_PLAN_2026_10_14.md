## Предлагаемая методика (без ИИ, по слоям от самого точного)

1. **Приставка + служебное слово.** Снять цепочку приставок `ו? (ש|כש|מש|לכש)? (ב|ל|כ|מ)? ה?` и сверить остаток
   со списком служебных слов с учётом огласовки (בַּעֲלֵי «владельцы» ≠ ב+עלי). Такие слова уходят к служебным,
   как и их формы без приставки: не входят в список и не считаются в знакомости.
2. **Приставка + обычное слово.** Сегментатор ProcliticSegment (его уже использует карточка) + разбор основы
   с поправкой огласовки (снять гласную приставки, восстановить слитый артикль בַּ = ב+ה). Ключ — лемма основы
   (то же правило, что Д7: форма → лемма). Отметка «знаю סוֹף» покрывает בַּסּוֹף.
3. **Вариант огласовки.** Написание есть в Pealim, огласовка не совпала: засчитать лемму, только если это
   написание указывает ровно на одну лемму (как Д7.1). Иначе — «есть догадка».
4. **Строки без огласовки.** Огласить при сборке (Dicta, как остальные строки), либо слой 3 по написанию.
5. **Аббревиатуры и обрывки** — отдельная группа, обрывки не считаются словами текста.
6. **Остаток** — «Вне словаря: имена и заимствования»: справочник имён с проверкой огласовки, правила
   заимствований (‑יָה, ‑יסט, ‑יזם, ‑לוגיה), и по желанию объяснение ИИ на тапе.

## Проверка качества (независимый эталон)

Эталон — разбор Dicta (сегментация приставок и лемма) по этому и ещё двум текстам разных жанров, а не тот же
разборщик. Гейт: точность каждого слоя на эталоне; слой включается, если точность ≥ 97 %. Ошибки слоя 2
по оценке модуля ≈ 5 % без подтверждения Dicta.

## Решения владельца (нужны до кода)

- Д8-1: слой 2 — включать по офлайн-сегментации (≈ 95–97 %) или только с подтверждением Dicta.
- Д8-2: служебные слова с приставкой не учить и не считать — как служебные без приставки.
- Д8-3: обрывки распознавания не считать словами текста. **УТВЕРЖДЕНО владельцем 2026-10-14.**
- Д8-2 (встречное предложение владельца): галочка, которая показывает или убирает служебные слова с приставкой.
  Ответ: узнавать их нужно всегда (וְזֶה = זֶה), а галочка управляет только видимостью служебных слов в списке.
- Замечание к Д8-1: в черновом замере (без защит модуля) 7 из 27 разобранных основ оказались неверны
  (מוֹנְטִי → «склоняться», לַהַכְשָׁרָה → «петь», בְּכִכַּר → «подушка»). Оценку модуля ≈ 5 % надо перемерить на эталоне Dicta до решения.

## Решения владельца 2026-10-14 (утверждены)

- **Д8-1: только с подтверждением Dicta.** Обычное слово с приставкой засчитывается лемме основы, только когда
  разбор Dicta (сегментация приставки) подтверждает это разделение. Без подтверждения слово остаётся в
  «Не разобрано». Офлайн-сегментация в списке не используется.
- **Д8-2: галочка.** Служебные слова с приставкой всегда распознаются как служебные (וְזֶה = זֶה). Галочка
  «Показывать служебные слова» управляет только видимостью в списке (формы с приставкой и без), по умолчанию
  выключена. Процент знакомости от галочки не зависит.
- **Д8-3: обрывки распознавания не считаются словами текста.**

## Концепция Д8-К: каждое слово текста — запись словаря (ПРЕДЛОЖЕНИЕ, ждёт решения владельца)

Данные уже есть и оплачены: у 120 из 120 проверенных неразобранных слов есть контекстный перевод слоя слов
(Gemini при сборке; имена помечены «имя: …»), у ~98 % — лемма и часть речи Dicta.

Ярусы личности слова (честная пометка происхождения у каждой записи):
1. **Pealim** — как сейчас: лемма, корень, таблицы, тренировка форм.
2. **Лемма Dicta** (нет в Pealim или Pealim не подтвердил) — ключ `dl:<лемма>`, значение = перевод слоя слов в контексте,
   часть речи Dicta. Можно отмечать, учить, повторять, выгружать в Anki; таблиц форм нет. Пометка «по разбору Dicta».
3. **Имена и названия** — часть речи Dicta / пометка «имя:» перевода. Не учатся по умолчанию, не входят в знакомость.
4. **Служебные слова и наречия** — галочка (сделано).
5. **Не разобрано** — только строки без разбора Dicta + кнопка «Разобрать через Dicta» (согласие на отправку текста).

Риски и как закрываются: лемма Dicta ошибается ~5–8 % — запись не выдаёт себя за Pealim, значение берётся из перевода
именно этого места; позднее совпадение с Pealim переносит отметки (механизм Д7.2). Новый вид ключа затрагивает отметки,
повторения, Anki, синхронизацию и сервер наставника — нужен разбор по ролям до кода.
