# Ф4 · XLSX «Мой словарь» — зрелая учебная книга

Дата: 2026-10-13. Основание: команда владельца после 3.11.752 («нет переходов Словарь → Формы, учебный процесс не
замкнут; нужна серия требований, чтобы файл имел высокую образовательную ценность»). Образец — прототип владельца
`03_Иврит_Учебный_навигатор.xlsx` (листы «Начать / Повторение / Карточка / Слова / Парадигмы / Как заниматься»).
Предыдущее: раздел XLSX в [F4_D2_LEARNING_SPEC_2026_10_12.md](F4_D2_LEARNING_SPEC_2026_10_12.md).

## Принцип
Файл — **самостоятельная учебная тетрадь**: открыл → понятно, что делать сегодня → по ссылкам дошёл от слова до
его таблицы, примера и проверки → увидел итог. Без макросов (работает в Excel, LibreOffice, Google Таблицах,
мобильном Excel). Файл — снимок: правки в нём не меняют программу, и это сказано на первом листе.

| X2 | **Лист «Начать»**: что это, дата, фильтр выгрузки, счётчики, оглавление со ссылками, «как заниматься» (5 шагов), легенда цветов | первый лист |
| X3 | **«Повторить сегодня»** на «Начать»: слова к сроку/просроченные (до 15), со ссылками на строку слова | из FSRS |
| X4 | **Лист «Таблицы»**: по блоку на слово — время/группа в строке, клетки «лицо · форма · транслит · перевод» как у Pealim; встреченные в моих текстах подсвечены, уверенные ✓ | rich text в клетке |
| X5 | **Лист «Формы»** (плоский): фильтр по времени/лицу/«встречена»/«уверенно» для работы по всем словам сразу; ссылка на блок таблицы | автофильтр |

## Разбор по ролям (до кода)
- **R2 (методист):** главное в учебной книге — припоминание с проверкой (X6) и «что делать сегодня» (X3), а не
  справочник. Проверка — производство формы, как «Ввод» в приложении; ответ скрыт до попытки (скрытые колонки).
- **R1 / R11:** ответы и формы — только клетки Pealim и подтверждённые разборы; правила приёма ответа те же, что в
  приложении (полное написание — только по огласовке). Файл не выдаёт себя за источник истины: правки не синхронизируются.
- **R4:** первый экран — «Начать», а не сырые данные; ссылки крупным текстом; перенос строк, ширины колонок; RTL.
- **R10:** формула проверки не «похоже»: точное совпадение после снятия огласовки/конечных букв, два варианта
  написания; полное написание с частичными вставками (только одна из двух ו) не принимается — честно в подсказке.
- **Риск:** Google Таблицы и старый Excel — `UNICHAR` есть с Excel 2013; внутренние ссылки работают в Excel и
  LibreOffice; в Google Таблицах ссылка на лист может открываться иначе — проверяем валидность файла независимым
  чтением (openpyxl) и формулы — пересчётом LibreOffice, если он доступен.

## Реализовано — 3.11.753
- X1–X12 сделаны. Модули: `public/js/xlsx-core.js` (стили без дублей, внутренние/внешние ссылки, rich text, формулы
  с пересчётом при открытии, условное форматирование, печать, строки над шапкой), `public/js/dictionary-workbook.js`
  (сборка шести листов; тесты `tests/dictionaryWorkbook.test.js`), сбор данных — `exportXlsx` в `dictionary-ui.js`
  (пример: банк контекстов → место «моего слова» → место отметки). `dictionary.html?word=<ключ>` открывает статью.
- Правило полного написания уточнено по проверке в Excel (и в приложении тоже): хирик в закрытом слоге
  (следующая буква под швой) и хирик под самой י не дают י — לכתוב, בית (не ליכתוב, ביית).
- Проверено в настоящем Excel (COM): файл открывается без восстановления; ответы вводом → формулы пишут
  «✓ верно: …» / «✗ ответ: …» (краткое написание, полное, с огласовкой); счёт на «Начать» пересчитывается;
  все ссылки ведут по адресам; просроченная дата закрашена по TODAY(); слово в примере жирное; печать «Словаря»
  — колонки A:P с повтором шапки. Независимое чтение — openpyxl. В Excel обязательно `_xlfn.UNICHAR` (без
  префикса — #ИМЯ?).
- Ограничения: в Google Таблицах внутренние ссылки на листы могут вести себя иначе (не проверено); правки в файле
  не возвращаются в программу (сказано на «Начать»); заданий «Проверь себя» не больше 400.
