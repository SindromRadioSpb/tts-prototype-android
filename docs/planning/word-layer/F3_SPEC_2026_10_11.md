# Ф3 · Перевод слов в контексте (Gemini) — спецификация

Дата: 2026-10-11. Статус: **РЕАЛИЗОВАНО в 3.11.741** (решения владельца — §5).
Канон: [../WORD_LAYER_RESEARCH_AND_PLAN_2026_10_11.md](../WORD_LAYER_RESEARCH_AND_PLAN_2026_10_11.md) (D1 гибрид, D2 опция, по умолчанию ВЫКЛ).
Основание: [QUALITY_GAP_ANALYSIS_2026_10_11.md](QUALITY_GAP_ANALYSIS_2026_10_11.md) — после шага 1 (3.11.740)
покрытие 88%, остаток ≈7% вводящих в заблуждение (омонимы, сочетания, вид глагола) + 12% без подписи.

## 1. Что делает

Для строки учебной таблицы Gemini получает: огласованную строку, её русский перевод из таблицы и
пословный офлайн-разбор (лемма, часть речи, найденная форма и её перевод, метка уверенности). Возвращает
по каждому слову: короткий перевод ИМЕННО этой формы в ЭТОМ контексте («что я слышал», «к нашему дому»),
отметку сочетаний (span слов + перевод сочетания, напр. מוצאי שבת → «исход субботы»), и флаг, если
офлайн-разбор неверен (другая лемма/смысл). Офлайн-разбор — опора и ограничение, не истина: модель не
выдумывает форм, которых нет в слове.

## 2. Как встроено (существующая инфраструктура, без нового контура)

- Новый сценарий `word-gloss-ctx` в `ingest/geminiPolicy.js` (модель, promptId, schemaId) и маршрут
  `/api/word-gloss-ctx` по образцу `/api/ingest/retell`: вход → ключ (BYOK, `geminiApiKey`) → серверный кэш
  по содержимому строки+модели+промпта → Gemini → `classifyGeminiError`. Повторная сборка того же текста
  не платит второй раз; ключ не логируется.
- Клиент хранит результат локально (OPFS) по хэшу строки, чтобы подстрочник/лента/карточка работали
  офлайн; входит в экспорт карточки. Для текстов публичного корпуса — тот же локальный слой.
- Показ: глосса Ф3 заменяет офлайн-подпись с отметкой происхождения «ИИ» (честность R1); офлайн-подпись
  остаётся видимой в карточке как «словарь». Ручная правка (если будет) — lock, перегенерация не перетирает.
- Валидация ответа: число слов совпадает со строкой, каждое слово отвечено, span сочетаний внутри строки;
  иначе строка помечается «ИИ: не удалось» и показывается офлайн-слой (никакого тихого смешения).

## 3. Качество — как будем мерить (до релиза)

Слепая выборка 60 слов на «Шура» до/после + отдельная выборка из известных ошибок шага 1 (חָלָל, הוֹרָדָה,
אֲוִירָה, אִי אֶפְשָׁר, вид глагола). Цель: вводящих в заблуждение ≤2%, покрытие ≥97%. Обязателен прогон
с реальным ключом до релиза (урок feedback_llm_path_test_before_ship).

## 4. Стоимость (замер на реальном ключе)

| Модель | Вводящих в заблуждение (слепые выборки) | $ / 1000 слов | Весь «Шура» (5.6 тыс. слов) | 20 строк |
|---|---:|---:|---:|---:|
| gemini-3.8-flash (выбрана) | ≈2% | ≈0.13–0.15 | ≈$0.8 | ≈50 с |
| gemini-3.5-flash-lite | ≈5% | ≈0.01 (оценка тарифа) | ≈$0.06 | ≈8 с |

Черновая оценка $0.14/текст была неверной: не учитывала токены «размышления» (уровень medium по политике
проекта) — они составляют около половины выхода и являются накладными на запрос; пакет из 3 строк стоил
за слово ≈6× дороже, чем 8–12 строк. Отсюда: ленивый режим запрашивает звучащую строку + 7 следующих.
Платит ключ пользователя; повторное чтение того же текста — из серверного кэша, бесплатно.

## 5. Решения владельца (2026-10-11)

1. Запуск: кнопка «Перевести все слова текста (ИИ)» (оценка + согласие) **и** ленивый режим при
   включённом тумблере «Перевод слов ИИ (Gemini)» — по умолчанию выключен (D2).
2. Модель: gemini-3.8-flash; flash-lite замерена — ошибок больше на ≈3 п.п. (> порога 1 п.п.), не включена.
3. Проверка до релиза — реальным ключом из файла вне репозитория (замер, маршрут, живой браузерный прогон).

## 6. Реализация (3.11.741)

- Сервер: `ingest/wordGlossCtx.js` (промпт, схема, строгая валидация), сценарий `word-gloss-ctx` в
  `ingest/geminiPolicy.js`, маршрут `/api/word-gloss-ctx` (BYOK, ≤12 строк, кэш по строке без подсказок,
  свой лимитер 60/мин). Тесты `tests/wordGlossCtxRoute.test.js`.
- Клиент: `public/js/word-gloss-ai.js` (IndexedDB по ключу содержимого строки, пакеты по 8, до 3 параллельно,
  ленивый режим через IntersectionObserver + смену звучащей строки); `WordGloss.apply({ai})`; подписи ИИ
  выделены цветом (происхождение), сочетание — в подсказке слова и в ленте.
- Хранение: локально (IndexedDB) + серверный кэш оплаченных строк; экспорт карточки не нужен — потеря
  локального кэша не стоит денег. Карточка по тапу пока показывает словарный разбор (ИИ — следующий шаг).
- Гейт: `node scripts/premium/word-gloss-ai-smoke.js [--live-key-file …]` (подмена ответа + живой прогон).
