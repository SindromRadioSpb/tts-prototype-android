## Модель и приоритеты

- Раздельные факты: значение поля, источник/способ получения, привязка к исходной строке, статус проверки. Метаданные не доказывают языковую правильность.
- Источник поля проходит через существующие field_meta / edit_meta_json и переносимые строки. Значения не переписываются для исправления подписи. Нет достоверных метаданных — неизвестный источник.
- Идентичность вхождения не равна ключу кэша. Постоянная строка имеет stable/portable ID; новая привязка проверяет содержимое. Временная строка имеет локальную идентичность в пределах её набора.
- Приоритет: собственная ручная правка вхождения → импортированный/полученный gloss вхождения → прежний оплаченный общий ответ с отмеченной областью происхождения → явно словарный fallback (или пропуск в строгом режиме).
- Старый общий ответ не позволяет восстановить утраченные различия. Импорт оригинального архива может восстановить их, сохранив собственные ручные правки. Автоматического повторного платного запроса нет.
- ИИ-предложения не записываются как owner/teacher lexical decisions. Подтверждённые решения используют существующие anchors, события и отмену. Статусы знания/FSRS не мигрируют по gloss.
- Новая информация не отменяет обоснованное чтение без явного подтверждения; не создаётся общий корень для имени и прилагательного (R1/R10/R11).
- Переносимость и откат без удаления старого кэша, исходников, ручных исправлений и learner state (R9/R13/R16).
