# Слой слов после Ф2: откуда пропуски и что даст каждый шаг (2026-10-11)

Повод: владелец на проде (3.11.739, карточка «До последнего имени», вкладка Зала через Kapture):
«много слов без перевода», «картина сырая». Вопрос: можно ли значительно лучше без ИИ.

## Факт на проде

Подсчёт в DOM вкладки владельца совпал с офлайн-замером: 5641 слово огласованной колонки,
подпись у 4282 (75.9%), без подписи 1359 (24.1%). Среди пропусков — самые частые простые слова
(וְאָז, שֶׁזֶּה, בְּכָל, כָּזֶה, כְּאִלּוּ, הֲמוֹן, בֶּאֱמֶת, חַיִּים, הַרְבֵּה, בַּסּוֹף, לַמִּשְׁפָּחָה).

## Причины пропусков (доля от всех слов)

| Класс | Доля | Примеры | Чем лечится |

## Симуляция без генеративного ИИ (Dicta из Ф0, рабочий резолвер, ru-forms)

Покрытие **75.9% → 92.2%** (A +225, B +523, Bi +45, C +74, E +50). Ручная проверка 50 случайных
восстановленных подписей: **39 верно, 11 неверно (22%)** — неверный омоним при стыковке леммы Dicta с
Pealim (לַגִּיל «радость», הַמְּפַקֵּד «перепись», בְּנֵי «дикий», אֶפְשָׁר «предоставлять»), ложная
приставка у коротких слов (בָּאךְ, וּמַכָּה), сочетания (מוֹצָאֵי), испорченный исходник.
Итог по всем показанным подписям при таком включении «как есть»: ~10% вводят в заблуждение (сейчас ~8%).

Вывод: A, C, E безопасны и дешевы (точность высокая при защите коротких слов); B даёт больше всего
покрытия, но требует выбора омонима — по огласованной лемме Dicta, иначе 20% ошибок.

## Что без ИИ не решается

Выбор значения в контексте (גיל возраст/радость, מפקד командир/перепись, משפט суд/фраза),
сочетания (מוצאי שבת, בני אדם), естественный русский (вид: «происходил» → «произошло»),
испорченные ASR-строки. Это ровно задача Ф3 (Gemini-глосса по контексту).

## Рекомендация

1. Детерминированная волна (≈Ф2.5, $0): A с защитой коротких слов, C, E/числа, D-наречия списком,
   B с выбором омонима по огласовке леммы Dicta; Dicta-контекст брать из уже существующего
   `sentence_morph` / Tier-3 при согласии. Цель: покрытие ~90% при точности ≥92%, офлайн-фолбэк.
2. Ф3 (Gemini, опция): смысл в контексте, сочетания, естественная форма; подаётся разбор Dicta как

3. UI (длинные ленты, «?», столбики слов на 380px) — отдельная итерация по выбору владельца.

Скрипты замера: `E:/tmp-lp/classify.cjs`, `E:/tmp-lp/sim.cjs` (вне репозитория, на данных Ф0).

## Шаг 1 реализован (3.11.740)

`ReaderMorph.enrichReading` — офлайн-обогащение нерешённых чтений (unknown / guessed / likely),
общее для подстрочника, ленты и карточки по тапу; `resolveCore` не тронут, ключ статуса слова прежний.

| Источник | Слов на «Шура» |
|---|---:|
| форма без букв-помощниц (`canonForm`, однозначная парадигма) | 460 |
| лексикализованные наречия (по огласованной форме) | 169 |
| служебное слово за приставкой (с проверкой огласовки приставки) | 131 |
| наречие за приставкой | 17 |
| имя / название (метка вместо «?») | 28 |

Покрытие **75.9% → 88.2%** (4976/5641), перевод формы у 2274 слов. Слепая выборка 60 показанных
подписей: вводят в заблуждение 4 (≈7%) — омонимы (חָלָל, הוֹרָדָה, אֲוִירָה) и сочетание (אִי אֶפְשָׁר);
ещё 2 — вид глагола («понимал» вместо «понял»). Всё это — зона Ф3.

Правила, найденные по ходу (закреплены `tests/wordLayerEnrich.test.js`):
- чтение по форме без букв-помощниц помечается «вероятно» (≈), не «точно»: метка «точно» на архаичном
  эталоне снижала честную деградацию 81.8% → 62%; с «вероятно» — 82.3%, контроль 35/36 без изменений;
- артикль ה не стоит перед частицей (הַאִם — вопросительное ה, не «если»);
- «вероятное» наречие и набор местоимений не разбираются на приставку (לְכָאן «сюда», מֵאָז, לְמָה).
