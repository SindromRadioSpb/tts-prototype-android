# Ф4 · «Мой словарь» — учебная среда (КОНЦЕПЦИЯ, решения владельца приняты 2026-10-12)

Дата: 2026-10-12. Запрос владельца: «полноценный "Мой словарь" для пользователя, который также будет учебной
средой: фильтры, сортировка, интеракция, спряжения и склонения, и другой функционал, раскрывающий
образовательный процесс». Канон слоя слов: [../WORD_LAYER_RESEARCH_AND_PLAN_2026_10_11.md](../WORD_LAYER_RESEARCH_AND_PLAN_2026_10_11.md) §4 («экран
"Мой словарь" строится поверх word_status / word_context / review_log по ключу lemma-canon»).

## 1. Опись: что уже есть (не дублировать, а собрать в одно место)

**Пробел:** нет места, где видны **все мои слова из всех текстов** сразу — с поиском, фильтрами, сортировкой,
полной статьёй слова и запуском обучения по выбранному набору. Всё перечисленное выше разбросано по Залу, Студии
и карточке одного слова.

## 2. Концепция

**Запись словаря = лемма** (ключ `lemma-canon`, как у статусов и повторений). Новых хранилищ нет: словарь — это
представление над `word_status` + `word_context` + `review_log` + заметки `word_study` + слой ИИ + офлайн-парадигмы.

### 2.1 Список (экран словаря)
- **Колонки/поля:** слово с огласовкой и лемма · значение (ваше → словарное) · часть речи, биньян, корень ·
  статус · сила памяти и дата повторения (FSRS) · сколько раз встретилось и в скольких текстах · когда добавлено /
  когда видели последний раз. На телефоне — карточки-строки, на ПК — таблица.
- **Поиск:** иврит без огласовки и с ней, русский по значению, корень.
- **Фильтры:** статус · «к повторению сегодня / просрочено / трудные (пиявки)» · часть речи · биньян · корень ·
  источник (текст, подборка Медиатеки, Бен-Иегуда) · есть ваш перевод/заметка · частотность в ваших текстах ·
  период добавления. Сохранённые наборы фильтров («глаголы пиэль к повторению»).
- **Сортировка:** по алфавиту иврита · по дате добавления · по дате повторения · самые слабые (сила памяти, срывы) ·
  самые частые в моих текстах · недавно встреченные · группой по корню.
- **Массовые действия над выбранным/отфильтрованным:** учить эти · сменить статус · выгрузить (Anki / таблица).

### 2.2 Статья слова (тап по записи)
Одна страница, всё о слове: озвучка · значения (ваше, словарное, все переводы ИИ из разных строк) · **все места
в ваших текстах** — предложение, перевод в контексте, переход к строке и ▶ к моменту видео · **спряжение /
склонение** с подсветкой форм, которые вы встречали, и русским в каждой клетке · семья корня с вашими статусами ·
ваша заметка · история памяти (повторения по дням, сила, следующий срок) · статус и «не учить».

### 2.3 Учебная среда (то, чего нет нигде сейчас)
- **«Учить эти»** — запустить существующую тренировку (каналы, уровни, FSRS) на ЛЮБОМ наборе из словаря, а не
  только на очереди «к сроку».
- **Тренировка форм** (новое): по таблице спряжения — «скажи/напиши форму: мы, прошедшее» → проверка по Pealim;
  начинается с форм, встреченных в ваших текстах.
- **Слово в своих предложениях:** пропуск слова в ДРУГОМ его месте из ваших текстов (не там, где учили) —
  проверка, что слово узнаётся в новом контексте.
- **Корень как гнездо:** «учить семью корня» — известные слова корня как опора для новых.
- **Прогресс словаря:** сколько слов в каждом статусе, сколько стало «знаю» за неделю/месяц, слабые места
  (часть речи / биньян с наибольшим числом срывов) → кнопка «тренировать это».

## 3. Решения владельца (нужны до проекта экрана)

1. **Где живёт словарь.** (а) новый пункт нижней навигации «Словарь» рядом с «Повторением»;
   (б) «Повторение» становится разделом «Словарь» с вкладками «Слова | Повторение | Прогресс»;
   (в) отдельная страница, вход из «Аа» Зала и из Студии.
2. **Что считается «моим словом».** (а) только то, что вы отметили: статус, «добавить в мои слова», заметка,
   повторение; (б) плюс все слова, встреченные в ваших текстах (тысячи; «не отмеченные» — отдельный фильтр);
   (в) (а) по умолчанию, (б) переключателем.
3. **Первая очередь.** (а) список + фильтры + сортировка + статья слова со спряжением, затем учебные режимы;
   (б) сразу список + «учить эти» + тренировка форм, статья слова — следом.
4. **Выгрузка.** Anki уже есть; нужна ли таблица XLSX по образцу вашего прототипа?

**Решения владельца 2026-10-12:** 1 — **(новый пункт нижней навигации «Словарь»)**; 2 — **(в)** отмеченные по
умолчанию + переключатель «все встреченные в моих текстах»; 3 — **(а)** первая очередь: список + фильтры + сортировка +
статья слова, затем учебные режимы; 4 — XLSX **да, позже**.
