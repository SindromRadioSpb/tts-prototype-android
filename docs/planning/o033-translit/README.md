## Что в ветке `feat/modern-translit`

`public/js/translit-modern-reading.js` готовит огласованный текст до библиотеки hebrew-transliteration:

1. **Удвоенные ו/י полного написания** (все профили): голая ו/י сразу после огласованной той же буквы не читается (מִצְוָוה → mitsva, אֱיָיל → eyal). Исключение: י после י с хириком — это «мать чтения» (חַיִּים).
2. **Немой алеф** (learner-latin, ru-phonetic): א без своей огласовки, не в начале слова, удаляется (הוּא → hu); кроме начала гласной вав (לְאוֹר → le'or).
3. **Современный шва** (learner-latin, ru-phonetic): звучащий шва заменяется хатаф-сеголем («e»), остальные — немые. Звучит: в начале основы под י ל מ נ ר ו; перед א ה ע י; между похожими согласными (та же буква, ב перед ו, зубной перед зубным/свистящим); второй из двух шва подряд; перед той же буквой. «Начало основы» — после проклитик с полной гласной и дагешем в следующей букве (артикль и т. п.). Слово без единой гласной (שְׁשְׁשׁ) не трогается.

SBL остаётся классической академической транскрипцией. Версии профилей в `db/premium/versions.js` подняты (только метаданные); ключ кэша премиум-конвейера `both-v2` намеренно не менялся — его смена вызвала бы платный повторный перевод.

Тесты: `tests/translitModernReading.test.js` (эталон из слов «Sweet Mud»), `tests/premium/*translit*`. Полный набор на ветке — 2224/2224.

## Закрыто в 3.11.685 (2026-09-28): ошибки модели огласовки

Решение владельца: (а) второе мнение Dicta только для подозрительных строк, согласие один раз на сборку; иначе (б) пометки в таблице.

- **Правила** (`public/js/niqqud-plausibility.js`): два шва в начале слова, дагеш не-бгдкфт сразу после шва, три шва подряд (кроме конечной буквы). Замер на 209 476 проверенных формах Pealim: дагеш — 0 срабатываний, два шва — 1 (שְׁטְרוּדֶל), три шва — 26 (телеграф-заимствования). Поэтому это повод посмотреть ещё раз, а не вето.
- **Сборка из субтитров**: после огласовки — шаг лестницы «Сверка сомнительных слов с Dicta» (пропускается без подозрительных слов). Один `confirm` на сборку; в Dicta уходят только исходные строки с подозрительными словами (без огласовки и перевода), `purpose: SUBTITLE_CHECK`, по 40 строк. Меняются только подозрительные слова и только на слово Dicta с теми же буквами, прошедшее те же правила. Dicta отвечает неполным написанием — `fillMatres` возвращает её огласовку на полное написание субтитра (לְקָרָטֶה → לְקָרָאטֶה, כֹּל → כּוֹל). Совпадение с моделью = независимое подтверждение (заимствование), слово запоминается на устройстве. Отказ, выход из аккаунта, недоступность Dicta — сборка не падает, итог в тосте.
- **Пометки в таблице Студии** (`public/js/niqqud-suspect-marks.js`): считаются из огласовки при каждой отрисовке, для любой карточки; не ставятся на строки с правленой вручную огласовкой и на подтверждённые Dicta слова. Значок — пустой span с текстом из CSS, в копирование и правку не попадает; `reader-morph.js` сохраняет его при разметке слов.
- Живой замер: реальный ответ Dicta на 8 строк с ошибками «Sweet Mud» — исправлены 8 из 8 (Tnagev, Lekarate, Lesibuv, Afarsekim, Listefan, Safarnu, Leshavu'a, Stefan); ответы записаны в `tests/subtitleSecondOpinion.test.js`.

## Закрыто в 3.11.683–684 (2026-09-28)

- Кавычки в «зеркальных» строках (15 строк вида `".לבוא`): группа с кавычкой и знаком препинания переносится в конец в обратном порядке (3.11.684, `normalizeVisualPunctuation`). Действует при следующей сборке из видео; сохранённые карточки не меняются.

- Гереш: ג' ז' צ' (ASCII-апостроф, ’ или ׳, огласовка до или после знака) читаются как j/zh/ch, ǧ/ž/č, дж/ж/ч. Проход современного чтения переносит знак перед буквой как ׳ (`markGeresh`); библиотека держит его рядом с выводом буквы, профиль заменяет пару (`_geresh` в `db/premium/translit.js`). На проде до выпуска «גַ'חְנוּן» давал gakhnun'.
- Заимствования с удвоенной буквой: список `GEMINATE_LOANS` (יאללה, וואללה, ואללה, אללה) по согласным исходного слова — yalla, valla. Растёт только из проверенных слов.
