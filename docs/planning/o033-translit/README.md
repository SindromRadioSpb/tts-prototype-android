## Что в ветке `feat/modern-translit`

`public/js/translit-modern-reading.js` готовит огласованный текст до библиотеки hebrew-transliteration:

1. **Удвоенные ו/י полного написания** (все профили): голая ו/י сразу после огласованной той же буквы не читается (מִצְוָוה → mitsva, אֱיָיל → eyal). Исключение: י после י с хириком — это «мать чтения» (חַיִּים).
2. **Немой алеф** (learner-latin, ru-phonetic): א без своей огласовки, не в начале слова, удаляется (הוּא → hu); кроме начала гласной вав (לְאוֹר → le'or).
3. **Современный шва** (learner-latin, ru-phonetic): звучащий шва заменяется хатаф-сеголем («e»), остальные — немые. Звучит: в начале основы под י ל מ נ ר ו; перед א ה ע י; между похожими согласными (та же буква, ב перед ו, зубной перед зубным/свистящим); второй из двух шва подряд; перед той же буквой. «Начало основы» — после проклитик с полной гласной и дагешем в следующей букве (артикль и т. п.). Слово без единой гласной (שְׁשְׁשׁ) не трогается.

SBL остаётся классической академической транскрипцией. Версии профилей в `db/premium/versions.js` подняты (только метаданные); ключ кэша премиум-конвейера `both-v2` намеренно не менялся — его смена вызвала бы платный повторный перевод.

Тесты: `tests/translitModernReading.test.js` (эталон из слов «Sweet Mud»), `tests/premium/*translit*`. Полный набор на ветке — 2224/2224.

## Как выпустить после «утверждаю»

1. `git merge feat/modern-translit` в рабочую ветку (конфликт возможен только в `public/index.html` — строка `cache.translitProfileVersion`).
2. `npm run build:local-translit` (бандл уже собран в ветке; пересобрать, если правила менялись).
3. Поднять версию синхронно: `?v=` у `/js/local-translit-bundle.js` (сейчас 573) в `public/index.html`, `public/sw.js`, `server.js`; `APP_VERSION`, `CACHE_VERSION`, футер `library.html`.
4. `npm test`, `node --test tests/i18n.smoke.js`; push `HEAD:main`; проверить `/sw.js` и `/healthz` (диск; кэш сборки можно чистить по постоянному разрешению).
5. ~~Уже сохранённые карточки не пересчитываются сами.~~ С 3.11.679 колонка выводится из огласовки при показе; см. «Закрыто» ниже.

## Открыто (не входит в эту волну)

- Ошибки модели огласовки (אַפְרְסְקִים, תְּנְגֵּב, בְּקְרָאטָה, לְסִּיבּוּב с лишним дагешем): применить на пути субтитров словарь проверенных форм (`canonicalizeKnownNiqqudRows` на пути Gemini) или свой.
- Приставка против корня (bmahalakh, bgadim): без морфологии не различить.
- Кавычки в «зеркальных» строках субтитров блокируют перенос точки (15 строк вида `".לבוא`), см. O-032.

## Закрыто в 3.11.683 (2026-09-28)

- Гереш: ג' ז' צ' (ASCII-апостроф, ’ или ׳, огласовка до или после знака) читаются как j/zh/ch, ǧ/ž/č, дж/ж/ч. Проход современного чтения переносит знак перед буквой как ׳ (`markGeresh`); библиотека держит его рядом с выводом буквы, профиль заменяет пару (`_geresh` в `db/premium/translit.js`). На проде до выпуска «גַ'חְנוּן» давал gakhnun'.
- Заимствования с удвоенной буквой: список `GEMINATE_LOANS` (יאללה, וואללה, ואללה, אללה) по согласным исходного слова — yalla, valla. Растёт только из проверенных слов.
