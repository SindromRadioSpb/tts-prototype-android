# Огласовка и транслитерация LinguistPro

Правила и отчёт проверки от 6 октября 2026 года. Версия приложения: **3.11.735**.

## Пример из «בֶּרְל כַּצֶּנֶּלְסוֹן»

В строке 02 написано `יְדִידְכֶם הַגָּדוֹל – אֵינֶנּוּ.`. Слово `הַגָּדוֹל` передаётся так:

| Профиль | Результат |
|---|---|
| Учебная латиница | `Hagadol` |
| SBL | `haggāḏôl` |
| Русская фонетика | `хагадол` |

Удвоенное `gg` в SBL правильно: сильный дагеш после определённого артикля обозначает удвоение. Современные фонетические профили его не произносят.

## Где читать правила SBL

[The SBL Handbook of Style, 2-е издание, §5.1.1](https://www.stpaulsem.com/wp-content/uploads/2022/06/The-SBL-Handbook-of-Style-by-Society-of-Biblical-Literature-z-lib.org_.pdf#page=72): печатные страницы 56–58, страницы PDF 72–74. Раздел §5.1.1.4(5) объясняет сильный дагеш; §5.1.1.4(6) — шва.

Профиль LinguistPro использует академическую схему SBL с последовательным обозначением спирантизации BGDKPT: например, `ḇ`, `ḡ`, `ḏ`, `ḵ`, `p̄`, `ṯ`. Это выбранный вариант академической схемы; руководство допускает обозначение этих различий, когда оно существенно. Поэтому `ḏ` в `haggāḏôl` не является указанием произносить современное ד как английское th.

Сильный дагеш удваивает согласную; слабый дагеш этого не делает. Гласные и буквы чтения различаются (`ā`, `î`, `ô`, `û`), алеф и айн обозначаются `ʾ` и `ʿ`, звучащий шва — `ə`; немой шва не получает гласной. Эта схема представляет написание и традиционные категории, а не только современную речь.

Техническая основа: [hebrew-transliteration](https://github.com/charlesLoder/hebrew-transliteration) и [документация библиотеки](https://charlesloder.github.io/hebrew-transliteration/getting-started/quick-start/). В релизе используется закреплённая версия 2.9.1; документация сайта может описывать более новую версию.

## Правила «Учебной латиницы»

«Учебная латиница» — собственная учебная конвенция LinguistPro для современного израильского чтения. Отдельного международного стандарта с таким названием нет. Этот раздел фиксирует правила профиля; он не тождествен SBL Simple.

Гласные записываются `a, e, i, o, u`, без знаков долготы и ударения. Цере и сеголь передаются через `e`; камац катан — через `o`. Чтение шва зависит от слова и современной морфологии: `תְּנַגֵּן → Tenagen`, но `תְּנוּעָה → Tnu'a`; `שֶׁלְּךָ → Shelkha`, `וְמְתוּקָה → Vemetuka`.

| Буквы | Учебная латиница |
|---|---|
| בּ / ב | b / v |
| ג, ד | g, d |
| ה / ח | h / kh |
| ו, ז, י | v, z, y |
| כּ / כ, ך | k / kh |
| ט, ת / ק | t / k |
| ל, מ, נ, ר | l, m, n, r |
| פּ / פ, ף | p / f |
| צ / שׁ / שׂ, ס | ts / sh / s |
| א, ע | апостроф внутри слова; начальный знак перед гласной опускается |

Буквы чтения дают гласную, без лишней согласной. Согласные ו/י в полном написании сохраняются. Конечная немая ה не даёт `h`. Дагеш не удваивает согласную. Суффикс `ָיו` читается `av`: `אֵלָיו → Elav`. Вынесенный патах читается перед конечной гортанной: `רוּחַ → Ruakh`, `נוֹסֵעַ → Nose'a`; обычное `רַע → Ra'` сохраняет порядок. Гереш в заимствованиях: `ג׳ → j`, `ז׳ → zh`, `צ׳ → ch`. Начало предложения получает заглавную букву.

## Русская фонетика

Использует то же современное чтение слова, что учебная латиница, с кириллической записью: `kh/h → х`, `ts → ц`, `sh → ш`, `y → й`; алеф и айн не получают отдельной согласной. Сеголь/звучащий шва записываются `э`, цере — `е`. Удвоения дагеша и академические различия `ḡ/ḏ/ṯ` не воспроизводятся.

| יְאָרְחוּ | ошибочное `o` | `Ye'arkhu`, `йэарху` |
| הַכָּל | `Hakal`, `hakkāl`, `хакал` | `Hakol`, `hakkol`, `хакол` |
| וְמְתוּקָה | пропущенный шва основы | `Vemetuka`, `вэмэтука` |

Маккеф и соф-пасук больше не считаются огласовками при переносе знаков на исходный текст. Реальная пунктуация гереш отделена от внутреннего маркера движка. Противоречащие друг другу гласные на одной букве и одновременно две точки шин/син помечаются для проверки.

Архитектура чтения общая для сервера и браузера: исходные графемы → качество гласных и современное чтение → выбранный профиль. Вместо замены фрагментов готовой транслитерации используется воспроизводимый словарь решений для шва/камаца из уже поставляемых таблиц Pealim. При неоднозначном сопоставлении словарное решение не принимается. Ручные исправления огласовки и транслитерации сохраняются; переключение профиля не требует платного запроса к модели.

## Проверки и границы автоматизации

Проверены все 198 строк указанного текста во всех трёх профилях, 1 268 разных слов, матрица правил и совпадение браузера с сервером. Дополнительно сопоставлена детерминированная выборка из 5 947 слов существующего словаря Pealim: число расхождений с его русской записью снизилось с 1 690 до 1 491; новых расхождений в этой выборке нет. Это сравнение записи, а не оценка лингвистической точности: часть оставшихся различий относится к условностям кириллицы.

Автоматическая огласовка не может гарантированно выбрать значение каждого неогласованного омографа, имя собственное или авторское написание. Полностью одинаковая огласовка также иногда допускает разные современные чтения. Такие случаи требуют контекста или редакторской проверки. Исходные тексты и сохранённые результаты провайдеров не переписывались массово. Исправления механизма не означают филологическую редактуру всего корпуса.
