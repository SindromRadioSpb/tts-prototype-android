# Local ASR Companion: התקנה ושימוש

Local ASR מתמלל אודיו בעברית במחשב Windows שלכם. אחרי שגיאת Local ASR קובץ האודיו אינו נשלח אוטומטית ל-Gemini; מעבר ל-Gemini הוא ידני ודורש אישור נפרד.

המדריך מיועד לבטא בהזמנה בלבד. התצורה הנתמכת היא **Windows 11 + NVIDIA/CUDA תואמים + Chrome**. Edge ו-Firefox אינם נתמכים בבטא הראשונה.

RU: `/docs/LOCAL_ASR_COMPANION_GUIDE.md`. EN: `/docs/LOCAL_ASR_COMPANION_GUIDE.en.md`.


## המסלול הקצר

1. התקינו את **LinguistPro Local ASR Companion** שסופק בהזמנה.
2. פתחו **התחל של Windows → LinguistPro → LinguistPro Local ASR Companion**.
3. המתינו למצב **Companion: RUNNING**.
4. באזור **Connect LinguistPro in Chrome** לחצו **Copy token for browser**.
5. חזרו ל-LinguistPro: **הגדרות → Experimental Local ASR**.
6. הדביקו את האסימון בשלב 2 ולחצו **חיבור**.
7. הפעילו בדיקת מכשיר, התקינו את המודל ובצעו warmup.
8. פתחו ייבוא אודיו ובחרו במפורש **Local**. Gemini נשאר ברירת המחדל.


## מאיפה מקבלים את אסימון הצימוד

ה-Companion יוצר את האסימון אוטומטית. אין צורך למצוא קובץ, להמציא אסימון או להשתמש בשורת פקודה.

1. הפעילו את ה-Companion מתפריט התחל.
2. מצאו בחלק העליון את האזור **Connect LinguistPro in Chrome**.
3. לחצו **Copy token for browser**.
4. חזרו ללשונית LinguistPro, הדביקו ולחצו **חיבור**.

LinguistPro שומר את האסימון רק בסשן הדפדפן הנוכחי. אחרי סגירת הלשונית יש לחזור על ארבעת השלבים. אל תשתפו את האסימון ואל תכללו אותו באבחון או בצילום מסך.


## התקנת Companion

המתקין של בטא פנימית זו אינו חתום. השתמשו רק בקובץ שהתקבל בהזמנה מהימנה ואמתו SHA-256 מול הסכום שסיפק הבעלים לאותה גרסה.

אם Windows מציג SmartScreen, המשיכו דרך **מידע נוסף → הפעל בכל זאת** רק לאחר שהשם וה-SHA-256 תואמים. עצרו אם הסכום חסר או שונה. ההתקנה היא למשתמש הנוכחי ואינה דורשת Python, venv או Uvicorn ידניים.


## בדיקת המחשב

לחצו **הפעלת preflight** במסך Local ASR. הבדיקה כוללת Windows 11, ‏NVIDIA/CUDA ו-VRAM פנוי, מקום בדיסק, פורט מקומי `127.0.0.1:8799`, ו-FFmpeg/FFprobe המצורפים. תקנו בדיקה שנכשלה לפני ההמשך. אין fallback נסתר שמשנה מודל, compute/decode, ‏VAD או timestamp policy.


## התקנת המודל

המודל יורד רק אחרי אישור. גודל ההורדה כ-**1.62 GB**, ונדרש מקום נוסף לאימות ולהפעלה בטוחה.

רק המודל הבא מורשה:

`ivrit-ai/whisper-large-v3-turbo-ct2@72ad623a37947395efcc3933132353790e5a12f5`

ה-Companion מאמת revision מדויק ו-SHA-256 של כל קובץ runtime לפני הפעלה. הורדה פגומה או חלקית אינה מופעלת. אפשר לבטל ולנסות שוב.


## תמלול אודיו

1. ודאו שה-Companion פועל, הדפדפן מחובר, המודל מאומת וה-warmup הסתיים.
2. פתחו ייבוא אודיו ובחרו קובץ.
3. בחרו במפורש **Local** כספק.
4. התחילו תמלול והמתינו למצב סופי.
5. בדקו את הטקסט ושמרו את הכרטיס בדרך הרגילה.

Gemini אינו מופעל אוטומטית אחרי שגיאת Local. כדי לנסות עם Gemini, עברו אליו ידנית ואשרו בנפרד העלאה לענן.


## חזרה לאחר זמן

1. פתחו את ה-Companion מתפריט התחל.
2. לחצו **Start** אם השירות עצר, או **Restart** אם המצב תקוע.
3. לחצו שוב **Copy token for browser** וחברו את הלשונית הנוכחית.
4. אין צורך להוריד שוב מודל שמוצג כ-**Verified and ready**.
5. בכל ייבוא חדש בחרו שוב **Local** במפורש.


## שגיאות נפוצות

| הודעה | פעולה |
|---|---|
| Companion אינו זמין | פתחו אותו, לחצו Start או Restart והעתיקו שוב את האסימון. |
| הצימוד נכשל | העתיקו את האסימון הנוכחי, החליפו את כל תוכן השדה ולחצו חיבור. |
| פורט 8799 תפוס | סגרו את התוכנה האחרת או הפעילו מחדש אחרי שחרור הפורט. |
| מעט מקום בדיסק | פנו מקום והריצו preflight שוב. |
| Model integrity / checksum | מחקו דרך הכפתור המנוהל ונסו שוב את אותה pinned revision. |
| OOM / אין די VRAM | סגרו יישומי GPU, הפעילו מחדש ונסו שוב. אין CPU fallback נסתר. |
| Warmup נכשל | בדקו preflight ומודל, לחצו Restart ובצעו warmup שוב. |


## נתונים, אבחון והסרה

- **Delete model** מוחק את המודל הנעול.
- **Delete jobs** מוחק משימות מקומיות, מדיה ותוצאות.
- **Export redacted diagnostics** אינו כולל אודיו, טקסט תמלול, שם קובץ מקורי או אסימון צימוד.
- הסרה עוצרת את השירות ומוחקת model/jobs/state מנוהלים של משתמש Windows זה.

שמרו כרטיס טקסט נחוץ בספריית LinguistPro לפני מחיקת משימות Local ASR.


## גבול הפרטיות

ה-Companion מאזין רק ב-`127.0.0.1:8799`. אסימון צימוד, בדיקות Origin/PNA/CORS ומגבלת גוף בקשה נשארים חובה. מדיה ותוצאות נשמרות בתיקיות המנוהלות של משתמש Windows הנוכחי.

דף LinguistPro ותכונות אחרות שתבחרו עשויים להשתמש ברשת. משימת ASR זו אינה מעלה לענן אלא אם תבחרו Gemini ידנית ותאשרו את המעבר.
