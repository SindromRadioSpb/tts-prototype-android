# P7.2a reverse:tg — измерение неоднозначности RU-глосса (R10 measure-before-code)

**Что:** замер, насколько русский глосс `pealim-infl-v12` однозначно указывает на ОДНО ивритское
слово — вход в eligibility-политику reverse:tg (owner-запрос 2026-07-07). **Как:** `measure.js`
гунзипит `public/data/inflection/pealim-infl-v12.json.gz` (9279 парадигм), нормализует RU-глосс
(lowercase, ё→е, убрать скобки), строит карту `сенс → множество лемм`. **Результат:** `results.txt`.
**Источник-коммит:** ветка main на дату каталога. **Раздел:** raw-замер; редактировать — `measure.js`.

## Ключевые числа

| Метрика | Значение |
|---|---|
| Покрытие meaning | 100% (9279/9279) |
| Глоссы-перечисления (`/`,`;`, «или») | 60.2% |
| Коллизия RU→HE (сенс → >1 разная лемма) | 57.3% |
| «Безопасный строгий reverse» (1 сенс, ≤3 слов, без коллизии) | **25.5%** |

## Вывод для дизайна

Наивный строгий reverse наказал бы ~75% ответов за валидный синоним. Карта `сенс→леммы` = набор
допустимых синонимов (деривируется из датасета) → коллизия становится премиальной фичей:
синоним-приём (abstain, не lapse). Конкретика — в
`docs/planning/TELEGRAM_P7_2_REVIEW_SPEC_2026_07_07_v3.md`.
