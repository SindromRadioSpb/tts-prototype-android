# R0 — доставка новой версии: диагноз

**Источник:** `npm run smoke:sw-update` (`scripts/premium/sw-update-browser-smoke.js`), локальный сервер + переписывающий прокси, Chromium (Playwright 1.60), 2026-09-25, база `aec96a26`.

## Как устроен стенд
- Сервер отдаёт релиз N (3.11.635). Прокси на :3308 умеет «выкатить» N+1: заменяет строку версии в `sw.js`, `/api/client-config` и HTML-оболочках и пересчитывает для них хеши `shellIntegrity`, как это сделал бы настоящий деплой. Режим `mixed` имитирует катящийся деплой: новый `sw.js`, старый `client-config`, поэтому установка нового воркера честно проваливается.
- Каждая HTML-оболочка получает служебную метку `<meta name="lp-test-release">`: так версия документа читается одинаково в Студии, Зале и Медиатеке.
- Сценарии стартуют из вкладки, уже управляемой воркером (как у установленного пользователя).

## Что нашли
1. **O-001 воспроизведён (E):** если во время катящегося деплоя установка воркера провалилась, после схождения две обычные перезагрузки дают старую версию. Релиз доставляет только тост.
2. **Медиатека** не искала обновлений сама (нет `registration.update()` при загрузке, возврате на вкладку и по таймеру). Исправлено. Нажатие на баннер теперь решает по актуальной регистрации: есть ожидающий воркер → `SKIP_WAITING` с одной переотправкой; нет → перезагрузка.
3. **Попытка «перезагрузка = обновление» (F) откачена.** `skipWaiting()` по запросу страницы при загрузке, если окно одно:
   - сначала взаимная блокировка: `await self.skipWaiting()` внутри `event.waitUntil` (промис `skipWaiting` ждёт активации, а активация ждёт завершения этого же события);
   - после исправления Студия и Зал проходили F, но ранний `skipWaiting()` во время загрузки иногда вводит Chromium в «зависшую активацию»: воркер остаётся `installed`, и после этого не помогает даже тост (E:room краснел). Это хуже исходного состояния, поэтому автоматика откачена. Дальнейшее исследование — O-015.
4. **Первый визит** (страница без контроля SW, релиз в ту же сессию): баннер Медиатеки перезагружает в старую оболочку — O-016.
