## A. LinguistPro (первопартийное приложение)

**Поверхности:** Студия (index.html: создание/импорт текстов, TTS, квизы, заметки, Anki-экспорт, Knowledge Map), Читальный зал (library.html: ~26K корпусных работ Ben-Yehuda + «Мои тексты», морфология-на-тап, scaffolded reading, karaoke, due-кольцо в чтении), Telegram-бот + Mini App (повторение 4 модальностями), Web Push.

**Retention-ядро:** FSRS-6 (fsrs-core.js, байт-парити ts-fsrs), append-only review_log = истина, канонический кейер лемм; модальности: reverse, cloze (из личных текстов, класс C), dictate, listen; D1 channel-aware направление заложено; reading-native retrieval (reveal-карточки в живом чтении) — моат. Штрих: study_day-леджер, all-surface стрик.

**Морфология иврита:** офлайн Pealim-словарь 9 279 парадигм (спряжения/склонения), Dicta-интеграция (морфо-дизамбигуация, niqqud), проклитика-сегментация, честный резолвер (бейдж «точно» только на решающих ячейках), ②-заметки полевой системы (word/niqqud/root/pos/binyan/meaning, 10K+ у владельца), Knowledge Map корней.

**Контент-пайплайн:** корпус-каталог (период→автор→работа), FTS-иврит свой индекс, prebake переводов (Gemini), TTS-озвучка (Google Cloud, karaoke-тайминги), scaffolded niqqud-fade.

**Инфраструктура агентности:** Cloud Learner Graph (сервер: review_log-синк, проекции, оракул replay==stored), артефакт-синк текстов (слим, LWW, tombstones — только что закалено), первопартийный ментор (Telegram/Mini App: объяснения предложений, study summaries, lesson windows, нуджи), consent-механика (классы A–D, per-scope ceremony), BYOK-ключи.

## B. Hermes-мост (AA-слой, 16 MCP-инструментов, v3.11.221)

Чтение: learning_brief, review_summary, due_review_items (слова+глоссы+coarse struggle), learner_profile, progress_delta, explanation_metadata/body, public catalog search, corpus reading content, **личные тексты: каталог (82) + тела окнами по standing-гранту**. Действия: reading/review handoff-ссылки (single-use), propose_action (note/suggestion/open_reading → owner confirm). Связь-статус: connection, access_window.

**Доктрины:** W0 (агент не пишет учебную истину) навсегда; кто учит — не сертифицирует (детерминированный грейдер, анти-циркулярность); ключи заданий агенту никогда; provenance: exposure-леджер (мигр. 053) — метка agent_exposed по реально прочитанным окнам; consent per-scope с PERSONAL-tier.

**Скиллы Hermes (2026-07-19):** «Разбор песни» (reading-first ядро), «Утренний бриф», «Подготовка к чтению» + общая политика тренера.

## C. Известные внутренние гэпы (до внешнего исследования)

1. **Голос отсутствует в связке**: приложение умеет TTS-выход, но НЕТ ASR-входа (произношение/говорение не тренируются нигде); Hermes текстовый (Hermex iPhone — тоже чат).
2. **Агент не видит ②-заметки** (собственные формулировки смыслов владельца) — S4 не начат.
3. **Агент не может создавать контент в приложении**: propose note — да, но не «создать текст в Библиотеке» (нет write-инструмента добавления текста, даже propose-then-confirm).
4. Нет петли ПИСЬМА: пользователь нигде не производит ивритский текст с проверкой.
5. Нет прослушивания вне TTS: подкасты/песни-аудио (реальные записи) не в петле.
6. Этап 2 взвешивания agent_exposed — ждёт данных.
7. Мотивационная петля: пуш «N слов ждут» есть; агентный целеполагающий коучинг (недельные цели, ретроспективы) — только скилл «Утренний бриф», без данных о целях.
8. Один пользователь-владелец; мульти-тенантность архитектурно есть, продуктово не проверена.
