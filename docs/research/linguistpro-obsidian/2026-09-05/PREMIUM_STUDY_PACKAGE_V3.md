# Premium Study Package v3 — архитектура и методика

## 1. Результат

Архив является переносимой учебной проекцией, а не резервной копией канона и
не вторым приложением для интервальных повторений.

- LinguistPro владеет текстом, морфологическими решениями, значениями карточек,
  аудио, статусами слов и FSRS.
- Локальный снимок Pealim является источником парадигм. Экспорт не скрейпит сайт
  и не выводит отсутствующие формы.
- Obsidian хранит читаемый учебный материал, связи, словарные справки и
  пользовательские конспекты.
- Пользовательские заметки создаются вне папки _LinguistPro; generated-слой
  можно безопасно обновлять.

## 2. Методическая модель

### Текст

Один цикл состоит из четырёх проходов:

1. смысл на слух без текста;
2. звук вместе с ивритом и shadowing;
3. проверка перевода и лексики только после собственной попытки;
4. пересказ или преобразование фраз и затем FSRS в LinguistPro.

Материал делится на файлы по 20 фраз. Это ограничивает рабочий экран и позволяет
брать 8–12 фраз на занятие, не превращая 500-строчный текст в одну страницу.
Перевод и транслитерация находятся в свёрнутом callout-блоке. Каждая фраза
связывается с локальными карточками слов.

### Лексика

Фокусный список содержит до 20 уже разрешённых лексем: сначала содержательные
части речи, затем служебные, внутри групп — по частоте в конкретном тексте.
Неоднозначные лексемы не попадают в активный список до решения в LinguistPro.
Это приоритизация материала, а не оценка знания.

Карточка текста требует активного воспроизведения: восстановить иврит по
значению и произнести один исходный контекст. Она не содержит собственного
расписания повторений.

### Формы по частям речи

Во всех случаях показываются только клетки конкретной найденной парадигмы.

| Часть речи | Минимальный продуктивный каркас | Расширенная справка |
|---|---|---|
| глагол | инфинитив; настоящее м. ед., ж. ед., м. мн., ж. мн. | прошедшее, будущее, повелительное, пассивные формы, если они есть |
| существительное | ед., мн., смихут ед., смихут мн. | местоименные притяжательные формы |
| прилагательное/причастие | м. ед., ж. ед., м. мн., ж. мн. | остальные засвидетельствованные клетки |
| предлог | формы с местоименными окончаниями | остальные засвидетельствованные клетки |
| неизменяемое слово | одна словарная форма | нет выдуманной парадигмы |

Минимальный каркас виден сразу; полная парадигма свёрнута. В YAML-свойства
выносятся отдельные поля form_infinitive, form_present_ms и т. д., поэтому вид
«Глаголы» в Bases показывает именно требуемые пользователю колонки.

## 3. Масштабируемая файловая модель

    _LinguistPro/
      Путеводитель.md
      Библиотека.base
      reference/
        lexemes/
          pid-2321.md
      media/
        audio/
          <safe-content-key>.mp3
      texts/
        <text-id>/
          Текст.md
          Учебный маршрут.md
          Фокус на лексику.md
          Лексика.base
          Лексемы/
            pid-2321.md
          Фразы/
            001–020.md
          Разбор/
            cluster-....md
          receipt.json

Общая reference-карточка не содержит предложений или идентификаторов
вхождений. Поэтому экспорт другого текста может записать по тому же Pealim ID
тот же контекст-независимый файл. Значение в конкретном тексте и примеры
находятся только в texts/<text-id>/Лексемы.

Аудио хранится один раз в общем content-addressed каталоге. Имя очищается для
Windows и получает контрольный суффикс, поэтому разные небезопасные ключи не
сливаются.

## 4. Двухфазный экспорт аудио

1. Чистый проектор строит дедуплированный audio_plan.
2. UI загружает ресурсы через существующий same-origin
   ShareService.fetchAudioAsset, не более шести одновременно.
3. Для каждого ключа фиксируется included или missing и машинная причина.
4. Проектор пересобирает заметки. Встроенный проигрыватель появляется только
   для фактически полученного файла.
5. receipt.json фиксирует expected/included/missing/pending и объём байтов.

Частичный отказ не уничтожает весь архив и не создаёт мёртвых аудиоссылок.
Большой исходный видеофайл не включается автоматически.

## 5. Provenance и fail-closed

- study_forms появляется только когда resolver вернул ту же точную pealim_id,
  которая пережила контекстный identity guard.
- Для identity_guarded парадигма кандидата не попадает в учебную карточку.
- Исправления корня и словарного класса выполняются только по точной записи
  локального Pealim snapshot.
- В receipt и projection сохраняется версия модели.
- Технические UUID остаются во frontmatter/HTML-комментариях; CSS snippet
  скрывает metadata-контейнер в учебных страницах. В видимом тексте UUID нет.
- Форма предложения, словарная начальная форма и корень не взаимозаменяемы.
  Нормативные поля, подписи и отказ от синтеза описаны в
  [surface/headword/root contract](SURFACE_HEADWORD_ROOT_CONTRACT.md).

## 6. Obsidian без обязательных community plugins

Основной пакет использует только Markdown, свойства, Bases, вложения, Wikilinks
и сворачиваемые callouts. CSS snippet улучшает RTL и размер иврита, но отсутствие
snippet не ломает данные. Community plugins не являются условием открытия,
миграции или восстановления архива.

## 7. Источники решений

- Израильский официальный справочник по ульпану связывает обучение языку с
  реальными задачами интеграции и общения:
  https://www.gov.il/BlobFolder/generalpage/firststeps_guides/en/olpan2019%20-en.pdf
- Эксперимент Nakata по L2-лексике проверяет повторное извлечение и отсроченные
  тесты: https://doi.org/10.1017/S0272263116000280
- Meta-analysis мультимедийных глосс подтверждает пользу глосс, но также
  предупреждает против бездумного наращивания модальностей:
  https://doi.org/10.1016/j.actpsy.2024.104341
- Официальный синтаксис Bases:
  https://obsidian.md/help/bases/syntax
- Официальный синтаксис сворачиваемых callouts:
  https://obsidian.md/help/callouts
- Поддерживаемые аудиовложения:
  https://obsidian.md/help/file-formats

Эти источники не доказывают эффективность конкретного продукта. Они
обосновывают выбранные механизмы; результат нужно измерять на реальном учебном
цикле.

## 8. Метрики следующего учебного цикла

Без записи нового канона в Obsidian:

- доля фраз, понятых на слух до раскрытия перевода;
- доля фраз, воспроизведённых после паузы;
- доля фокусных слов, восстановленных RU → HE;
- ошибки рода/числа/времени в преобразовании фраз;
- фактический FSRS recall в LinguistPro;
- число отсутствующих аудиофайлов и неразрешённых морфологических вхождений.

Это позволяет отличить красивый архив от действительно работающего учебного
процесса.
