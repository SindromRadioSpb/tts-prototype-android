## Причины и изменения

1. Изменение темы/подборки было доступно только через общий режим «Организовать», удаление — ещё глубже, внутри формы изменения. Теперь у личной темы и подборки есть непосредственные «Изменить» и «Удалить», в том числе на странице их материалов. Публичное редактирование по-прежнему требует редакторского режима владельца.
2. Карта и главная скрывали пустые категории и в личном пространстве. Теперь личные пустые темы отображаются со счётчиком 0; новая тема создаётся прямо из карты. Публичная витрина сохраняет прежнее правило наполненности.
3. «В подборку → Куда добавить» позволяет выбрать существующую категорию/подборку либо создать новую любого из этих типов; у категории выбирается родитель. Создание и включение материала сохраняются одной операцией. Тот же компонент работает при сохранении публичного материала в личную структуру без копирования содержимого.
4. «Отменить изменение» доступно и вне общего редакторского режима. После удаления открытой темы/подборки сбрасывается только ссылка на удалённый объект; прочие фильтры сохраняются. Выбор удаления с поднятием дочерних тем либо всего поддерева остаётся явным. Материалы и учебные данные не удаляются.
5. При отсутствии назначения выводится конкретная подсказка. Исправление ввода снимает устаревшую ошибку; конфликт версий продолжает блокировать устаревшее сохранение и сохранять введённый текст.

Роли: R4/R6 — доступное управление и видимость личной структуры; R3/R12 — сохранение ID и единый writer; R11/R13/R15 — удаление связей без потери материалов, отмена и проверка сохранности; R14 — прежняя граница публичного редактора. Учебное содержимое, морфология и FSRS не меняются.
