# Редакторская структура публичной Медиатеки

Срез 22 сентября 2026. Реестр не означает публикацию материалов или проверку прав.

## Основа и приоритет

Исследование владельца содержит 500 кандидатов, включая 50 рекомендаций, а не 500 подтверждённых ивритских каналов. Метрики подписчиков и страновой рейтинг не используются для автопубликации. Исходный реестр сохранён в research-candidates.json; редакторский поиск охватывает все 500 записей.

Приоритет первого наполнения — готовые интервью, репортажи, документальные серии и живая разговорная речь. Канал становится темой; серия, сезон или редакционная группа выпусков — подборкой. Один выпуск может входить в несколько подборок без копирования учебного материала. Сквозные рубрики («Интервью», «Общество», «История») можно создавать дополнительно, сохраняя канонический канал источником. Политические позиции каналов не объединяются в одну редакционную оценку.

- «Безумный Юг-1/2/3» — фактически 7.10 — גרסת יו״ש. Не прикреплять к הדרום הפרוע только по русскому имени файла. Локальный архив первой части подтверждает заголовок и 270 строк, но не содержит YouTube-источника; редактор должен указать его явно.
- Повторные ZIP одной серии, разные варианты Google/Gemini и пометка «переделать» требуют выбора владельцем нужной редакции. Ни один архив автоматически не объявлен финальным.
- Короткий playlist ID PLACmvHcJM5hc найден на официальной странице KAN11 с заголовком אויבים עונה 5. Первоначальное подозрение на обрезку снято. Длина ID сама по себе не критерий валидности. Четыре плейлиста документированы в playlist-evidence.json; остальные подборки пока редакционные.
- Полные архивы из Telegram не выгружались массово; существующие файлы владельца прочитаны без изменения.

## Работа редактора

1. «Изменить общедоступные» → «Каналы и серии из исследования» → предпросмотр изменений → применить. Существующие темы сохраняются, совпадения по video ID добавляются только для реально опубликованных материалов.
2. «Добавить материал»: учебный ZIP/lpmedia.zip; режим YouTube по умолчанию. Если ссылка уже в архиве, повторный ввод не нужен. Если её нет — вставить ссылку. Несовпадение с сохранённым источником блокирует импорт.
3. Для режима медиа — пакет с медиа или отдельный файл с совпадающей SHA-256. Поддерживаемые MIME: MP4, WebM, QuickTime, MP3, M4A. Лимит входного файла 512 МиБ; внутренний учебный ZIP ограничен действующим PortableLearningPackageCore.
4. Подтвердить название, тему и подборку (для 55 известных видео предлагаются автоматически), права и возможность скачивания. Посмотреть полный состав новой редакции канала.
5. Опубликовать материал; затем отдельно подтвердить структуру Медиатеки. Два шага соответствуют двум существующим независимым опубликованным указателям. При прерывании после первого материал уже публичный, а размещение можно завершить через редактор структуры.

Исходный учебный пакет хранится приватно по SHA-256, одинаковые байты не записываются повторно. В режиме YouTube вложенное видео не сохраняется. Платные провайдеры не вызываются. Публичная загрузка — опубликованный учебный пакет корпуса; это не прямая выдача исходного авторского ZIP. Права скачивания и стриминга раздельные.

## Границы проверки

Unit/domain и свежие локальные браузерные профили отделены от production, owner-live, физического телефона и AT. Скриншоты используют синтетический материал. Наличие метаданных YouTube не доказывает отсутствие возрастных/региональных ограничений или точность синхронизации.
