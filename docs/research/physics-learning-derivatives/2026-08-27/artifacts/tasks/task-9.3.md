# Физика — задача 9.3

## Стандарт математической записи

Индекс записывается через `_`: `v_A`, а составной индекс — в фигурных скобках:
`t_{AC}`. Степень записывается через `^`, умножение — только через `*`.
Например: `v^2 = v_0^2 + 2 * a * s`.

## Условие на русском

- Пакеты, каждый массой 1 кг, поступают с конвейера на абсолютно гладкую поверхность платформы со скоростью V_0 = 1 м/с, как показано на схеме. Ускорение свободного падения: g = 9.81 м/с²
- Рассчитайте предельный угол (φ_max), при котором пакет начинает отрываться от поверхности платформы, если радиус платформы R = 0.5 м.

## Подсказка: модель

В момент отрыва N = 0; объединяем радиальную динамику с законом сохранения энергии.

## Экзаменационное решение

### Дано

- v_0 = 1 м/с
- R = 0,5 м
- g = 9,81 м/с^2
- поверхность гладкая.

### Найти

- Предельный угол отрыва φ * m * a * x.

### Перевод в СИ и обозначения

- Все данные уже в СИ.

### Решение

#### 1. Физическая модель

В момент отрыва N = 0; объединяем радиальную динамику с законом сохранения энергии.

#### 2. Базовые законы

- v^2 = v_0^2 + 2 * g * R * (1 - cos(φ))
- m * g * cos(φ) - N = m * v^2/R
- при отрыве N = 0

#### 3. Вывод расчётных формул

1. В момент отрыва m * g * cos(φ) = m * v^2/R.
2. Подставляем v^2 из энергии: g * R * cos(φ) = v_0^2 + 2 * g * R * (1 - cos(φ)).
3. Собираем cos(φ): 3 * g * R * cos(φ) = v_0^2 + 2 * g * R; cos(φ) = (v_0^2 + 2 * g * R)/(3 * g * R), φ = arccos(...).


#### 4. Подстановка и последовательный расчёт

1. cos(φ) = (1^2 + 2 * 9,81 * 0,5)/(3 * 9,81 * 0,5) = 0,73462.
2. φ = arccos(0,73462) = 42,72°.

#### 5. Проверка результата

- Аргумент arccos должен лежать в [-1;1].

## Ответ

**φ_m * a * x = 42,72°**
