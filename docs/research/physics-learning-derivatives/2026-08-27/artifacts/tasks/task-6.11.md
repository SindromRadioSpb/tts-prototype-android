## Условие на русском

- Тело A лежит на наклонной плоскости с углом 25°, а тело B — на наклонной плоскости с углом 37°. Оба тела соединены тросом, проходящим через неподвижный блок, как показано на рисунке к задаче. Ветвь троса a параллельна плоскости, на которой лежит тело A, а ветвь b — плоскости, на которой лежит тело B. Тело B тянут силой P, действующей параллельно наклонной плоскости, на которой оно лежит. Масса тела A равна 50 кг, тела B — 40 кг.
- Коэффициент статического трения между телом A и плоскостью, на которой оно лежит, равен \mu s1 = 0.3, а коэффициент статического трения между телом B и плоскостью, на которой оно лежит, равен \mu s2 = 0.4.
- а. Начертите схемы сил, действующих на каждое из тел A и B непосредственно перед началом движения тела A вправо и вверх по наклонной плоскости, а тела B — влево и вниз по наклонной плоскости.
- б. Рассчитайте натяжение троса, необходимое для начала движения тела A вверх по наклонной плоскости.
- в. Рассчитайте силу P, которую необходимо приложить к телу B для начала его движения влево.
- Примечание: трением в блоке пренебречь и считать натяжения в обеих ветвях троса равными.

## Подсказка: модель

Предельное равновесие на обоих склонах непосредственно перед подъёмом A и спуском B.

## Экзаменационное решение

### Дано

- m_A = 50 кг, α * A = 25°, μ_{s1} = 0,3
- m_B = 40 кг, α * B = 37°, μ_{s2} = 0,4
- A готово вверх, B вниз.

### Найти

- Схемы сил
- T
- P.

### Перевод в СИ и обозначения

- Все данные уже в СИ.

### Решение

#### 1. Физическая модель

Предельное равновесие на обоих склонах непосредственно перед подъёмом A и спуском B.

#### 2. Базовые законы

- N = m * g * cos(α)
- F_{тр,max} = μ_s * N
- ΣF∥ = 0

#### 3. Вывод расчётных формул

1. Для A: T - m_A * g * sin(25°) - μ_{s1} * m_A * g * cos(25°) = 0.
2. Для B при готовности двигаться вниз трение направлено вверх: m_B * g * sin(37°) + P - T - μ_{s2} * m_B * g * cos(37°) = 0.
3. Сначала находим T из первого уравнения, затем P = T + μ_{s2} * m_B * g * cos(37°) - m_B * g * sin(37°).

#### Обязательное построение

- Тело A: m_A * g вертикально вниз; N_A перпендикулярно своей плоскости; T вверх по плоскости; f_A = μ_{s1} * N_A вниз по плоскости.
- Тело B: m_B * g вертикально вниз; N_B перпендикулярно своей плоскости; P вниз по плоскости; T и f_B = μ_{s2} * N_B вверх по плоскости.
- На схемах отдельно показать разложения веса m_A * g * sin(α) вдоль плоскости и m_A * g * cos(α) по нормали.


#### 4. Подстановка и последовательный расчёт

1. Для A: T = m_A * g * (sin(25°) + 0,3 * cos(25°)) = 340,7 Н.
2. Для B: P + m_B * g * sin(37°) = T + 0,4 * m_B * g * cos(37°), откуда P≈229,9 Н.

#### 5. Проверка результата

- Все направления сил сверяются с предполагаемым предельным движением каждого тела.

## Ответ

**схемы сил заданы; T≈340,7 Н; P ≥ 229,9 Н**
