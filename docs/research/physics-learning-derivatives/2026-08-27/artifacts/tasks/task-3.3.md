# Физика — задача 3.3

## Стандарт математической записи

Индекс записывается через `_`: `v_A`, а составной индекс — в фигурных скобках:
`t_{AC}`. Степень записывается через `^`, умножение — только через `*`.
Например: `v^2 = v_0^2 + 2 * a * s`.

## Условие на русском

- Самолет совершает горизонтальный полет, а автобус движется навстречу ему по земле. Все параметры движения самолета и автобуса указаны на схеме.
- В определенный момент пилот вертолета сбрасывает предмет так, чтобы он упал точно на крышу автобуса.
- Рассчитайте:
- а. Каково будет горизонтальное расстояние между вертолетом и автобусом в момент сброса предмета?
- б. Каково будет горизонтальное расстояние между вертолетом и автобусом в момент попадания предмета в автобус?
- в. С какой скоростью (величина и направление) предмет ударит по автобусу?
- Примечания: рассматривайте вертолет и автобус как материальные точки.
- Горизонтальный бросок в сочетании с трением и энергией

## Подсказка: модель

Груз сохраняет горизонтальную скорость вертолёта; сравниваем её со скоростью автобуса за время падения.

## Экзаменационное решение

### Дано

- Высота H = 720 м
- вертолёт 270 км/ч, автобус 90 км/ч навстречу
- g = 9,81 м/с^2.

### Найти

- Начальное расстояние
- расстояние при попадании
- скорость удара.

### Перевод в СИ и обозначения

- v_{верт} = 75 м/с
- v_{авт} = 25 м/с
- скорость сближения 100 м/с.

### Решение

#### 1. Физическая модель

Груз сохраняет горизонтальную скорость вертолёта; сравниваем её со скоростью автобуса за время падения.

#### 2. Базовые законы

- H = g * t^2/2
- Δx = (v_{верт} + v_{авт}) * t
- v_y = g * t
- |v| = √(v_x^2 + v_y^2)

#### 3. Вывод расчётных формул

1. t = √(2 * H/g).
2. Чтобы груз попал в автобус, начальный разрыв x_0 = (v_{верт} + v_{авт}) * t; в момент удара Δx = 0.
3. Груз сохраняет v_x = v_{верт}; v_y = g * t вниз; модуль и угол: v = √(v_x^2 + v_y^2), α = arctan(v_y/v_x).


#### 4. Подстановка и последовательный расчёт

1. Время падения с 720 м: t = √(1440/9,81) = 12,116 с.
2. Скорость сближения 270/3,6 + 90/3,6 = 100 м/с, поэтому исходное расстояние 1211,6 м, а при падении оно равно нулю.
3. При ударе v_x = 75 м/с влево, v_y = g * t = 118,85 м/с вниз.
4. Окончательно, после вычисления и округления: x = 1211,6 м; Δx = 0; |v| = 140,53 м/с; направление 57,7° ниже горизонта.

#### 5. Проверка результата

- За найденное время суммарное горизонтальное сближение ровно равно x_0.

## Ответ

**x = 1211,6 м; Δx = 0; |v| = 140,53 м/с; направление 57,7° ниже горизонта**
