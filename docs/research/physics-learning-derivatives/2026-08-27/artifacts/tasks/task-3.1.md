# Физика — задача 3.1

## Стандарт математической записи

Индекс записывается через `_`: `v_A`, а составной индекс — в фигурных скобках:
`t_{AC}`. Степень записывается через `^`, умножение — только через `*`.
Например: `v^2 = v_0^2 + 2 * a * s`.

## Условие на русском

- Пилот должен сбросить груз с самолета A так, чтобы он упал точно в точку C.
- Каким должно быть расстояние (x) между самолетом A и целью C, и каков угол (β), под которым пилот видит цель в момент сброса груза? Также рассчитайте время падения груза.
- Самолет летит горизонтально на высоте (H), равной 240 метров, с постоянной скоростью 250 км/ч. Примите: g = 9,81 м/с²

## Подсказка: модель

Горизонтальный сброс: x = v_x * t, H = g * t^2/2.

## Экзаменационное решение

### Дано

- H = 240 м
- скорость самолёта 250 км/ч
- g = 9,81 м/с^2
- начальная вертикальная скорость груза равна нулю.

### Найти

- Время падения
- горизонтальное расстояние x
- угол визирования β.

### Перевод в СИ и обозначения

- v_x = 250/3,6 = 69,444 м/с.

### Решение

#### 1. Физическая модель

Горизонтальный сброс: x = v_x * t, H = g * t^2/2.

#### 2. Базовые законы

- H = g * t^2/2
- x = v_x * t
- tan(β) = H/x

#### 3. Вывод расчётных формул

1. Из вертикального движения t = √(2 * H/g).
2. Горизонтальная скорость постоянна, поэтому x = v_x * √(2 * H/g).
3. Из прямоугольного треугольника β = arctan(H/x).


#### 4. Подстановка и последовательный расчёт

1. t = √(2 * 240/9,81) = 6,995 с.
2. При v_x = 250/3,6 = 69,444 м/с получаем x = 485,76 м.
3. Угол наблюдения определяется из tan(β) = 240/x.
4. Окончательно, после вычисления и округления: x = 485,76 м; β = 26,29°; t = 6,995 с.

#### 5. Проверка результата

- Время не зависит от горизонтальной скорости; x имеет размерность длины.

## Ответ

**x = 485,76 м; β = 26,29°; t = 6,995 с**
