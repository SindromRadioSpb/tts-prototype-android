# Физика — задача 9.1

## Стандарт математической записи

Индекс записывается через `_`: `v_A`, а составной индекс — в фигурных скобках:
`t_{AC}`. Степень записывается через `^`, умножение — только через `*`.
Например: `v^2 = v_0^2 + 2 * a * s`.

## Условие на русском

- В эксперименте с ракетной тележкой массой 100 кг тележка начинает движение из состояния покоя в точке A и перемещается по дуге окружности (AB), развивая постоянную силу тяги T = 2 кН.
- Рассчитайте расстояние S, на которое тележка поднимется по наклонной плоскости после прекращения действия силы тяги (в точке B) до полной остановки. Радиус дуги AB равен 90 м.
- Наклонная плоскость на участке S касается дуги AB, угол наклона α = 30°. (g = 9.81 м/с²). Пренебрегите трением между колесами тележки и рельсами.

## Подсказка: модель

Теорема об изменении кинетической энергии на дуге 30°, затем на касательной наклонной плоскости.

## Экзаменационное решение

### Дано

- m = 100 кг
- T = 2 кН
- R = 90 м
- α = 30°
- старт из покоя
- трения нет
- тяга действует на дуге AB.

### Найти

- Путь S после прекращения тяги.

### Перевод в СИ и обозначения

- T = 2000 Н
- α = π/6 рад для длины дуги.

### Решение

#### 1. Физическая модель

Теорема об изменении кинетической энергии на дуге 30°, затем на касательной наклонной плоскости.

#### 2. Базовые законы

- A_{тяги} = T * R * α
- Δh = R * (1 - cos(α))
- K_B = A_{тяги} - m * g * Δh
- K_B = m * g * S * sin(α)

#### 3. Вывод расчётных формул

1. Длина дуги l = R * α, работа тяги T * l; подъём по дуге Δh = R * (1 - cos(α)).
2. Из теоремы об энергии K_B = T * R * α-m * g * R * (1 - cos(α)).
3. На наклонном участке тяги нет: K_B = m * g * S * sin(α); S = K_B/(m * g * sin(α)).


#### 4. Подстановка и последовательный расчёт

1. l = 90 * π/6 = 47,124 м; A_{тяги} = 2000 * 47,124 = 94247,8 Дж.
2. Δh = 90 * (1 - cos(30°)) = 12,058 м; m * g * Δh = 100 * 9,81 * 12,058 = 11828,6 Дж.
3. K_B = 94247,8 - 11828,6 = 82419,2 Дж.
4. S = 82419,2/(100 * 9,81 * sin(30°)) = 168,03 м.

#### 5. Проверка результата

- Угол в формуле длины дуги берётся в радианах; это принципиально для расхождения с ключом.

## Ответ

**S = 168,03 м**
