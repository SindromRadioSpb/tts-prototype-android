# Физика — задача 1.3

## Стандарт математической записи

Индекс записывается через `_`: `v_A`, а составной индекс — в фигурных скобках:
`t_{AC}`. Степень записывается через `^`, умножение — только через `*`.
Например: `v^2 = v_0^2 + 2 * a * s`.

## Условие на русском

- Лыжник начинает движение из состояния покоя (точка A) и доходит до точки C. Предполагая, что движение является равноускоренным и величины ускорений равны:
- На участке AB длиной 30 метров: a₁ = 2 м/с²
- На участке BC длиной 50 метров: a₂ = 6 м/с²
- а. Рассчитайте общее время движения лыжника от точки A до точки C.
- б. Рассчитайте скорость в точке C.
- в. Постройте графики ускорения, скорости и пути как функции времени. Трением пренебречь.

## Подсказка: модель

Кусочно-равноускоренное движение.

## Экзаменационное решение

### Дано

- v_A = 0
- AB = 30 м, a_1 = 2 м/с^2
- BC = 50 м, a_2 = 6 м/с^2.

### Найти

- t_{AC}
- v_C
- графики a(t), v(t), x(t).

### Перевод в СИ и обозначения

- Все данные уже в СИ.

### Решение

#### 1. Физическая модель

Кусочно-равноускоренное движение.

#### 2. Базовые законы

- v^2 = v_0^2 + 2 * a * s
- t = (v - v_0)/a
- v = v_0 + a * t
- x = x_0 + v_0 * t + a * t^2/2

#### 3. Вывод расчётных формул

1. На AB: v_B = √(v_A^2 + 2 * a_1 * AB), t_{AB} = (v_B - v_A)/a_1.
2. На BC: v_C = √(v_B^2 + 2 * a_2 * BC), t_{BC} = (v_C - v_B)/a_2; t_{AC} = t_{AB} + t_{BC}.
3. Для графиков записываем отдельные функции на 0 ≤ t ≤ t_{AB} и t_{AB} ≤ t ≤ t_{AC}, сохраняя непрерывность v и x в B.

#### Обязательное построение

- a(t) = 2 м/с^2 при 0 ≤ t ≤ 5,4772 с; a(t) = 6 м/с^2 при 5,4772 < t ≤ 8,1236 с.
- v(t) = 2 * t при 0 ≤ t ≤ 5,4772 с; v(t) = 10,9545 + 6 * (t - 5,4772) при 5,4772 < t ≤ 8,1236 с.
- x(t) = t^2 при 0 ≤ t ≤ 5,4772 с; x(t) = 30 + 10,9545 * (t - 5,4772) + 3 * (t - 5,4772)^2 при 5,4772 < t ≤ 8,1236 с.
- Опорные точки: A(0;0;0), B(5,4772 с; 10,9545 м/с; 30 м), C(8,1236 с; 26,8328 м/с; 80 м).


#### 4. Подстановка и последовательный расчёт

1. AB: v_B = √(2 * 2 * 30) = 10,9545 м/с, t_{AB} = v_B/2 = 5,4772 с.
2. BC: v_C = √(v_B^2 + 2 * 6 * 50) = 26,8328 м/с, t_{BC} = (v_C - v_B)/6 = 2,6464 с.
3. Графики кусочные: a = {2;6}; v — непрерывная ломаная, x — непрерывная кусочно-квадратичная функция.
4. Окончательно, после вычисления и округления: t_{AC} = 8,1236 с; v_C = 26,8328 м/с; построение графиков описано.

#### 5. Проверка результата

- v_C > v_B > v_A и оба времени положительны, что согласуется с положительными ускорениями.

## Ответ

**t_{AC} = 8,1236 с; v_C = 26,8328 м/с; построение графиков описано**
