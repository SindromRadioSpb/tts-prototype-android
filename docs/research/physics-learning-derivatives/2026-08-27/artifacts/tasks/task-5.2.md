# Физика — задача 5.2

## Стандарт математической записи

Индекс записывается через `_`: `v_A`, а составной индекс — в фигурных скобках:
`t_{AC}`. Степень записывается через `^`, умножение — только через `*`.
Например: `v^2 = v_0^2 + 2 * a * s`.

## Условие на русском

- Тело массой 20 кг движется (вправо) по гладкой поверхности со скоростью 0,5 м/с. В некоторый момент времени к нему прикладывается сила 40 Н, направленная противоположно его предыдущему движению.
- Рассчитайте, какой будет скорость тела (величина и направление) через 3 секунды после начала действия силы?

## Подсказка: модель

Одномерный импульс при постоянной противодействующей силе.

## Экзаменационное решение

### Дано

- m = 20 кг
- v_0 = + 0,5 м/с
- F = -40 Н
- t = 3 с
- поверхность гладкая.

### Найти

- Скорость через 3 с: модуль и направление.

### Перевод в СИ и обозначения

- Направление первоначального движения принимаем положительным.

### Решение

#### 1. Физическая модель

Одномерный импульс при постоянной противодействующей силе.

#### 2. Базовые законы

- ΣF = m * a
- v = v_0 + a * t

#### 3. Вывод расчётных формул

1. a = F/m.
2. v = v_0 + (F/m) * t; знак результата определяет направление, модуль равен |v|.


#### 4. Подстановка и последовательный расчёт

1. a = -40/20 = -2 м/с^2.
2. Момент остановки: 0 = 0,5 - 2 * t_0, откуда t_0 = 0,25 с; значит, к 3 с тело уже движется обратно.
3. v * (3) = 0,5 + (-2) * 3 = -5,5 м/с; модуль скорости 5,5 м/с.

#### 5. Проверка результата

- Отрицательная скорость означает, что тело остановилось и начало двигаться обратно.

## Ответ

**v = -5,5 м/с, то есть 5,5 м/с против первоначального направления**
