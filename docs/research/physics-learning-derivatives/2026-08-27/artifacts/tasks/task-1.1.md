# Физика — задача 1.1

## Стандарт математической записи

Индекс записывается через `_`: `v_A`, а составной индекс — в фигурных скобках:
`t_{AC}`. Степень записывается через `^`, умножение — только через `*`.
Например: `v^2 = v_0^2 + 2 * a * s`.

## Условие на русском

- Поезд движется со скоростью 110 км/ч. В точке M пути машинист применяет тормоза, и поезд движется к перекрёстку C с постоянным ускорением (замедлением) так, что на расстоянии 0,8 км от точки M его скорость снижается до 80 км/ч.
- Легковой автомобиль движется по дороге, пересекающей железнодорожные пути, со скоростью 40 км/ч. В момент, когда поезд находится в точке M, автомобиль находится в точке N. В точке N водитель ускоряет автомобиль, и тот движется к перекрёстку C с постоянным ускорением.
- Рассчитайте величину ускорения легкового автомобиля, если он пересекает перекрёсток C на 10 секунд раньше поезда.
- Какова скорость легкового автомобиля на перекрёстке C?
- Расстояния от точек M и N до перекрёстка C приведены на схеме.

## Подсказка: модель

v^2 = v_0^2 + 2 * a * s; x = v_0 * t + a * t^2/2

## Экзаменационное решение

### Дано

- Поезд: v_{0T} = 110 км/ч, v_T = 80 км/ч, s_{T1} = 800 м, MC = 1500 м.
- Автомобиль: v_{0A} = 40 км/ч, NC = 1200 м
- t_A = t_T - 10 с.

### Найти

- a_A
- v_A в точке C.

### Перевод в СИ и обозначения

- v_{0T} = 30,556 м/с
- v_T = 22,222 м/с
- v_{0A} = 11,111 м/с.

### Решение

#### 1. Физическая модель

v^2 = v_0^2 + 2 * a * s; x = v_0 * t + a * t^2/2

#### 2. Базовые законы

- v^2 = v_0^2 + 2 * a * s
- s = v_0 * t + a * t^2/2
- v = v_0 + a * t

#### 3. Вывод расчётных формул

1. a_T = (v_T^2 - v_{0T}^2)/(2 * s_{T1}).
2. Из MC = v_{0T} * t_T + a_T * t_T^2/2 получаем квадратное уравнение a_T * t_T^2/2 + v_{0T} * t_T - MC = 0; выбираем положительный корень.
3. t_A = t_T - 10; из NC = v_{0A} * t_A + a_A * t_A^2/2 выражаем a_A = 2 * (NC - v_{0A} * t_A)/t_A^2; затем v_A = v_{0A} + a_A * t_A.


#### 4. Подстановка и последовательный расчёт

1. Для поезда a_T = ((80/3,6)^2 - (110/3,6)^2)/(2 * 800) = -0,274884 м/с^2.
2. Физически допустимый корень для пути 1500 м: t_T = 73,1790 с, поэтому t_{авто} = 63,1790 с.
3. Для автомобиля a = 2 * (1200 - (40/3,6) * t)/t^2, а v_C = 40/3,6 + a * t.
4. Окончательно, после вычисления и округления: a = 0,249530 м/с^2; v_C = 26,8762 м/с.

#### 5. Проверка результата

- Отрицательное a_T соответствует торможению; время и скорость автомобиля положительны.

## Ответ

**a = 0,249530 м/с^2; v_C = 26,8762 м/с**
