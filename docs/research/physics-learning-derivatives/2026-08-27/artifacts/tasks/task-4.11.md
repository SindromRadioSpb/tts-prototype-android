# Физика — задача 4.11

## Стандарт математической записи

Индекс записывается через `_`: `v_A`, а составной индекс — в фигурных скобках:
`t_{AC}`. Степень записывается через `^`, умножение — только через `*`.
Например: `v^2 = v_0^2 + 2 * a * s`.

## Условие на русском

- На рисунке к задаче футболист бьет по мячу с начальной скоростью v под углом \alpha к горизонту. На горизонтальном расстоянии 25 метров от точки удара мяч достигает максимальной высоты, равной 20 метрам.
- Вычислите:
- а. Время подъема мяча до наивысшей точки.
- б. Угол удара по мячу \alpha.
- в. Начальную скорость удара по мячу v?
- г. Скорость мяча в наивысшей точке траектории?

## Подсказка: модель

Заданная точка — вершина траектории при x = 25 м, y = 20 м.

## Экзаменационное решение

### Дано

- Вершина: x_H = 25 м, h = 20 м
- g = 9,81 м/с^2.

### Найти

- t_H
- α
- v_0
- скорость в вершине.

### Перевод в СИ и обозначения

- Все данные уже в СИ.

### Решение

#### 1. Физическая модель

Заданная точка — вершина траектории при x = 25 м, y = 20 м.

#### 2. Базовые законы

- h = v_{y0}^2/(2 * g)
- t_H = v_{y0}/g
- x_H = v_x * t_H

#### 3. Вывод расчётных формул

1. v_{y0} = √(2 * g * h), затем t_H = v_{y0}/g = √(2 * h/g).
2. v_x = x_H/t_H; α = arctan(v_{y0}/v_x); v_0 = √(v_x^2 + v_{y0}^2).
3. В вершине v_y = 0, поэтому v_H = v_x.


#### 4. Подстановка и последовательный расчёт

1. v_{y0} = √(2 * 9,81 * 20) = 19,809 м/с; t_H = 19,809/9,81 = 2,019 с.
2. v_x = 25/2,019 = 12,38 м/с.
3. α = arctan(19,809/12,38) = 58,0°; v_0 = √(19,809^2 + 12,38^2) = 23,36 м/с.
4. В вершине v_H = v_x = 12,38 м/с.
5. Окончательно, после вычисления и округления: t_H = 2,02 с; α = 58,0°; v_0 = 23,36 м/с; v_{верш} = 12,38 м/с.

#### 5. Проверка результата

- Подстановка компонент должна дать одновременно x_H = 25 м и h = 20 м.

## Ответ

**t_H = 2,02 с; α = 58,0°; v_0 = 23,36 м/с; v_{верш} = 12,38 м/с**
