## Подсказка: модель

Строим отдельные схемы сил для A и B; положительное направление вдоль плоскости выбираем вниз, куда тело B готово начать движение.

## Экзаменационное решение

### Дано

- m_A = 20 кг на B и связано тросом
- m_B = 50 кг
- α = 20°
- μ_{AB} = 0,3
- μ_{B-пл} = 0,5
- B готово вниз
- P горизонтальна.

### Найти

- Схемы сил
- T
- P_{min}.

### Перевод в СИ и обозначения

- Все данные уже в СИ.

### Решение

#### 1. Физическая модель

Строим отдельные схемы сил для A и B; положительное направление вдоль плоскости выбираем вниз, куда тело B готово начать движение.

#### 2. Базовые законы

- F_{тр,max} = μ * N
- ΣF_∥ = 0
- ΣF_⊥ = 0

#### 3. Вывод расчётных формул

1. Для A: N_1 = m_A * g * cos(α), f_1 = μ_{AB} * N_1; T = m_A * g * sin(α) + f_1.
2. На B вдоль плоскости действует контактное трение f_1 от A; натяжение T непосредственно на B не действует.
3. Для B по нормали: N_2 = m_B * g * cos(α) + N_1 - P * sin(α) = (m_A + m_B) * g * cos(α) - P * sin(α).
4. Для B вдоль плоскости на грани движения вниз: P * cos(α) + m_B * g * sin(α) = f_1 + μ_{B-пл} * N_2.
5. После подстановки N_2: P * (cos(α) + μ_{B-пл} * sin(α)) = f_1 + μ_{B-пл} * (m_A + m_B) * g * cos(α) - m_B * g * sin(α).

#### Обязательное построение

- Тело A: m_A * g вертикально вниз; нормаль N_1 от B; T вверх по плоскости; трение f_1 вниз по плоскости.
- Тело B: m_B * g вертикально вниз; нормаль N_2 от плоскости; со стороны A действуют N_1 в сторону плоскости и f_1 вверх по плоскости; трение плоскости μ_{B-пл} * N_2 вверх по плоскости; сила P имеет компоненты P * cos(α) вниз по плоскости и P * sin(α), уменьшающую N_2.
- Вес m_A * g не действует непосредственно на B: его нормальная составляющая передаётся через N_1, а касательная связь — через f_1.


#### 4. Подстановка и последовательный расчёт

1. Для тела A по нормали: N_1 = m_A * g * cos(20°) = 20 * 9,81 * cos(20°) = 184,37 Н.
2. Предельное трение между A и B: f_1 = μ_{AB} * N_1 = 0,3 * 184,37 = 55,31 Н; на A оно направлено вниз по плоскости, а на B — вверх.
3. Равновесие A вдоль плоскости: T - m_A * g * sin(20°) - f_1 = 0, поэтому T = m_A * g * sin(20°) + f_1 = 122,41 Н.
4. Для тела B по нормали: N_2 = m_B * g * cos(20°) + N_1 - P * sin(20°) = (m_A + m_B) * g * cos(20°) - P * sin(20°).
5. Вдоль плоскости для одного B: P * cos(20°) + m_B * g * sin(20°) = f_1 + μ_{B-пл} * N_2. Составляющая m_A * g * sin(20°) сюда не входит: вес A действует на A, а на B передаются N_1 и f_1.
6. Подстановка даёт P * cos(20°) + 50 * 9,81 * sin(20°) = 55,31 + 0,5 * ((20 + 50) * 9,81 * cos(20°) - P * sin(20°)).
7. Собираем члены: P * (cos(20°) + 0,5 * sin(20°)) = 55,31 + 0,5 * 70 * 9,81 * cos(20°) - 50 * 9,81 * sin(20°) = 210,19 Н.
8. Отсюда P = 210,19/(cos(20°) + 0,5 * sin(20°)) = 189,24 Н. Проверка всей системы A + B: P * cos(20°) + (m_A + m_B) * g * sin(20°) = T + 0,5 * N_2; при T = 122,41 Н получается то же значение.

#### 5. Проверка результата

- Для одного B после подстановки P_{min} = 189,24 Н обе стороны равны 345,59 Н.
- Для системы A + B внешнее уравнение P * cos(α) + (m_A + m_B) * g * sin(α) = T + μ_{B-пл} * N_2 также даёт равенство 412,70 Н; натяжение T здесь обязательно.
- Расхождение 189,24 Н и 189,19 Н из ключа составляет около 0,03% и объясняется округлением промежуточных величин.

## Ответ

**схемы сил заданы; T = 122,41 Н; P_{min} = 189,24 Н**
