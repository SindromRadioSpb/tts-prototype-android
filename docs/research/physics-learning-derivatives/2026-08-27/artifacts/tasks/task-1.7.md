# Физика — задача 1.7

## Стандарт математической записи

Индекс записывается через `_`: `v_A`, а составной индекс — в фигурных скобках:
`t_{AC}`. Степень записывается через `^`, умножение — только через `*`.
Например: `v^2 = v_0^2 + 2 * a * s`.

## Условие на русском

- Два транспортных средства едут навстречу друг другу по прямому горизонтальному участку дороги. Когда расстояние между ними (AB) составляло 500 метров, скорость первого транспортного средства (V₁) была 48 км/ч, а скорость второго (V₂) — 32 км/ч. В этот момент оба транспортных средства начали ускоряться и двигаться с постоянным ускорением.
- Ускорения двух транспортных средств были: a₁ = 1,6 м/с², a₂ = 1,4 м/с²
- а. Рассчитайте промежуток времени (t) от момента начала ускорения до встречи обоих транспортных средств.
- б. Рассчитайте положение точки (C) на отрезке AB, где они встретятся.
- в. Рассчитайте скорость обоих транспортных средств в точке встречи и проверьте, не превысили ли они разрешённую скорость 100 км/ч.

## Подсказка: модель

Сумма расстояний, пройденных навстречу друг другу, равна 500 м.

## Экзаменационное решение

### Дано

- AB = 500 м
- v_{10} = 48 км/ч, v_{20} = 32 км/ч
- a_1 = 1,6 м/с^2, a_2 = 1,4 м/с^2.

### Найти

- Время встречи
- положение C
- обе скорости и сравнение со 100 км/ч.

### Перевод в СИ и обозначения

- v_{10} = 13,333 м/с
- v_{20} = 8,889 м/с
- 100 км/ч = 27,778 м/с.

### Решение

#### 1. Физическая модель

Сумма расстояний, пройденных навстречу друг другу, равна 500 м.

#### 2. Базовые законы

- s = v_0 * t + a * t^2/2
- v = v_0 + a * t

#### 3. Вывод расчётных формул

1. До встречи s_1 + s_2 = AB: (a_1 + a_2) * t^2/2 + (v_{10} + v_{20}) * t - AB = 0.
2. Для квадратного уравнения A * t^2 + B * t + C = 0: D = B^2 - 4 * AC, t = (-B + √D)/(2 * A); отрицательный корень отбрасываем.
3. s_1 = v_{10} * t + a_1 * t^2/2, s_2 = AB - s_1; v_1 = v_{10} + a_1 * t, v_2 = v_{20} + a_2 * t.


#### 4. Подстановка и последовательный расчёт

1. 1,5 * t^2 + 22,222 * t - 500 = 0; D = 22,222^2 - 4 * 1,5 * (-500) = 3493,83.
2. t = (-22,222 + √3493,83)/(2 * 1,5) = 12,295 с; второй корень отрицателен.
3. s_1 = 13,333 * 12,295 + 1,6 * 12,295^2/2 = 284,88 м; s_2 = 500 - 284,88 = 215,12 м.
4. v_1 = 13,333 + 1,6 * 12,295≈33,0 м/с; v_2 = 8,889 + 1,4 * 12,295≈26,1 м/с.
5. Окончательно, после вычисления и округления: t = 12,295 с; x_A = 284,88 м; x_B = 215,12 м; v_A≈33,0 м/с > 100 км/ч; v_B≈26,1 м/с < 100 км/ч.

#### 5. Проверка результата

- s_1 + s_2 = 500 м; каждую скорость отдельно сравниваем с 27,778 м/с.

## Ответ

**t = 12,295 с; x_A = 284,88 м; x_B = 215,12 м; v_A≈33,0 м/с > 100 км/ч; v_B≈26,1 м/с < 100 км/ч**
