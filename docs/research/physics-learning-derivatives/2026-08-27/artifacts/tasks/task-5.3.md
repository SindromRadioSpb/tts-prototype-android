# Физика — задача 5.3

## Стандарт математической записи

Индекс записывается через `_`: `v_A`, а составной индекс — в фигурных скобках:
`t_{AC}`. Степень записывается через `^`, умножение — только через `*`.
Например: `v^2 = v_0^2 + 2 * a * s`.

- б. Мощность P (в киловаттах), развиваемую силой трения во время скольжения.

- Примечание: 1 кВт = 1 (кН · м)/с

## Подсказка: модель

Торможение заблокированных колёс: a = -μ * g; средняя мощность трения равна работе, делённой на время.

## Экзаменационное решение

### Дано

- m = 2250 кг
- v_0 = 98 км/ч
- v = 80 км/ч
- μ_k = 0,3
- g = 9,81 м/с^2.

### Найти

- d
- P_{ср} силы трения.

### Перевод в СИ и обозначения

- v_0 = 27,222 м/с
- v = 22,222 м/с.

### Решение

#### 1. Физическая модель

Торможение заблокированных колёс: a = -μ * g; средняя мощность трения равна работе, делённой на время.

#### 2. Базовые законы

- F_{тр} = μ * m * g
- a = -μ * g
- v^2 = v_0^2 + 2 * a * d
- P_{ср} = F_{тр} * d/t

#### 3. Вывод расчётных формул

1. Из второго закона Ньютона получаем a = -μ * g.
2. d = (v^2 - v_0^2)/(2 * a), t = (v - v_0)/a.
3. P_{ср} = μ * m * g * d/t; переводим Вт в кВт.


#### 4. Подстановка и последовательный расчёт

1. a = -2,943 м/с^2; d = (v_f^2 - v_i^2)/(2 * a) = 42,0017 м.
2. t = (v_f - v_i)/a = 1,69895 с, P_{ср} = μ * m * g * d/t = 163,70 кВт.

#### 5. Проверка результата

- Расчёт должен совпасть с 1.6: это одна физическая постановка.

## Ответ

**d = 42,0017 м; P_{ср} = 163,70 кВт**
