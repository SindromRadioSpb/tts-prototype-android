# Физика — задача 8.1

## Стандарт математической записи

Индекс записывается через `_`: `v_A`, а составной индекс — в фигурных скобках:
`t_{AC}`. Степень записывается через `^`, умножение — только через `*`.
Например: `v^2 = v_0^2 + 2 * a * s`.

## Условие на русском

- Тело A массой m_A = 10 кг освобождается из состояния покоя в точке B на верхнем краю круговой траектории без трения. Радиус окружности r = 5 м.
- В нижней точке траектории D тело A ударяется о блок C и застревает в нем. Масса блока C составляет m_C = 50 кг.
- После удара система «тело–блок» движется по шероховатой горизонтальной плоскости. Коэффициент кинетического трения между блоком и плоскостью равен μ_k = 0.3 (см. рисунок к задаче 4).
- а. Рассчитайте скорость тела A в точке D перед ударом о блок C.
- б. Рассчитайте скорость системы «тело–блок» сразу после столкновения.
- в. Рассчитайте среднюю силу, действовавшую между блоком C и телом A во время соударения, если время удара составляет Δt = 0.05 с.
- г. Рассчитайте расстояние s, которое пройдет система «тело–блок» по шероховатой плоскости до полной остановки.

## Подсказка: модель

Энергия на круговой траектории, абсолютно неупругий удар, предоставленная формула переменной массы для каждого замкнутого тела и остановка трением.

## Экзаменационное решение

### Дано

- m_A = 10 кг
- m_C = 50 кг
- перепад r = 5 м
- μ = 0,3
- Δt = 0,05 с
- A застревает в C.
- В предоставленной формуле u_{потока} обозначает абсолютную скорость массы, пересекающей границу открытой системы.
- Символ u_{потока} не обозначает общую скорость u после столкновения.

### Найти

- v_D до удара
- общую скорость u
- среднюю силу F_{EX}, действующую между A и C
- путь остановки s.

### Перевод в СИ и обозначения

- Все данные уже в СИ.

### Решение

#### 1. Физическая модель

Энергия на круговой траектории, абсолютно неупругий удар, предоставленная формула переменной массы для каждого замкнутого тела и остановка трением.

#### 2. Базовые законы

- m_A * g * r = m_A * v_D^2/2
- m_A * v_D = (m_A + m_C) * u
- F_{EX} = m * ΔV/Δt - V_{rel} * Δm/Δt
- V_{rel} = u_{потока} - V
- u^2 = 2 * μ * g * s

#### 3. Вывод расчётных формул

1. Из закона сохранения механической энергии v_D = √(2 * g * r).
2. Из сохранения импульса u = m_A * v_D/(m_A + m_C).
3. В формуле переменной массы второй член учитывает поток массы через границу открытой системы.
4. Для замкнутого тела C масса не пересекает границу системы, поэтому Δm_C = 0 и F_{EX} = m_C * (u - 0)/Δt.
5. Для замкнутого тела A также Δm_A = 0, поэтому модуль силы равен F_{EX} = m_A * (v_D - u)/Δt. По третьему закону Ньютона оба модуля обязаны совпасть.
6. После удара μ * (m_A + m_C) * g * s = (m_A + m_C) * u^2/2, поэтому s = u^2/(2 * μ * g).


#### 4. Подстановка и последовательный расчёт

1. v_D = √(2 * 9,81 * 5) = 9,9045 м/с.
2. u = 10 * 9,9045/(10 + 50) = 1,6508 м/с.
3. Для C: F_{EX} = 50 * (1,6508 - 0)/0,05 = 1650,8 Н.
4. Проверка по A: F_{EX} = 10 * (9,9045 - 1,6508)/0,05 = 1650,8 Н.
5. s = 1,6508^2/(2 * 0,3 * 9,81) = 0,463 м.

#### 5. Проверка результата

- Силы A на C и C на A равны по модулю 1650,8 Н и направлены противоположно.
- 3300 Н ≈ 1650,8 Н + 1650,8 Н — это сумма модулей пары действие-противодействие, а не одна сила между телами.
- Для объединённой замкнутой системы A + C контактные силы внутренние, поэтому их сумма не является внешней силой системы.

## Ответ

**v_D = 9,9045 м/с; u = 1,6508 м/с; F_{EX} = 1650,8 Н; s = 0,463 м**
