## Условие на русском

- Тело A лежит на наклонной плоскости, а тело B — на горизонтальной плоскости. Оба тела соединены тросом, проходящим через блок, как показано на рисунке к задаче. Тело B тянут горизонтальной силой P. Масса тела A равна 40 кг, тела B — 60 кг. Коэффициент статического трения между телом A и наклонной плоскостью \mu_{s1} = 0.2, а коэффициент статического трения между телом B и горизонтальной плоскостью \mu_{s2} = 0.3.
- а. Начертите схемы сил, действующих на каждое из тел A и B непосредственно перед началом движения тел вправо и вверх по наклонной плоскости.
- б. Рассчитайте натяжение троса, необходимое для начала движения тела A вверх по наклонной плоскости.
- в. Рассчитайте силу P, которую необходимо приложить к телу B для начала его движения вправо.
- Примечание: трением в блоке пренебречь и считать натяжения в обеих ветвях троса равными.

## Подсказка: модель

На грани движения статическое трение достигает предельного значения.

## Экзаменационное решение

### Дано

- m_A = 40 кг на плоскости 30°
- m_B = 60 кг горизонтально
- μ_{s1} = 0,2
- μ_{s2} = 0,3
- движение A вверх, B вправо.

### Найти

- Схемы сил
- T
- минимальная P.

### Перевод в СИ и обозначения

- Все данные уже в СИ.

### Решение

#### 1. Физическая модель

На грани движения статическое трение достигает предельного значения.

#### 2. Базовые законы

- N = m * g * cos(α)
- F_{тр,max} = μ_s * N
- ΣF = 0 на грани движения

#### 3. Вывод расчётных формул

1. Для A трение направлено вниз: T - m_A * g * sin(α) - μ_{s1} * m_A * g * cos(α) = 0.
2. Отсюда T = m_A * g * (sin(α) + μ_{s1} * cos(α)).
3. Для B: P - T - μ_{s2} * m_B * g = 0, поэтому P_{min} = T + μ_{s2} * m_B * g.

#### Обязательное построение

- Тело A: m_A * g вертикально вниз; N_A перпендикулярно плоскости; T вверх по плоскости; f_A = μ_{s1} * N_A вниз по плоскости.
- Тело B: m_B * g вертикально вниз; N_B вертикально вверх; P вправо; T влево; f_B = μ_{s2} * N_B влево.
- На каждой схеме оси направить вдоль предполагаемого движения и перпендикулярно опоре.


#### 4. Подстановка и последовательный расчёт

1. Для A, готового двигаться вверх по плоскости 30°: T = m_A * g * (sin(30°) + 0,2 * cos(30°)) = 264,17 Н.
2. Для B, готового двигаться вправо: P > T + 0,3 * m_B * g = 440,75 Н.

#### 5. Проверка результата

- Направление трения на каждом теле противоположно предполагаемому началу движения.

## Ответ

**схемы сил заданы; T = 264,17 Н; P > 440,75 Н**
