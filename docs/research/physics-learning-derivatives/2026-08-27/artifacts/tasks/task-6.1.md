## Стандарт математической записи

Индекс записывается через `_`: `v_A`, а составной индекс — в фигурных скобках:

Например: `v^2 = v_0^2 + 2 * a * s`.

## Условие на русском

- Тело A весом (Q) 200 Н тянут с постоянной скоростью силой Q, равной 160 Н, вниз по наклонной плоскости на расстояние 1,5 м. Сила Q наклонена к горизонту под углом 10°. Коэффициент статического трения (\mu) между наклонной плоскостью и телом A равен 0,3, а угол наклона \theta равен 40°.
- Рассчитайте работу каждой отдельной силы, действующей на тело A, а также полную работу всех сил, действующих на тело совместно.

## Сначала поймём задачу

### Что здесь происходит

Тело перемещается вниз по склону, а каждая сила образует свой угол с перемещением; знак работы определяется этим углом, а не названием силы.

### Что нужно вспомнить

- Работа зависит от компоненты силы вдоль перемещения.
- Теорема о кинетической энергии связывает суммарную работу с изменением скорости.
- Мощность показывает скорость совершения работы.

### Почему подходит этот принцип

**Работа, энергия и мощность.** Энергетический баланс связывает начальное и конечное состояния без описания каждого мгновения, но в него должны войти работы всех сил, меняющих механическую энергию.

Условия применимости:

- Начальное и конечное состояния определены однозначно.
- Для каждой силы установлен угол к перемещению и знак работы.

### Маршрут решения

1. Нарисовать перемещение и все силы на одном теле.
2. Для каждой силы определить угол к перемещению и вычислить работу отдельно.
3. Сложить работы и сопоставить сумму с изменением кинетической энергии.

### Главная ловушка

> Нормальная реакция имеет нулевую работу, потому что перпендикулярна пути, даже если её модуль велик.

### Что часто путают

- Складывать модули работ, теряя знак.
- Путать среднюю мощность за интервал с мгновенной мощностью.

### Проверьте себя до вычислений

- Почему работа тяжести положительна при движении вниз по склону?
- Какая сила даёт отрицательную работу и что это означает для энергии?

## Подсказка: модель

Перемещение направлено вниз по склону. Для каждой силы применяем W = F * s * cos(γ), где γ — угол между силой и перемещением.

## Экзаменационное решение

### Дано

- Вес тела G = 200 Н
- приложенная сила Q = 160 Н под 10° к горизонту
- угол склона θ = 40°.
- Перемещение вниз по склону s = 1,5 м
- коэффициент трения μ = 0,3.

### Найти

- W_N — работу нормальной силы
- W_f — работу силы трения
- W_G — работу силы тяжести
- W_Q — работу силы Q
- W_{Σ} — суммарную работу.

### Перевод в СИ и обозначения

- Все данные уже в СИ.
- Положительное направление оси Ox выбираем вниз вдоль склона.

### Решение

#### 1. Физическая модель

Перемещение направлено вниз по склону. Для каждой силы применяем W = F * s * cos(γ), где γ — угол между силой и перемещением.

#### 2. Базовые законы

- W = F * s * cos(γ)
- f = μ * N
- N = G * cos(θ) - Q * sin(θ + 10°)
- W_{Σ} = W_N + W_f + W_G + W_Q

#### 3. Вывод расчётных формул

1. По схеме сил углы с перемещением равны: γ_N = 90°, γ_f = 180°, γ_G = 90°-θ = 50°, γ_Q = θ + 10° = 50°.
2. Из проекции сил на нормаль к плоскости: N = G * cos(θ) - Q * sin(θ + 10°); затем f = μ * N.
3. W_N = N * s * cos(90°) = 0; W_f = f * s * cos(180°) = -f * s.
4. W_G = G * s * cos(90°-θ); W_Q = Q * s * cos(θ + 10°).
5. Суммарная работа равна алгебраической сумме отдельных работ: W_{Σ} = W_N + W_f + W_G + W_Q.

#### Обязательное построение

- Изобразить тело на наклонной плоскости и стрелкой показать перемещение s вниз по склону.
- Из центра тела провести: G вертикально вниз, N перпендикулярно плоскости, f вверх по склону против перемещения, Q под 10° к горизонту.
- Подписать углы между каждой силой и перемещением: 90° для N, 180° для f, 50° для G и 50° для Q.


#### 4. Подстановка и последовательный расчёт

1. N = 200 * cos(40°) - 160 * sin(50°) = 153,21 - 122,57 = 30,64 Н.
2. f = μ * N = 0,3 * 30,64 = 9,19 Н.
3. W_N = 30,64 * 1,5 * cos(90°) = 0 Дж.
4. W_f = 9,19 * 1,5 * cos(180°) = -13,79 Дж.
5. W_G = 200 * 1,5 * cos(50°) = 192,84 Дж.
6. W_Q = 160 * 1,5 * cos(50°) = 154,27 Дж.
7. W_{Σ} = 0 - 13,79 + 192,84 + 154,27 = 333,32≈333,3 Дж.

#### 5. Проверка результата

- Знаки определены углами: нормальная сила перпендикулярна перемещению, трение направлено против него, G и Q имеют составляющие вдоль перемещения.
- Проверка округления: 192,84 + 154,27 - 13,79 = 333,32 Дж, что округляется до 333,3 Дж и совпадает с ключом.

## Ответ

**W_G = 192,84 Дж; W_Q = 154,27 Дж; W_f = -13,79 Дж; W_Σ = 333,3 Дж**
