## 4. Строки урока, морфология, звук, слои

Атлас **не вставляет стандартный tr из таблицы Зала**, а создаёт свои `.atlas-row[data-ref]` и подключает общий ReaderMorph. `attachReaderMorph(mount, overrides)` (`public/js/library-ui.js:8311`) отсоединяет предыдущий readerMorph (8314), задаёт общие saveWord/notes/context/speakWord callbacks. Проверка места подключена в `library-ui.js:1992–1994`: `source_kind === 'atlas_block'` маршрутизируется в AtlasWords.verifyOccurrence. `ReaderMorph opts.cardTop` (`public/js/reader-morph.js:2709–2713`) принимает текстовые kicker/title/subtitle/lines, экранирует их. Открытие атласного места не пишет материал в БД; сохранение/статус — отдельное явное действие. Для курса нельзя просто назвать место atlas_block: нужен собственный проверяемый source_kind/контекст либо сознательно отключённые операции сохранения места.

**Можно ли дать {niqqud,plain,ru} без материала?** Да, через адаптер отображения `{he:pair.plain, he_niqqud:pair.niqqud, ru}` и стабильные row IDs, getters и occurrence verifier по данным урока. **Звук:** обычный `public/js/reader-core.js:748`, `attachRowAudio`, принимает getters; normalize row на 163 переносит `audio_asset_key` в `_v3_audioAssetKey`. ## 8. Мир в блоке урока

Текущий `public/js/world-engine.js` — глобальный singleton. mountStage (1089–1090) выбирает первый `[data-world-slot=...]` через document.querySelector; API в конце (1568 и далее): boot/set/current/play/signal/goTo/setLighting/visit/togglePause/stop/openPicker/debugState, **нет публичного mount(container)/destroy instance**.

Размеры не ограничены блоком: `layoutStage` (487–510) использует `document.documentElement.clientWidth`, отрицательные left/top относительно родителя, высоту от верха страницы, renderer.resize(docW,height,scale). Поэтому нельзя просто поместить существующий stage div внутрь строки и обещать изолированную сцену.

Есть pause (`togglePause`, 1071 и далее), reduced motion (`reducedMotion`, 383), visibility/resize handlers (1214 и далее); unmount (1199) чистит DOM/observers и вызывает renderer.destroy при наличии. `stop` в публичном API — endScene, не полный destroy движка. `public/js/ulpan-world.js:17` использует `opts.pack.ulpan.story`; 205 блокирует анимацию при hidden/reduced/reading/audio/editing/paused/calm, 217 destroy удаляет свои buttons. Это конкретный адаптер, не универсальный публичный загрузчик произвольного story.json.

Низкоуровневая точка повторного использования: `public/js/world-render.js:103`, createRenderer(canvas,opts); API 520–532 — resize/render/setLighting/setPose/panTo/size. Можно написать отдельный host для canvas с собственными размерами, RAF, pause/reduced-motion, звуком и очисткой; сценарный движок/pack loading и действия надо адаптировать отдельно. Без изменения API безопасный независимый embedded WorldEngine текущим кодом не предоставлен. В P3 выбрать статичную сцену/изолированный course host либо отдельную ограниченную задачу адаптации, не вызывать глобальный set для локального задания.

## Вывод для плана P3

Минимальная интеграция состоит из реестра/маршрутов, собственного course renderer с lifecycle, адаптера строк и verified occurrence, явного audio host, загрузки валидированных данных с тома, подключения P1/P2 и smoke. Общий произвольный облачный JSON, независимый embedded WorldEngine и полноценная экранная клавиатура сейчас не готовы к прямому использованию. Их нельзя закладывать в план как существующие API. Код и production в этом задании не изменялись; отчёт основан на статическом чтении текущего main, а не на повторной runtime-приёмке.
