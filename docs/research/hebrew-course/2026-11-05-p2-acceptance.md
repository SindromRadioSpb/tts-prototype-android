## Исправления

**P2-F1 (средняя): частично пройденный урок показывается как «не начат».**
Сейчас `lessonSkill` при части выполненных transfer-заданий возвращает `not_started`.
Нужно: добавить значение `'in_progress'` — есть хотя бы одна попытка по заданиям урока, но не все transfer-задания выполнены, и нет условия `needs_review`. `not_started` — только когда попыток нет совсем.
Тест: одна попытка по обычному заданию урока → `in_progress`; одно из двух transfer-заданий выполнено → `in_progress`.

**P2-F2 (средняя): привязка попытки к словам вычисляется по текущей версии урока.**
Отчёт Codex сам называет это ограничение. Уроки будут часто править, а прогресс по словам не должен «переезжать» после правки.
Нужно:
1. Экспортировать `touchedLexIds(lesson, task) -> string[]` (то же правило, что сейчас использует `itemStatus`).
2. `record` принимает необязательный `lesson` и сохраняет `attempt.lexIds = touchedLexIds(lesson, task)`.
3. `itemStatus` и `courseCounts` используют `attempt.lexIds`, когда они есть, и текущий урок — только для старых попыток без `lexIds`.

Тест: попытка записана с уроком v1 (слот `drink` содержит `lx.tea`); в v2 слот переписан без `lx.tea` → `itemStatus(…, 'lx.tea', [v2])` по-прежнему учитывает эту попытку.
