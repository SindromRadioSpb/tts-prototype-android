## Исправления по независимому browser QA

1. Смена языка сохраняет экран, черновик и выбранный R/D run (O-145).
2. У пилота две содержательно разные последовательные подсказки (O-146).
3. Все восемь R/D preflight-инструкций больше не показывают точный ответ
   «сахар» до письменного извлечения. Разрешение писать без огласовок сохранено.
4. После успешного ответа клавиатурный фокус переходит к следующему вопросу;
   после ошибки записи возвращается к сохранённому черновику. Ввод черновика
   не вызывает принудительного перемещения фокуса.
5. Физический двойной клик не отправляет пустой ответ следующего задания;
   удержание Enter/Space не активирует новую кнопку.
6. Ключи недоступны после Finish и reload, пока пользователь отдельно не
   нажмёт их раскрытие. Неудачная запись не раскрывает ключи.

## Честные ограничения

Аудиофайлов нет. Аудирование, произношение, физический iPhone/WebKit,
assistive-technology и учебный эффект на реальном ученике не проверены.
Открытые языковые действия сверяются по авторской рубрике, не сертифицированным
языковым экзаменатором. Приложение показывает эти границы, а не выдаёт текстовые
задания за аудирование. R/D — клиентский учебный сценарий: ключи присутствуют
в JSON, часы устройства и самоотчёт о помощи не имеют серверной аттестации.

Текстовый экспериментальный выпуск не означает полную педагогическую готовность
аудиокурса. Утверждения о независимом контроле относятся только к сохранённым
условиям конкретной попытки. Исторические локальные отчёты сохранены как evidence,
но не заменяют будущую проверку опубликованной версии.
