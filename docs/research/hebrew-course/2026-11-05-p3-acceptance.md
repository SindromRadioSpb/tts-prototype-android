## P3-F1 (высокая, педагогика): огласовка берётся из общей настройки Зала, а не из уровня урока

Наблюдение:
- на `ru-390-scene.png` реплики урока 1 показаны без огласовок (`שלום. אפשר קפה בלי חלב`), а образец в задании — с огласовками (`אֶפְשָׁר תֵּה בְּלִי סֻכָּר`);
- причина — `public/js/course-reader.js:88`: `opts.layers?.niqqudMode === 'off' ? plain : niqqud`, режим берётся из `room.niqqudMode`, по умолчанию выключенного;
- спека §4.6: в начале курса огласовано всё, опоры снимаются по урокам. Начинающий не должен видеть первый урок без огласовок только потому, что так настроен Зал для чтения книг.

Нужно:
1. Поле урока `niqqud: "full" | "new" | "tap"` (по умолчанию `"full"`) в формате v1: валидатор, `COURSE_FORMAT_V1.md`.
   - `full` — все ивритские строки урока огласованы;
   - `new` — огласованы только токены единиц из `introduces` этого урока, остальные — полное письмо;
   - `tap` — полное письмо, огласовка по касанию строки.
2. Общая настройка `room.niqqudMode` к курсу **не применяется**. Вместо неё переключатель курса «Огласовки: как в уроке / всегда / никогда», ключ `course.<courseId>.niqqudOverride`, хранится локально.
3. Одно правило для сцены, текста, образцов, вариантов `choice` и пар `match`.

Тесты:
- урок без поля → сцена и образец с огласовками при `room.niqqudMode = 'off'`;
- `new` → огласовано только слово из `introduces` (`קָפֶה` в строке `אפשר קָפֶה`);
- override «никогда» → `plain` везде;
- скриншот RU 390 сцены после исправления.
