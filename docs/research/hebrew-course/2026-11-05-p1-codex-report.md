## Уточнения и отступления

- Handoff требует пять файлов тестов, но план называет четыре. CLI вынесен в пятый `courseCli.test.js`, без изменения смысла проверок.
- Контракт assess не принимает course. Для preknown вызывающая сторона задаёт `index.preknown = course.preknown`; это описано в каноне формата. Формы требуют своих изученных ID, знание леммы не означает знание всех форм.
- Альтернативные seq одного значения слота могут иметь одинаковый key (service/here); повтор ID сущностей остаётся ошибкой.
- Поля перевода ru у реплик и абзацев представлены объектами `{ru}`, согласно общему требованию локализуемого ученического текста.
- Для confirm разные наборы слотов card/claim дают unknown: неполная карточка не позволяет проверить всю реплику. Начальное לא при исправлении подтверждения трактуется как ввод исправления.
- Граф использует явно сохранённое plain; сохраняет всех кандидатов омографов и многословные ключи. При неоднозначности плотность консервативно учитывает нового кандидата. Структурная проверка не доказывает смысл омографа или новизну контекста.
- Добавлены проверки обязательных полей spec, некорректных структур и безопасных путей CLI; новые зависимости не добавлялись.
- Полный npm test запущен на итоговом коде. Для focused-проверок использовался node --test, поскольку npm test -- <file> в этом репозитории всё равно добавляет весь набор.
