# Общий полный экспорт Atlas — локальная реализация

Ветка `research/atlas-transfer-audit`, базовый main eb5fad7c. Новые редакции и runtime на production не публиковались.

## Различия корпусов

Оба используют `linguistpro.atlas-reader-index.1.0.0` и reader sections. 97001: 21 раздел / 203 страницы, immutable revision и manifests, отдельный закреплённый context. 97002: 42 раздела / 564 страницы по локальному index/source manifest, каталог DATA_DIR/atlas/a97002; такого immutable pin нет. Различия хранения требуют двух адаптеров, а не двух независимых экспортёров. Любой следующий корпус этого reader-типа может использовать каталог и source descriptor. Иные типы корпусов (обычные книги, courses, physics) этим контрактом автоматически не охватываются.

## Реализация

`lib/atlasMaterialExport.js`: единый формат ZIP `linguistpro.atlas-material.1`, неизменённые байты файлов, manifest размеров/SHA-256 и привязка PDF. Pinned adapter проверяет manifests и каждый файл. Legacy adapter снимает копию во временный каталог и повторно проверяет состав/хеши исходников: изменение во время операции блокирует выдачу. ZIP читается только из зафиксированной копии. Один экспорт на процесс; архив передаётся потоком, временная копия удаляется после завершения/ошибки. Лимит 512 MiB на файл / 2 GiB на материал.

Owner-only API: `GET /api/atlas/:id/material-export` (доступность), `GET /api/atlas/:id/material-export.zip` (полная проверка, сборка и native download). Без owner — 401/403. Исходники и PDF не выдаются через публичный static маршрут. В reader владельцу добавлена ссылка, строки RU/HE/EN; нет проверенного исходного пакета — явное сообщение, а не неполный ZIP. Не читаются atlas-review, БД, профиль, прогресс и настройки пользователя.

Полные исходники подключаются в `DATA_DIR/atlas-sources/<id>/`. `manifest.json` содержит `atlas_id`, `pdf` (путь PDF), `files` (путь → sha256/bytes). Копировать сюда только исходный/редакционный материал, не профиль или секреты. Локальный intake:

```text
node scripts/atlas/register-export-sources.cjs a97002 <каталог исходников> <имя.pdf> <новый каталог atlas-sources/a97002>
```

Скрипт не перезаписывает каталог, запрещает ссылки, пишет manifest последним. До подключения полного источника нельзя объявлять полноту. Полный PDF 97002 должен соответствовать каноническому source manifest SHA-256 `e5f20b1a41257ee84978c45568576205f04dc1f69fdb4be9adf541b5ca7b73e3`. Локальный data/atlas/a97002 содержит только index/sections — это не полный материал для приёмки реальной загрузки.

## ИИ-зависимости

Офлайн prepare теперь инвалидирует все разделы при изменении PDF/изображений/assets/sources. Добавления, удаления и изменения байтов при том же имени учитываются. В новом ZIP есть ai_dependencies_sha256 для исходников, изображений и разделов; экспорт не присваивает редакционное одобрение. Для legacy без доказанной привязки ИИ к этим зависимостям явно записывается `unverified_requires_review`, для pinned — `pinned_dependencies_unchanged`. Статус не означает научную или человеческую вычитку.

## Доказательства и границы выпуска

- 6 backend/API тестов: оба адаптера и будущий типовой ID, все байты ZIP, неизвестные поля, запрет без PDF, повреждение, отсутствие изображения, права доступа, очистка временного каталога и конкурентное изменение legacy.
- 5 существующих atlasEdition tests прошли после расширения API contextPin.
- 4 browser component cases: RU 380px, HE RTL 1280px, отсутствие источника, скрытие для member. Проверялся фактический UI-блок с подставленными session/availability, а не полноценный owner-сеанс приложения. Снимки просмотрены.
- Python: 3 tests, включая 12 комбинаций замены/удаления/добавления PDF и изображений, реальное перемещение stale AI и блокировку неверного PDF binding.
- Реальная image-only мутация 97001: все 21 section-файла побайтно прежние, все 21 AI слоя исключены из активного каталога. Обновлённый переносимый ZIP r2 принят независимым восстановлением.

Перед выпуском нужны подключение и проверка реальных source packages обоих корпусов, полная browser/API приёмка в приложении на этих данных и стандартный release preflight/безопасная очистка. Production доступность новой кнопки здесь не заявляется. Публикация новой редакции и импорт нового API-формата в приложение не входят в этот экспортный модуль; существующие offline tools обслуживают прежний delivery-формат. ZIP API имеет отдельную явную версию и не должен подаваться в прежний importer без адаптера.
