# Учебная огласовка поверх исходного произведения — пилот 34190

Основание: одобрение владельца 2026-10-06; O-077. Исходный код: `origin/main` / `7c3b9a82`. Область: одно произведение «מול שער השמים», читатель Библиотеки. Массовая переогласовка корпуса и изменение сохранённых редакций не выполняются.

## Источники и результат подготовки

- Оригинал: https://benyehuda.org/read/34190. Его частичная огласовка `הבוֹקר הטהוֹרים.` не задаёт произношение всей строки.
- Опубликованная редакция: https://linguistpro.kolosei.com/data/benyehuda/works/34190.json, 437 строк. SHA-256 исходных байтов: `80fd43b0ea0005d9997c80bbc360c995865d1e9305d2ea11c2b3acc5a6287a3a`. Удалённый файл на томе проверен перед релизом; исходник не перезаписывался.
- `build-learning-niqqud.js` снимает исходные знаки, отдаёт Dicta 23 связных фрагмента, возвращает огласовку на исходные буквы через `fillMatres`. Границы фрагментов ограничены размером и окончаниями предложений; это не восстановление исторической абзацной разметки.
- Все 437 ID/порядок/исходные буквы и пунктуация сохранены. 2 928 из 2 953 ивритских токенов получили согласованный по буквам ответ с гласными; 25 остались без дополнения (главы א/ב/ג, имена, сокращения, междометия и слитное исходное `בביתהכנסת`). Они не заменены догадками. Это не оценка лингвистической точности 99,15 %.
- 327 строк отличаются от прежней огласовки. Строка 06: `הַבּוֹקֶר הַטְּהוֹרִים.` → `Haboker hatehorim.` / `habbôqer haṭṭəhôrîm.` / `хабокэр хатэхорим.`. Проверена в настоящем читателе для трёх профилей.
- Машинный результат не вычитан полностью. Применённый provider/model: `dicta-cloud` / `dicta-nakdan-cloud-v1` (версия адаптера, не утверждение о точной версии весов). 25 токенов и контекстные чтения имён требуют дальнейшей редакторской проверки. Правила невозможной огласовки дают один сигнал на конструкции с приставкой перед цитатой; они не являются независимым доказательством языковой корректности.

## Контракт применения

Слой: `learning-niqqud/34190-6e36585cf69be520757f6f16f28e766c.json`; полный SHA-256: `6e36585cf69be520757f6f16f28e766c9289a3bf843f9c7dcd5492bfb3d03295`, 161 891 байт. Данные находятся на persistent volume, не в Git. Тонкий `benyehuda-learning-niqqud-manifest.js` независимо версионирует этот производный слой. Каталог 8 и его ready cards не меняются: новая публикация произведения не создаётся.

Перед первым paint читатель проверяет hash слоя, source work ID, число/порядок/совокупный hash исходных строк, затем прежнюю огласовку каждой строки. Применение — копия read model; SQL/OPFS не записываются. Ручные правки, блокировки и изменённая огласовка без флага правки имеют приоритет. Другие произведения, приватные/групповые/отдельные public corpora и несовпадающие версии не получают слой. Проверки identity/epoch после ожидания не разрешают позднему ответу покрасить другой материал.

Переключатель «Огласовка: учебная · Dicta / исходная» даёт сравнение в читателе; транслит следует выбранной огласовке. Сам источник и сохранённая редакция остаются прежними. При 503/offline/hash mismatch читатель показывает источник; timeout запроса ограничен 1,8 с, успешный слой кэшируется, ошибка может повториться при следующем открытии. Полноценный offline/PWA сценарий отдельно не заявляется.

В Студию и native ZIP по-прежнему передаётся сохранённая редакция, а не эта временная проекция. Подключение учебного слоя к этим поверхностям и экспорту — отдельное расширение после пилота; оно не должно незаметно менять source/provenance.

Сопутствующий дефект: cold link старого corpus work делал `scrollToReaderRow`, сбрасывая `last_step_id`. Ранее запрет passive resume применялся только к новым learning editions. Теперь cold arrival любой карточки Бен-Иегуды предлагает resume без записи шага; явное «Продолжить» остаётся явным действием. Реальный browser fixture с сохранённым `translation` подтверждает отсутствие сброса.
