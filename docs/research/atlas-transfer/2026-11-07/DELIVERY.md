Файл: `E:/projects/tts-prototype-android/Архив/atlas-transfer-20261107/atlas97001-full-export-20261107.zip`

Размер: 264535672 байта (252.28 MiB).

SHA-256: `8edb190cac4745a883bad088234331e7ce59d493f5b4ad1e4a9c40767e84e592`.

Рядом находятся `.zip.sha256` и `.acceptance.json`. Архив содержит 882 файла:
873 файла материала, его инвентарь, три автономных инструмента, три отчёта,
русскую инструкцию и общий список контрольных сумм. PDF и исторические
редакционные/поставщицкие пакеты входят в материал. ZIP не содержит тестовых
изменений текста, пользовательского профиля или настроек сервера.

Приёмка выполнена после извлечения именно этого ZIP в новый каталог
`delivery-acceptance-clean`. Проверены SHA-256 самого ZIP, ZIP CRC, полный
инвентарь поставки, семантика материала, восстановление и повторный экспорт.
Запущен только вложенный `tools/verify_delivery.py` через Python `-I -B`,
с удалённым PYTHONPATH и рабочим каталогом распакованной поставки.
Все 873 файла восстановленного материала совпали по размеру и SHA-256.
Результат: [delivery-acceptance.json](delivery-acceptance.json).

Для использования распаковать ZIP в новый каталог, открыть `README.ru.md`
и выполнить `python -B tools/verify_delivery.py`. Затем пробная полная
проверка: `python -B tools/verify_delivery.py --roundtrip ../restore-check`.
Целевой каталог должен отсутствовать. Python 3.12+; фактическая приёмка — 3.14.
Ни репозиторий, ни npm/pip, ни сетевые подключения для восстановления не нужны.

Сборщик для повторения: `scripts/atlas/build_delivery.py --package <snapshot-package> --out <new.zip>`.
Это архив редакции, зафиксированной 2026-11-07, а не динамический экспорт
любой будущей версии. Новое получение с сервера требует нового снимка.

выполнялась, поскольку публикации не было.
