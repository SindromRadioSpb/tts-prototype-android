# Hebrew NLP Resources — программное исследование (2026-08-04)

**Что это.** Стратегическое + оперативное исследование ресурсов израильской национальной
NLP-программы (NNLP-IL/MAFAT) и смежной экосистемы Hebrew-NLP для всей программы LinguistPro:
инвентарь каталогов, верификация выбора инструментов L4 (local translation + nikud + S6),
кейс корпуса песен Shironet, возможности для существующих поверхностей и новые направления,
ранее не рассматривавшиеся. Заказ владельца 2026-08-04 (сессия post-P4).

**Источники.**
- https://resources.nnlp-il.mafat.ai/?language=hebrew — каталог национальной программы
- https://github.com/NNLP-IL/Hebrew-Resources — курируемый GitHub-список
- Hugging Face / публикации / бенчмарки (FLORES-200 и др.) — для верификации моделей

**Как сгенерировано.** 5 параллельных research-агентов (Claude Code, сессия 2026-08-04,
web-research без загрузки датасетов), синтез с ролевыми линзами R1–R17.
Оценочные оси владельца: учебная ценность / целесообразность / приоритетность / актуальность.
