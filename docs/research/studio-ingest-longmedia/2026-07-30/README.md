# S12.6 — сводка прогона ASR на 380px (скриншоты вёрстки)

**Что это.** Скриншоты НАСТОЯЩЕГО блока сводки (`StudioImport.renderAsrSummary` +
`AsrTranscript.summarizeAsrRun`, боевые `public/js/*` и боевые локали), снятые на 380×844 —
обязательная мобильная проверка вёрстки по правилу проекта. Не превью, не макет: страница-харнесс
грузит те же файлы, что грузит `index.html`, и вызывает тот же экспорт.

**Как сняты.** Playwright (chromium), viewport 380×844, `fullPage`. Скрипт-харнесс —
scratchpad сессии `a6490fa4` (`rev-s126/shot.js`): поднимает статический сервер над `public/`,
отдаёт inline-страницу с четырьмя сценариями сводки, дергает `renderAsrSummary`. В репозиторий
харнесс не кладётся: боевого кода он не содержит, а воспроизводится из этого описания за минуту.

**Источник.** Адверсариальный ревью слайса S12.6, 2026-07-30, рабочее дерево v3.11.267
(незакоммиченное на момент съёмки). Канон слайса —
`docs/planning/STUDIO_INGEST_S12_6_FALSE_GAP_COMPRESSED_MARKS_2026_07_30.md`.
