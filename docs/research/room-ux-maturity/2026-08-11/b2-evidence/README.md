3. `Сегодня` содержит только доступные действия: каноническое SRS-повторение, текст с реально известным числом строк и разрешённый групповой корпус;

5. компактные входы во все реальные корпуса;

Новых таблиц, stores, рекомендательных оценок и самостоятельных learner-state writers не добавлено. `Continue` читается из `texts + text_progress`; очередь повторения — из существующего `_dueCounts`; стартовая рекомендация — из `buildNextTextPicks`; разрешённые учебные материалы — из `groupCorpora`.

## Продуктовые решения B2

- Один выразительный блок получает тёплый редакционный акцент; остальные элементы остаются плотными строками. Это сохраняет премиальную иерархию без «стены теней».
- Процент чтения показывается только при известном числе строк; иначе интерфейс честно называет последнюю строку.
- Процент знакомых слов показывается только при числовом `pick.cov`. Cold start использует внутреннюю лёгкость текста и не притворяется персональным профилем.
- Короткий текст попадает в `Сегодня` только при числовом `segments`; выдуманного времени чтения нет.
- Название закрытого корпуса считается авторитетными серверными данными и не переводится клиентом. Поэтому HE fixture сохраняет выданное сервером русское название «Учебные песни» — это проверка честного отображения, а не утечка locale-key.
- Локально оставшийся закрытый текст допускается в `Continue` только если текущий membership-filtered каталог всё ещё разрешает его корпус; локальный байт не считается действующим entitlement.
- Число «Моих текстов» берётся точным `COUNT(*)`, а не ограниченной browse-выборкой; неизвестный `works_count` группового корпуса не превращается в косметический ноль.
- Ссылки на тексты остаются настоящими `href`: обычный клик открывает тёплый reader, а modifier/right-click сохраняет нативную навигацию.
- Стрелки действий зеркалятся для RTL.

## Найденные и закрытые регрессии

- Старые browser-smoke сценарии ждали удалённые `.hub-cards`; они переведены на семантические `.learning-corpus-entry` и новый L0-контракт.
- В панели reader тест (и потенциальная автоматизация) путал переключатель учебного режима с «Статусом слов», потому что оба label имели `.reader-aids-status`. Переключатель статусов получил стабильный `#readerWordStatusToggle`, а учебный режим — отдельный класс.
- При смене языка внутри SRS-модали Learning Home пересобирался, старый inline-триггер удалялся, и закрытие возвращало focus в `body`. Триггер получил стабильный `data-focus-key`; `roomFocusRestore` теперь находит его свежий экземпляр. Интеграционный гейт `studio-room-srs` проходит `49/49`.
