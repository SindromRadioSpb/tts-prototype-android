# Медиатека: обложки подборок, единые названия и безопасная очистка

2026-09-12. База `c3e27793`, целевая версия `3.11.526`. Вручную составленный отчёт по скриншоту и поручению владельца. Читать/комментировать этот файл; PNG и evidence.json — результаты автоматических проверок, не редактировать. Временные БД и кэш в `.tmp` не являются результатом.

## Изменения

- Удалено искусственное дополнение обложки до трёх частей с названием подборки. Один реальный материал занимает всю ширину, два — две части, три и более — первые три реальных материала. Пустая или полностью недоступная подборка имеет нейтральный значок; её название остаётся под обложкой.
- Единая пользовательская схема: **Материалы → Темы → Подборки**. Вложенные темы называются подтемами. Исправлены RU/EN/HE: создание/изменение/удаление, объединение, поиск, фильтры, добавление, экспортные подсказки, редакторское сравнение изменений. Имена пользовательских подборок не переписываются. Внутренние ключи `category`, стабильные ID, структура хранения и миграции не менялись.
- R4/R6: обложка показывает реальный состав, терминология едина. R11/R13: это изменение представления, без миграции пользовательских данных. Публичные редакторские границы сохранены.
