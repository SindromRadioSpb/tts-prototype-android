# Выбранные учебные цели: реализация V2

Дата: 2026-10-21. База `2952e5da` / 3.11.803; версия кандидата 3.11.804. Контракт утверждён владельцем: [план](../../../planning/MORPHOLOGY_LEARNING_TARGETS_V2_2026_10_21.md). Evidence: локальные автоматические проверки на изолированных данных; production ещё не обновлён. Профиль владельца не использовался для пробных отметок или оценок.

## Поведение и данные

- Общая карточка Зала и Студии по умолчанию показывает «Мой статус слова» с леммой и её значением. «Учить эту форму» включает одну форму; при омографии нужно явно выбрать грамматическое чтение. Переключатель «Слово / Эта форма» меняет область одной палитры и строки повторения.
- `learning-targets.js` задаёт `ft1:<pid>:<slot>:<clitic codes>`; `learning-target-repository.js` атомарно записывает mark/seed и отдельную проекцию в прежних `review_log`/`word_status`. Новых таблиц и миграции старых историй нет.
- Карточка не создаёт оценки ответа при включении. Самооценка l1–l4 может посеять собственный FSRS. Ответ в упражнениях относится только к выбранной цели. Алиасы формы в слово или другую форму запрещены на клиенте, сервере и при свёртке истории.
- Тренировка требует полную форму; для `שֶׁפָּחַדְתָּ` вариант `פחדת` ошибочен. Проверка допускает поддерживаемые графические варианты одной клетки. Старый MC с обрезанием приставок для форм отключён; используются ввод/буквы.
- В словаре выбранные формы находятся под родительским словом. Форма не увеличивает число известных слов и не красит другие формы как известные. `form-drill` ведёт прежние счётчики и добавляет текущий ответ в FSRS только для явно включённой клетки без клитики; старые счётчики не мигрируют в ответы.
- Цель с клитикой без проверяемого примера на устройстве сохраняется, но недоступна для упражнения до открытия источника. Огласовку приставки не синтезируем. Bare cell восстанавливается по Pealim. Серверные внешние упражнения не подставляют родительское слово вместо неподдерживаемого `ft1`.
- Структурный ключ, marks и reviews проходят обычный cloud sync и полный/карточный bundle. Class-A не содержит новых текстовых описаний цели. Пример остаётся локальным содержимым материала.
- Чтение списка целей вынесено из массового `resolveWordLight` в открытие карточки; массовый скан не получает SQL-запрос на каждое слово. Версионные ссылки LocalDB едины для всех поверхностей.
