## Как пользоваться

1. В сохранённой карточке откройте метаданные → **Источник видео**, вставьте ссылку YouTube.
2. Если у таблицы есть временная разметка, проверьте начало, середину и конец через **Проверить видео и строки**. При необходимости задайте смещение. Подтверждение синхронизации сохраняется только после явной отметки.
3. **Видео и строки** открывает общий экран; в Зале кнопка находится у открытого материала. Для роликов с разрешённым встраиванием доступны обычный плеер и повтор строки.
4. В результате импорта можно выбрать **Подготовить и сохранить**: выбранный переводчик → карточка → подготовленный ZIP. Продолжение прерванной задачи доступно в Библиотеке → **Задачи подготовки**. Загрузка ZIP требует отдельного нажатия; проверьте сохранённый файл.
5. Пакет с источником YouTube имеет формат v3; файл MP4 в него не входит. Офлайн доступна таблица. Старый клиент должен обновиться, прежде чем импортировать v3.

## Воспроизводимость

В корне репозитория запустить тестовый сервер без владельческих credentials на `127.0.0.1:3336`, затем:

```
node scripts/premium/youtube-learning-browser-smoke.cjs
node scripts/premium/study-video-browser-smoke.cjs
# Отдельно: реальное YouTube-воспроизведение, сеть обязательна:
# STUDY_VIDEO_ID=iG9CE55wbtY
node scripts/premium/study-video-live-smoke.cjs
node scripts/test-unit.js --test-reporter=tap
```

`evidence.json` — краткая сводка инженерных проверок; `production-verification.json` — отдельное подтверждение production. PNG — просмотренные браузерные снимки тестовых материалов, не независимая оценка транскрипта. Править пользователю ничего не требуется. Сырые логи, OPFS-профили и ответы оплаченного Gemini-пилота находятся только в локальных scratch-артефактах и не публикуются. Повторять платный пилот автоматически нельзя: его локальный budget ledger сохраняет неизвестные резервы.
