## Отступления от протокола (честно)

1. **Правило совпадения уточнено после просмотра первого прохода** (A1–A3 в `score.js`): лемма-оракул, совпадающая с
   цитатной формой парадигмы (лемма; у глагола — 3 л. ед. м. р. прош. и инфинитив), — согласие; экзаменатор, не
   отделивший проклитики (`בטעות` целиком), воздерживается; род числительного (אחד/אחת) — не личность. Причина: исходное
   правило метило «неразличимо» 28 из 60 случаев S1, где экзаменатор называл ту же лемму, что программа (омографы
   парадигм). Влияет на S1–S3 в сторону программы; в 50 случаях владельца решал владелец.
2. **Для ответов владельца правило строже машинного:** выбран вариант не программы при показанном варианте программы —
   ошибка программы (кроме цитатной формы той же леммы). Клеточное совпадение там врёт: `חלקה` — клетка «гладкий», а
   владелец имел в виду «первую стрижку».
3. **Голос владельца — с помощью ChatGPT** (видно по ссылкам в пояснениях). Это повышает независимость от автора (другое
   семейство моделей), но не делает его человеческим эталоном.
4. **Предсказательная сила (п. 5 протокола) не измерена:** тест по журналу негоден по устройству (ниже). Порог протокола
   к нему не применён.
5. Калибровка всех экзаменаторов — на современном иврите без огласовки; на архаике Бен-Иегуды их точность не измерена.

## Предсказательная сила статуса — почему не измерено

1063 повторения по 327 словам (2026-07-02 — 2026-10-13). Успех по ручному статусу на момент повторения, формат «плитки»:
l1 90 % (41), l2 79 % (29), l3 73 % (126), l4 84 % (123), «знаю» 90 % (30) — без монотонности. Но повторения идут по
расписанию FSRS, которое назначает каждое слово на момент ≈ 90 % вероятности вспомнить, **при любом статусе** — успех
выравнивается по построению. Годная проверка — слепой опрос вне расписания (например, 40 случайных слов, по 8 на статус,
один формат, ~10 минут).

(Попутно: казавшиеся сбоем 0/22 «печатных» повторений со стадией l4 — не дефект: `training_stage` в журнале — стадия
ПОСЛЕ ответа; «l4 + провал» = понижение со «знаю».)

## Опровергающий разбор по ролям

- **R10 (морфолог, независимый эталон):** впервые замер не «Dicta против Dicta»: три независимых экзаменатора + владелец.
  Слабое место R10 подтверждено: путь `likely` берёт клетку чужой парадигмы, когда у формы есть своя статья (тип A) —
  это не контекст, а порядок поиска; правится офлайн и детерминированно.
- **R11 (не портить верное):** Д7 нетто-монотонен (1/60). Д8-К3 **уже применил 1173 слияния историй** на лексиконе S4,
  где 16 % ключей ложные; подозрительные слияния видны и в плане (`בעל` → `dl:על#adverb`, Шломо → «целый», Мирьям → глагол
  `רום`). Откат — только выборочный, обратными событиями (`undoKeyAliases`), только для подтверждённых классов, после
  проверки списка тем же способом. Журнал не переписывается.
- **R7 (регистр):** имена и иноязычные строки (песни, арабский, аббревиатуры с ״) — главный класс S4; на архаике
  экзаменаторы не калиброваны — выводы по Бен-Иегуде слабее, чем по новостям и субтитрам.
- **R16 (стоимость):** вся проверка — локальные модели + один агент (~170 тыс. токенов) + 300 предложений через уже
  используемый путь Dicta; правки A и B — офлайн, без ИИ на пути ученика.

## Правки по цене ошибки (решение владельца)

1. **Д8-К3: проверить 1173 применённых слияния** тем же методом (экзаменатор + правила B/C) и выборочно откатить ложные
   обратными событиями. Самая дорогая ошибка: слияние склеивает историю двух разных слов.
2. **Лексикон Dicta (S4) — фильтр на входе:** не делать слово из имени / иноязычной строки / аббревиатуры с ״ и стяжения
   с ׳; если у формы есть собственная статья Pealim (בדואי, חיות) — брать её; лемма во мн. ч. — к ед. ч. Перемерить S4.
3. **Путь `likely` (S2, тип A):** собственная статья Pealim с той же формой (без проклитик) важнее клетки чужой
   парадигмы. Меняет ключи этих слов → перенос отметок тем же механизмом Д7.2. Перемерить S2.
4. **Имена (тип B, S5 22 %):** газеттир имён — отложенный пункт R2 исследования 2026-06-25 (KIMA / Wikidata).
5. **Многозначные «не разобрано» (54 % S5):** контекстный разбор при сборке материала — отдельное решение (R16).
6. **Слепой опрос знания** вместо журнала — если нужен ответ, считать ли «знакомо X%» знанием.
