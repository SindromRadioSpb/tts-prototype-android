## Пользовательский результат

После ответа личного наставника доступно «Закрепить за минуту». Объяснение и
полный источник скрываются, пользователь восстанавливает пропущенное слово,
при желании раскрывает его или пропускает попытку. Затем видит итог и возвращается
к объяснению/тексту. Источник — выбранное предложение; эталон не создаётся LLM.
Слово берётся из вопроса при точном совпадении, иначе выбирается длинное слово
исходника. Это прозрачная техническая эвристика, не диагностика учебного пробела.

Огласовки не оцениваются; буквы/конечные формы не подменяются. Все одинаковые
вхождения целевого слова скрыты. Для длинных (>600 символов), коротких (<3 слов)
и неподходящих фрагментов предлагается продолжить разбор, без выдуманного задания.
Независимая грамматическая оценка не заявляется: другой ответ может быть допустим
по смыслу. В интерфейсе различаются «совпало с исходником», «в исходнике иначе»
и «пропущено», видна использованная подсказка.

## Данные и границы

Миграция 071 добавляет `tutor_practice`, привязанный FK к исходной tutor session.
Сервер хранит скрытый эталон, source digest/revision, одну попытку, её ключ и hash.
API rechecks owner/connection/TTL на каждом действии. Повтор идентичной попытки
возвращает прежний итог; изменение уже записанной попытки отклоняется.

`source_seen=true`, `explanation_seen=true`, `hint_seen`, `niqqud_scored=false`,
`evidence_kind=post_explanation_source_recall` сохраняют происхождение помощи.
Никаких вызовов canonical review writer, записей в FSRS/mastery или review_log.
Канонический путь оценивания остаётся единственным для будущих настоящих reviews.
Эта короткая практика после объяснения не становится доказательством независимого
знания. Итог живёт до TTL исходной сессии (15 минут); постоянные артефакты — M4.

## До полной приёмки M2

Нужны независимо отредактированные смысловые/грамматические задания, набор
допустимых вариантов, неоцениваемые неоднозначные ответы, проверка качества на
реальных разнородных материалах. Source recall позволяет поставить ограниченный
рабочий цикл сейчас, но не заменяет эти gates. M3 — consumer connection wizard;
M4 — артефакты/четыре поверхности; M5 — grammar map и инициатива.

Production rollout фиксируется отдельно в [release evidence](PRODUCTION_ROLLOUT.md).
