## Кросс-поверхностный сценарий (R11)

1. Студия, несохранённая таблица → тап מלחמה → метка l2 → `word_status['pid:3704']='l2'`
   (глобально по лемме) + seed-строка `review_log` + расписание FSRS.
2. Страница Студии закрыта (headless-OPFS: одна страница за раз), открыт Зал →
   Корпус → «Мои тексты» → текст с тем же словом → слово раскрашено `.rm-w-l2`.

Вывод: continuity цвета/статуса между поверхностями — by construction (одно хранилище,
один ключер, один канон метки через `morph-host.js`).
