# Пилотный архив для поставщика содержимого (dots)

**Что это.** Архив `a97002-pilot-for-dots.zip` — всё, что нужно ИИ-наставнику dots для пилотной
поставки атласа נוסחאון 97002: инструкция (`README.ru.md`), задание (`TASK.ru.md`), исходный пакет
страниц 7, 197, 282, 284, 287, 288, 289, 485, схемы, валидатор и эталон.

**Как получен.** `python scripts/atlas/build_dots_bundle.py --out docs/research/engineering-atlas/2026-10-30-pilot-pack/a97002-pilot-for-dots.zip`
Сборка воспроизводима (фиксированное время и порядок файлов): те же входы дают тот же SHA-256.

**Версия, переданная dots 2026-10-31:** 50 файлов, 7 032 079 байт,
`sha256 8148bf48f0538141695537b3d12458152e02a4206c71ef190371e4cfcfaa96c1`;
`source_pack_sha256` = `f3905a6e1498a0c790d39e175b37386797d60ce1a2027594afb670cd4411c0f1`.

**Почему zip не в git.** Он на 99 % состоит из уже закоммиченного исходного пакета
(`atlas/a97002/pilot/source-pack/`, 6,8 МБ) и собирается заново командой выше; копия для dots лежит в
папке Google Drive владельца (ссылка намеренно не в репозитории — он публичный).

**Статус.** `ready-for-dots`. Ответ dots импортируется так:
`python scripts/atlas/atlas_import.py --source atlas/a97002/pilot/source-pack --content <ответ>.jsonl --out <папка>`.
