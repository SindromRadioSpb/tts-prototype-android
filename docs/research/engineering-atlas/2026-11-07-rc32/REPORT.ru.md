Дата: 2026-11-07. Основание: пакет владельца `atlas97001-full-native-rc3-scoped-20261107.zip`, базовый commit `cec374dec254d5213dcf21170c1042f9d2f93478`. Пользователь разрешил публикацию после проверок и выбрал новый корпус вместо замены первоначальной редакции.

- Исходный AI context остаётся привязан к старой редакции. Новый корпус отвергает загрузку AI context до сетевого запроса. Сертификация всех строк, научных утверждений, огласовок или переводов не заявляется.

## Изменения runtime

Проверены все 16 файлов исходного patch и новые build/test-файлы. Patch без конфликтов проходит `git apply --check` на точном базовом commit. Его переключение единственного PIN было заменено двумя клиентами с разными corpus ID. Добавлены карточка и переводы RU/EN/HE, согласованы shell/SW/module URLs, сохранён первоначальный PIN. Внесены проверки granular eligibility, таблиц с частями/подписями, MathML, точных областей термина и удержания старых оценок из пакета. Недопущенные значения символов и единиц также исключены из scoped-редакции.

Проекция ID требует проверки поисковых связей по исходному манифесту: повторная сериализация проекции даёт другой SHA. Исходные файлы по-прежнему полностью проверяются до проекции, затем `checkLink` проверяет равенство межфайловой ссылки хешу из того же манифеста. Отрицательные тесты повреждённых байтов и неправильных хешей проходят; ослабления проверки целостности нет.

## Исправление экспорта первоначального прогресса

До выкладки реальный экспорт отказал с `ATLAS_PROGRESS_SCHEMA`. Read-only диагностика через существующий выделенный snapshot RPC (без SQL из консоли, открытия профиля на диске или замены worker) установила, что валидатор не разрешал поле `confidence`, которое штатно пишет reading-tap writer. Также тест воспроизвёл отказ законной структурной ссылки `…:structure:<sha256>`. Валидатор теперь принимает только перечисленные provenance labels из ReaderMorph и точный структурный суффикс. Произвольные строки, объекты, вложенные секреты и чужие источники продолжают отклоняться. 20 schema/capture/snapshot тестов пройдены.

Для исходного снимка до релиза исправленный экспортёр временно смонтирован в разрешённой вкладке приложения, с тем же guarded read-only RPC. Глобальный экспортёр не заменялся; временный блок удалён. Файл сохранён владельцем и независимо проверен. В действующую БД импорт не выполнялся; данные не нормализовались и не отбрасывались ради зелёной проверки. Исправление самого экспортёра включено в релиз 875.

## Резервирование и откат

До публикации создан согласованный online backup SQLite, `PRAGMA integrity_check = ok`. В архиве ровно один согласованный `app.db`, без WAL/SHM; его извлечённый поток сверён по SHA256 со снимком. Архив проверен `gzip -t`. [Результат](production/backup-verification.json).

- Проверенный серверный архив: `/opt/backups/linguistpro/atlas97001-rc32-20261107/volume-before-rc32.tar.gz`, 2 378 830 760 байт.
- SHA256 архива: `90d65fb46d5a06f932f3f134642a89cd22471e250b7f6250a27b441e05d8f136`.
- SHA256 SQLite-снимка: `e559a5822ef22189dae9a3f64575221e3cdfd4567f597b42c7d686c76e1f1b1d`.
- Старые backups и audio-cache не включались повторно в новый архив; они сохранены на сервере. Передача большого архива на Windows прервана из-за медленного SSH; локальный частичный файл не является резервной копией. Проверенная полная копия находится на сервере.
- Перед деплоем выборочно удалены только два проверенных неиспользуемых образа приложения. Контейнеры, volumes, текущий/предыдущий рабочие образы 874, образ редакции 870 и резервные копии сохранены. После резерва перед сборкой оставалось 8,34 ГБ при gate 6,44 ГБ. После выпуска свободно около 4,70 ГБ; `disk_warn=true` (88%) остаётся наблюдением, новая сборка потребует свежего capacity gate.

Обычный откат выполняется через Coolify на предыдущий работающий runtime **3.11.874**, commit/tag `8d696e1799db1b580e9fca72c7ad9df6e9d9cee4`, image `sha256:ec7de753ddd3798c9917f95cbf99eaa6b9d268fd6651712416675387f5cb0446`. Наличие образа повторно проверено после выпуска. Предрелизная read-only проверка этого runtime подтвердила чтение всех 843 manifest-файлов первоначального корпуса без открытия learner-БД: [rollback check](production/rollback-check.json). Боевой откат не выполнялся.

При откате:

1. Вернуть только runtime. Не восстанавливать старую learner-БД, не сбрасывать словарь, историю или локальные браузерные данные.
2. Сохранить оба immutable namespace, исходные PDF/ZIP, AI namespace первоначального корпуса и учебные ключи нового корпуса. Новый corpus исчезнет из старого каталога, но его данные сохранятся для повторного включения.
3. Перезагрузить вкладки RC3.2: старый сервер не знает расширенный набор файлов нового manifest. У runtime 874 также останется прежнее ограничение экспортного валидатора; это не основание изменять данные.
4. Проверить версию, health/DB/migrations и первоначальный корпус. Полное восстановление volume из архива — отдельная аварийная процедура; оно не требуется для обычного отката этого добавления.

## Что остаётся для независимой приёмки

Независимая языковая/научная проверка всех 203 страниц и физическое мобильное устройство не выполнены. 15 вопросов чтения, 5 спорных терминов, 252 неподтверждённых поля p116 и ограничение p203 остаются явно отмеченными; соответствующие недопущенные упражнения не включены. AI context новой редакции отключён. Для RC3.2 пока нет штатных экспортов полного материала/истории — [O-166](../../../planning/OBSERVATIONS_LOG.md#o-166--rc32-отдельным-корпусом-новые-экспортеры-ещё-не-подключены).

Сообщённая владельцем задержка кнопки обновления и ранняя перезагрузка в прежнюю оболочку не объявлены исправленными. Установка 875 завершилась, но причина/обратная связь требуют отдельного воспроизведения; записано O-167 в журнале наблюдений. Кэш и регистрацию SW не очищали. Эти ограничения отделены от подтверждённой интеграции и сохранности данных.

На уровне поставщицкой метки `activation.environment=isolated_staging` в разделах остаётся устаревший баннер «публикация не выполнена». Это неточная фраза интерфейса: фактический выпуск 875 подтверждён сервером, manifest и браузером. Содержание/хеш immutable источника ради этой метки не менялись; замечание O-168 требует отдельной правки отображения.
