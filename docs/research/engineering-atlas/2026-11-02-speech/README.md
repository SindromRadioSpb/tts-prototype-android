## Что сделано

- **V1. Текст для чтения** — `public/js/atlas-speech.js` (общий для выпечки и ридера). Формулы читает разбор
  подмножества LaTeX книги по словарю `atlas/a97002/speech-lexicon.json`; неизвестная команда, слово или непарная
  скобка → «записи нет» с причиной (приблизительного чтения нет, языковой модели нет). Проза — огласованный иврит
  поставщика; обозначения внутри (`Mt`, `n_rot`, `σy`, `N/mm`, формулы с ивритским индексом `nגְּזִירָה`) читаются
  тем же словарём; английские названия после ивритского термина («(reducer)», «– High-Speed Steel») не читаются.
  Ручные решения по отдельным объектам — `atlas/a97002/speech-overrides.json` (пока пусто).
- **Сверка свежести (уточнение к §4.4).** Ридер хэширует не текст чтения, а **исходные поля** объекта
  (`sourceOf`: огласованный иврит блока; LaTeX и обозначения формулы) и сравнивает с манифестом. Правка текста после
  выпечки по-прежнему глушит старую запись, а браузеру не нужен генератор со словарём. Версия словаря и правил —
  в манифесте (`lexicon_sha256`, `speech_contract`).
- **V3. Плеер** — `public/js/atlas-reader.js`: «▶ Слушать» в панели раздела, «▶ עב» в карточке формулы, мини-плеер
  (⏮ ⏯ ⏭, скорость 0,75–1,5, «Формулы», «иврит», ✕), подсветка читаемого (`aria-current`), следование прокруткой с
  паузой 5 с при ручной прокрутке и кнопкой «К читаемому месту», «читать отсюда» по нажатию на абзац, «Раздел
  прослушан · Следующий раздел →», Media Session, честный счётчик «озвучено N из M», настройки в localStorage.
  Один звук на Зал: старт атласа останавливает аудио карточки слова и строки; уход из атласа останавливает атлас.
  Нет записей у раздела → нет кнопок и **нет запроса** (список разделов с записями — поле `audio` в `index.json`).
- **Выпечка** — `scripts/atlas/atlas-tts.cjs` (`inventory` без сети, `review-pack`, `bake` с воротами D1/D5 и
  учётными данными оператора, `verify`, `index`). Пропускает ровно то, что ридер не показывает
  (`layoutPage().duplicate` и строки, показанные таблицей). Возобновляемо по ключу содержимого.
- Запись о правах D1 — `atlas/a97002/rights/tts-attestation.json` (слова владельца).
