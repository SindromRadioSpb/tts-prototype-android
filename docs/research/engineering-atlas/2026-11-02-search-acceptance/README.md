## Метод

1. Чтение кода движка и экрана.
2. Собственный набор запросов (не из эталона Codex): термины с приставками и огласовкой, словоформы, транслит,
   двухсловные запросы, обозначения (`σ_Lc`, `τ_S`, `d₁`, `F_y`, `D`, `η`), единицы (`N/mm`, `N/mm²`, `МПа`, `об/мин`).
   Метрика — **первый экран** (первые 50 результатов, как показывает ридер), метки совпадения, повторы, обрезка.
3. Прод 3.11.840 в браузере (Playwright, анонимно): RU/HE × 390/1440, запрос → результат → страница → «Назад».
4. Те же проверки на локальном сервере с исправленным кодом и пересобранными данными; смоук Codex; все наборы тестов.

## Осознанный компромисс

Запрос-единица со знаком (`N/mm`, `об/мин`) теперь находит обозначения и формулы с этой единицей, но не абзацы и
таблицы, где единица просто написана в тексте: индекс хранит текст без знаков, и «N/mm» в нём неотличимо от «N·mm».
Это честнее, чем прежние «точные» совпадения с другой единицей. Полноценный поиск единиц в тексте — запись O-141.
