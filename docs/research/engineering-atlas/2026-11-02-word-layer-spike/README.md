   оборачивает. Риск памяти/скорости обёртки — низкий; время на телефоне (CPU ×4) меряется в браузерном smoke W1

2. **Место термина находится у 85 % ссылок.** Из 1 821 ссылки блок → термин (312 терминов, 247 из них —
   словосочетания): 1 548 — весь термин стоит в тексте блока (по скелету, с приставками ו/ה/ב/ל/מ/ש/כ и окончаниями

## 2. Как подключить карточку слова (E2)

Карточка Зала (`ReaderMorph` + общий хост памяти `morph-host.js`) привязывает слово к месту одним из путей:

| Путь | Где уже работает | Что даёт атласу |
|---|---|---|
| А. «Несохранённый текст» (`getTextKey() = null`) | Студия до сохранения | разбор, статус, «в мой словарь»; **место слова теряется** — метка без источника, заметка без места |
| Б. Раздел атласа = текст в локальной базе | работы Бен-Иегуды | всё, включая разбор по месту (Д10) и повторение в контексте; **но открытие пишет 42 раздела в базу каждого устройства**, правка текста поставщиком = новая редакция, атлас появляется среди «моих текстов» |
| **В. Внешнее проверенное место** (`source_kind` + `verifyOccurrence`) | учебные решения Физики и Материаловедения (`reviewed_solution`, `public-corpus-adapter.js`, `library-ui.js` ~8404, ~10404) | та же карточка, статус, SRS-посев, заметка с местом, «в мой словарь»; **открытие ничего не пишет**; место проверяется по данным издания, иначе источник не записывается |

**Рекомендация — В.** Новый вид места `atlas_block`: ключ текста `atlas-block-v1:<atlas>:<раздел>:<sha256 содержимого раздела>`,
место = блок (`a97002:p16:b001`) + номер слова + слово. Проверка: блок есть в загруженном разделе, sha256 строки
иврита совпадает, слово под этим номером — то же. Подключение — тем же переходником `attachReaderMorph(mount, overrides)`,
что у Физики: `cellSelector` = ячейки `.atlas-he`/`.atlas-niqqud` блока, `buildOccurrence`/`verifyOccurrence` —
в новом `public/js/atlas-words.js`.

Чего у пути В нет (как и у Физики сегодня), и что с этим делать:

| Ограничение | Решение |
|---|---|
| Очередь повторения показывает слово без его предложения из атласа (`getSentenceForReview` ищет только локальные тексты) | приемлемо для W1–W3; в тренажёре G6 — читатель места `atlas_block` по данным тома |
| «Проверить морфологию» по месту (`confirmOccurrenceAnalysis`) требует локального предложения | кнопка скрыта для мест атласа (как у Физики) |
| Разбор по месту Д10 читает только локальную базу; `placeOfSpan` ищет строку `<tr>` | W2: загрузчик мест атласа отдаёт выпеченные факты для id `atlas:…` и передаёт остальные id прежнему загрузчику; `placeOfSpan` — `closest('[data-sentence-id]')` вместо `closest('tr')` (одна строка в `reader-morph.js`, Зал и Студия не меняются: у них `data-sentence-id` стоит на `<tr>`) |
| Переходник Зала один на страницу (`readerMorph` — одиночка) | атлас занимает весь Зал; при выходе из атласа хост отсоединяется (проверить в W1 тестом «вышел из атласа → карточка в обычном тексте работает») |

## 3. Нажатие на слово при открытом плеере (E3, решение владельца)

Нажатие на слово иврита **всегда** открывает карточку. «Читать отсюда» — только кнопкой ▶ у строки (3.11.843).
Прежнее «нажатие на абзац при открытом плеере = читать отсюда» (P3 V3) снимается полностью: одно правило, без
долгих нажатий. Затрагивает `atlas-reader.js` (обработчик нажатия на блок) и тест P3 V3.

## 4. Запасной путь E5 — «В контексте (ИИ)»

Если ворота W2 (выборка 100 слов) не пройдены, слой готовит ИИ-агент владельца, как для Бен-Иегуды. **Новый формат
не нужен** — атлас ложится в существующий слой `word-gloss-ai-layer-v1` (`public/js/word-gloss-ai.js`,
спецификация `docs/planning/word-layer/F3B_BUILD_AND_EXPORT_SPEC_2026_10_12.md` §3.4):

- строка = блок атласа (`he`, `he_niqqud`, `ru`); ключ строки = `r2` + хэш(слова огласовки + перевод) + `:` + число
  слов — тот же, что везде; правка текста поставщиком → ключ не совпал → подпись отбрасывается, а не врёт;
- ответ агента: `{schema:"word-gloss-ai-layer-v1", rows:[{order_index, key, model, glosses:[{gloss}], mwe:[{from,to,gloss}]}]}`,
  `glosses.length` = числу слов строки; проверка — та же `WordGlossAI.remember` (`{stored, rejected}`).

**Экспорт (архив).** Предложение: `atlas-a97002-context-export.zip` —
`manifest.json` (схема `atlas-context-export-v1`, атлас, дата, разделы с sha256 содержимого, число строк),
`rows/<раздел>.jsonl` (на строку: `order_index`, `block_id`, страница, `he`, `he_niqqud`, `ru`, список слов, `key`),
`FORMAT.ru.md` (что вернуть и как проверяется), пример ответа на 2 строки. Ответ агента кладётся рядом с разделами
на том (`atlas/a97002/context-ai/<раздел>.json`), ридер проверяет каждую строку при загрузке.
Как получать архив — вопрос E6 ниже.
