# Проверка прежнего прогресса: источник найден, копия ещё не получена

Источник — существующая вкладка Chrome Default на `https://linguistpro.kolosei.com`, атлас 97001, с.122, версия 3.11.867. Это действующий пользовательский профиль, а не автоматизационный Chrome. Корень профиля: `C:\Users\lletp\AppData\Local\Google\Chrome\User Data\Default`.

По коду установленного приложения SQLite `app.db` находится в origin storage: AccessHandlePoolVFS `/tts-opfs`, либо резервный IDBBatchAtomicVFS `tts-opfs-idb`. Наличие origin IndexedDB-каталогов подтверждено метаданными; фактически выбранный VFS и количество атласных записей не прочитаны. Физические OPFS-файлы нельзя считать самостоятельным обычным `app.db` без обработки VFS. Копирование всей базы также захватило бы данные других корпусов.

Доступный read-only интерфейс существующей вкладки предоставил DOM, но не `localStorage` и SQL/worker приложения. Это ограничение интерфейса, **не доказательство отсутствия истории**. Обход через консоль, новый CDP, сырые файлы профиля или новый DB worker не выполнялся. Вкладка не перенаправлялась, браузер не закрывался, оценки не менялись. Полный профиль, cookies, пароли, токены и база не копировались.

Проверены только метаданные известных локальных экспортов: обнаруженный экспорт библиотеки от 2 августа и локальная серверная база от августа предшествуют ноябрьскому атласу. Их содержимое не читалось; они не приняты за актуальную копию прогресса 97001. Подтверждённого текущего atlas-only экспорта нет.

Минимальный следующий шаг — получить локальный фильтрованный экспорт через уже открытое приложение и его уже инициализированное соединение, с явно разрешённым доступом к storage. Такой экспортёр ещё не установлен и не выполнялся. Не следует открывать отдельный импорт DB-модуля: это может запустить worker/миграцию исходной базы.

Предлагаемый контракт экспорта для проверки:

1. Только SELECT из `word_status`: существующие ключи `at1:a97001:%` и строки с явной source-привязкой `atlas-block-v1:a97001:%`; сохранить все поля расписания и привязки без изменения. Для общих слов это проверяет только явно привязанное к атласу текущее состояние.
2. Только SELECT из `review_log`: `item_key` с точным префиксом `at1:a97001:` и записи с однозначной atlas97001 source-привязкой в структурированных метаданных. Не включать всю историю общего lemma_key из других книг. Не выбирать по простому поиску подстроки в произвольных заметках. Сохранить исходные идентичности/оценки/время; никакого пересчёта.
3. Из origin localStorage — только записи `room.atlas.find.v1`/`room.atlas.find.stale.v1`, чьи question ID точно относятся к 97001. Сначала проверить формат ID по действующему банку; неизвестный формат оставить блокером, не экспортировать общий ключ целиком. Другие атласные настройки включать только после проверки конкретной схемы и необходимости для сценария.
4. Локальный файл в разрешённом workspace, без передачи третьим лицам; количество строк и SHA-256, без содержимого пользовательских записей в публикуемом отчёте. Загрузить только в отдельную тестовую БД. До/после новой структуры сравнить полные исходные строки и историю, отсутствие размножения родительской оценки и корректный fallback старых примеров. Исходник не импортировать и не менять.

Статус: **ожидание поддерживаемого фильтрованного экспорта/разрешённого доступа к storage**, а не отказ записи или неопределённо выполненная операция. Реальная копия не создана и тест на ней не проведён. Синтетический тест уже прошёл, но не закрывает этот gate. Production, push и очистка не выполнялись.

Повторная проверка после нового явного разрешения Петра: существующая вкладка 43738751 остаётся на версии 3.11.867, с.122. Поддерживаемый read-only scope вновь вернул `storageExposed=false`, `workerExposed=false`. Проверка export-контролов не обнаружила atlas-only экспорта word_status/review_log/find history; локальная диагностика и история наставника не подходят этому контракту и не выгружались. Технический предел доступа сохраняется. Новое разрешение не заменялось console injection, CDP или чтением сырого профиля. Нужен поддерживаемый atlas-only экспорт в действующем приложении/соединении; ещё одно общее подтверждение доступа этот блокер не устранит.
