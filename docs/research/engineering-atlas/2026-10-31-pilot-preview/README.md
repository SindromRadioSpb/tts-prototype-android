# Предпросмотр пилота атласа — экран и печать (вариант Б)

Не продукт Читального зала, а страница для приёмки: показывает ровно то, что лежит в графе атласа
(статусы, находки ядра, опечатки рядом с оригиналом).

- `dots-v1/` — **пилот от dots** (главное для приёмки): `print-variant-b.pdf` (печать, 12 листов A4 на 8 страниц
  книги — большие каталожные таблицы переносятся), `screen.html` (экран; открыть в браузере, формулы
  через KaTeX с CDN — нужен интернет), `screen-desktop.jpg`, `screen-phone-380.png` (горизонтальной прокрутки нет).
- `reference/` — то же для эталона (стр. 7 и 197 полностью).

Как получено: `python scripts/atlas/render_preview.py --source atlas/a97002/pilot/source-pack --content <пакет> --out <папка>`,
затем `node scripts/atlas/print-preview.cjs <папка>`. Статус: `preview · ждёт приёмки владельца`.
