## 1. Итог

1. Карточка слова Зала (W1) уже разбирает каждое слово атласа офлайн (словарь Pealim + огласовка поставщика). Замер на
   всей книге ([coverage.json](coverage.json), `scripts/atlas/word-card-coverage.cjs`): 27 147 употреблений, 5 698
   пар «слово + огласовка»; «точно» 41 %, «вероятно» 26 %, служебные 13 %, «подобрано» 6 %, **«не определено» 14 %**.
2. Нераспознанные — в основном **не редкие слова, а написание**: поставщик ставит огласовку поверх полного письма
   («סִיבוּב», «חִיתּוּךְ», «הִידּוּק»), а формы Pealim — огласованное письмо без матер («סִבּוּב», «חִתּוּךְ»).
   Без огласовки словарь тоже не находит (2 из 300 самых частых).
3. **Разбор Dicta по плану W2 не включён — он вредит.** Выпечка раздела s02 (`scripts/atlas/bake-atlas-parse.cjs`,
   210 строк за 52 с, 0 отказов Dicta) и прогон карточки с контекстом Dicta на всех 2 185 словах s02: «не определено»
   249 → 235 (Dicta тоже ставит огласовку поверх полного письма), зато служебные слова теряют перевод
   («לְפִי», «בְּאֶמְצָעוּת» → пусто) и часть «точно» опускается до «вероятно». Правило места Д10 (`_atPlace`) выбирает
   только между омографами Pealim и словам вне словаря не помогает. Выпечка всей книги не делалась; файл s02 —
   только локально, на том не выкладывался.
4. **Ворота E5 не пройдены: 79 из 100** (порог 95). Выборка — 5 разделов × 20 слов, фиксированное зерно
   (`scripts/atlas/word-card-sample.cjs`), вердикты — [sample-100.json](sample-100.json): верно 67 + 12 слов-терминов
   (термины 12/12 = 100 %, термин атласа сверху карточки), нет ответа 12, неверно 9 («יְחִידָה» → «единственный»
   вместо «единица», «בִּמְתִיחָה» → «гибкий» вместо «растяжение», «תַּבְרִיג» → «завинчивать» вместо «резьба»,
   «בְּאֶמְצָעוּת» → «расположение в середине» вместо «посредством», «מֵחָדָשׁ» → «новый» вместо «заново» …).
5. По решению владельца E5 провал — не блокер: сделан путь **«В контексте (ИИ)»**.

## 2. «В контексте (ИИ)» для атласа

- Формат — существующий `word-gloss-ai-layer-v1` (как у Бен-Иегуды и материалов Студии), строка = блок атласа,
  ключ строки = `WordGlossAI.rowPayloadFromData` (огласованные слова + перевод блока). Строки экспорта и ридера —
  одна функция `AtlasWords.glossRows`; совпадение ключей «экспорт = экран» проверено на всех 2 983 блоках книги
  (0 расхождений; 78 блоков без слов иврита пропускаются с обеих сторон).
- **Экспорт (E6):** `node scripts/atlas/export-context.cjs --drive=<папка>` → `atlas-a97002-context-export.zip`
  (42 раздела, 2 905 строк, 27 144 слова, 0,48 МБ): `manifest.json`, `rows/<раздел>.jsonl`, `FORMAT.ru.md` — задание и
  формат ответа. Положен на Google Диск владельца: `nuschaon/atlas-a97002/context-ai/`.
- **Приём:** `node scripts/atlas/import-context.cjs --answers=<папка|zip>` — каждая строка перепроверяется кодом
  ридера (`WordGlossAI.remember`); строка с чужим ключом, другим числом переводов или `mwe` за пределами строки
  отбрасывается, остальные пишутся в `<data>/context-ai/<раздел>.json`. Выкладка на том — отдельный шаг
  (резервная копия папки, затем копирование; деплой не нужен).
- **Ридер:** при открытии раздела загружает `/data/atlas/a97002/context-ai/<раздел>.json` (нет файла — карточка как
  раньше), `WordGlossAI.remember` проверяет каждую строку; карточка показывает «в контексте (ИИ): …» с правкой ✎.
  Общие модули поправлены минимально и только запасным путём: `word-gloss-ai.js` ищет ячейки `[data-col]`, если в
  строке нет `td`, и только у строки с `data-wg-row`; `reader-morph.js` ищет строку как `tr`, иначе `[data-wg-row]`.
- Проверка: пробный ответ на 4 строки s02 (3 верные, 1 с лишним словом) — принято 3, отброшена 1; в браузере
  карточка слова принятой строки показывает «в контексте (ИИ): [проба] 2», отброшенной — нет; ошибок страницы нет.
  Пробный слой удалён, на том не выкладывался.
