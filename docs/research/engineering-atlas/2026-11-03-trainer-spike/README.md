## Код

- **Вход в тренировку терминов** — уже есть: `startSetTraining(keys)` в `library-ui.js` («Учить эти», Ф4 · Д2)
  запускает обычную тренировку Зала по явному списку ключей. Новый вид охвата `atlas` не нужен.
- **Сборка вопроса** — `_buildDueSourcedItems` уже ветвится для `ft1:` (`_learningTargetReviewItem`); для `at1:` нужна
  такая же ветка: термин и предложение берутся из раздела атласа (по `srs_text_key` = `atlas-block-v1:a97002:<sid>:<sha>`
  и `srs_sentence_id` = блок), а не из таблицы `sentences`.
- **Оценка** — `gradeLearningTarget`/`commitReviewAttempt` в `morph-host.js` пишут строку журнала и проекцию атомарно;
  ключ ограничен разбором `LearningTargets.parse` (только `ft1:`).
- **Потребители, которые отдельно исключают `ft1:`** (нужен тот же обход для `at1:`): `public/db/local-db.js` — 3051
  (статусы для раскраски), 3403, 3876/3918 (проверка строки журнала), 7742 (импорт); `public/js/key-alias-core.js` 96;
  `db/learnerGraphRepo.js` 153/158/188/190/416 (счёт слов наставника и мини-приложения); `db/keyingService.js` 311/366
  (серверные упражнения и подпись ключа).
- **Сервер** не проверяет вид ключа при приёме журнала — строки `at1:` примутся; без обхода они попадут в счёт «слов»
  и в серверные упражнения.
- **Синхронизация** переносит только `review_log` (содержательные поля `meta` вырезаются). Заметки (`notes_v2`) не
  синхронизируются — только полная резервная копия.

## Решения (внесены в план)

1. Банк «Найди в книге»: prose, list_item, caption; 5–35 слов; без требования термина; без дословных повторов;
   без s00 (не переведён). Режим «этот раздел» в малых разделах честно говорит, сколько фрагментов есть.
2. «Что за символ»: фильтр по пометке проверки не нужен (её нет); берутся формулы с ≥ 2 символами с `ru`.
3. Термины в SRS: вход — `startSetTraining`; ветка `at1:` в сборке вопроса и в оценке; обход всех потребителей из
   списка выше.
4. Мои термины: заметка `notes_v2` на устройстве (переживает перезапуск, входит в полную копию) + «Выгрузить / Загрузить
   мои термины» файлом; на все устройства и для всех — через файл дополнений атласа. Синхронизация заметок — вне P5.
5. Плотность подстрочника у живого профиля владельца на копии не измерялась (база на устройстве владельца) — проверить
   глазами на проде после G1.
