### Входные файлы, которых здесь НЕТ и не будет

Скрипты рассчитывают на два внешних входа, намеренно не закоммиченных:

1. `shironet/kaggle.csv` — скачивается с
   `https://www.kaggle.com/api/v1/datasets/download/guybarash/hebrew-songs-lyrics?datasetVersionNumber=1`
   (4.1 MB, редирект на подписанный GCS-URL, авторизация не нужна).
   **Это охраняемые тексты песен — в git не класть, на прод не выкладывать.**
2. `library.json` — из владельческого бандла
   `~/Downloads/library-bundle-20260723-092730.zip`, запись `library/library.json`.
   **Тоже охраняемый контент (77 песен), в git не класть.**

`scripts/token-measure.js` читает `GEMINI_API_KEY` из `.env` проекта и бьёт в бесплатный
эндпоинт `countTokens` (генерации нет, платы нет). Ключ не печатается.

Скрипты запускать из каталога, где лежат оба входных файла (в этой сессии — scratchpad),
а не из этой папки: пути внутри относительные.
