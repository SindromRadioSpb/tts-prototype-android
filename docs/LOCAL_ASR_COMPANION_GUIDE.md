# Local ASR Companion: установка и работа

Local ASR расшифровывает ивритское аудио на вашем Windows-компьютере. Аудиофайл не отправляется в Gemini после ошибки Local ASR: переход к Gemini возможен только вручную и с отдельным подтверждением.

Эта инструкция относится к invite-only beta. Поддерживается **Windows 11 + совместимая NVIDIA/CUDA + Chrome**. Edge и Firefox в первой beta не поддерживаются.

EN: `/docs/LOCAL_ASR_COMPANION_GUIDE.en.md`. HE: `/docs/LOCAL_ASR_COMPANION_GUIDE.he.md`.


## Короткий путь

1. Установите полученный по приглашению **LinguistPro Local ASR Companion**.
2. Откройте меню Windows **Пуск → LinguistPro → LinguistPro Local ASR Companion**.
3. Дождитесь состояния **Companion: RUNNING**.
4. В блоке **Connect LinguistPro in Chrome** нажмите **Copy token for browser**.
5. Вернитесь в LinguistPro: **Настройки → Experimental Local ASR**.
6. Вставьте token в поле шага 2 и нажмите **Подключить**.
7. Выполните проверку устройства, установите модель и сделайте warmup.
8. Откройте импорт аудио и явно выберите **Local**. Gemini остаётся вариантом по умолчанию.


## Откуда взять pairing token

Token создаётся Companion автоматически. Искать файл, придумывать token или запускать командную строку не нужно.

1. Запустите Companion из меню **Пуск**.
2. В верхней части окна найдите отдельный блок **Connect LinguistPro in Chrome**.
3. Нажмите **Copy token for browser**.
4. Вернитесь в открытую вкладку LinguistPro, вставьте token и нажмите **Подключить**.

LinguistPro хранит вставленный token только в текущей браузерной сессии. После закрытия вкладки повторите эти четыре действия. Не отправляйте token другим людям и не добавляйте его в диагностический архив или скриншот.


## Установка Companion

Установщик этой внутренней beta не подписан. Используйте только файл, полученный через доверенное приглашение, и до запуска сравните SHA-256 с контрольной суммой, указанной владельцем для конкретной сборки.

Если Windows показывает SmartScreen:

1. Сначала убедитесь, что имя файла и SHA-256 совпадают с приглашением.
2. Только для совпавшей доверенной сборки выберите **Подробнее → Выполнить в любом случае**.
3. Не продолжайте, если контрольная сумма отсутствует или не совпадает.

Установка выполняется для текущей учётной записи Windows и не требует ручного Python, venv или Uvicorn.


## Проверка компьютера

В веб-экране Local ASR нажмите **Запустить preflight**. Проверяются:

- Windows 11;
- NVIDIA GPU, CUDA driver/runtime и доступная VRAM;
- свободное место на диске;
- локальный порт `127.0.0.1:8799`;
- FFmpeg/FFprobe из поставки Companion.

Если проверка показывает код ошибки, сначала устраните именно его. Local ASR не меняет модель, compute/decode, VAD или timestamp policy скрытым fallback.


## Установка модели

Модель загружается только после вашего подтверждения. Размер загрузки — около **1,62 GB**; для загрузки, проверки и безопасной активации требуется дополнительное свободное место.

Разрешена только модель:

`ivrit-ai/whisper-large-v3-turbo-ct2@72ad623a37947395efcc3933132353790e5a12f5`

Companion проверяет точную revision и SHA-256 каждого runtime-файла до активации. Повреждённая или неполная загрузка не активируется. Загрузку можно отменить и повторить.


## Расшифровка аудио

1. Убедитесь, что Companion запущен, браузер подключён, модель проверена и warmup завершён.
2. Нажмите **Открыть импорт аудио**.
3. Выберите файл.
4. В поле провайдера вручную выберите **Local**.
5. Запустите распознавание и дождитесь terminal status.
6. Проверьте полученный текст, затем сохраните карточку обычным способом.

После ошибки Local ASR Gemini автоматически не вызывается. Если вы хотите повторить задачу через Gemini, переключитесь на него вручную и отдельно подтвердите cloud upload.


## Если вернулись спустя время

1. Откройте Companion через меню **Пуск**.
2. Если служба остановлена, нажмите **Start**; если состояние зависло — **Restart**.
3. Снова нажмите **Copy token for browser** и подключите текущую вкладку LinguistPro.
4. Модель повторно загружать не нужно, если Companion показывает **Verified and ready**.
5. Для каждого нового импорта снова явно выбирайте **Local**.


## Типовые ошибки

| Сообщение | Что делать |
|---|---|
| Companion недоступен | Откройте Companion, нажмите Start или Restart и снова скопируйте token. |
| Pairing не прошёл | Скопируйте текущий token из Companion, полностью замените значение в поле и нажмите Подключить. |
| Порт 8799 занят | Закройте другую программу на порту 8799 или перезапустите Companion после освобождения порта. |
| Недостаточно места | Освободите место на локальном диске и повторите preflight. |
| Model integrity / checksum | Удалите неполную/установленную модель через управляемую кнопку и повторите ту же pinned revision. |
| OOM / недостаточно VRAM | Закройте приложения, использующие GPU, перезапустите Companion и повторите. Скрытого CPU fallback нет. |
| Warmup не прошёл | Проверьте preflight и модель, затем Restart и повторный warmup. |


## Управление данными и удаление

Кнопки Companion управляют только каталогами Local ASR текущего пользователя Windows:

- **Delete model** удаляет pinned-модель;
- **Delete jobs** удаляет локальные задания, исходные медиа и результаты;
- **Export redacted diagnostics** создаёт архив без аудио, текста расшифровки, исходного имени файла и pairing token;
- удаление Companion останавливает принадлежащую ему службу и удаляет его managed model/jobs/state.

Перед удалением нужной карточки текста сначала сохраните её в Библиотеке LinguistPro: удаление Local ASR jobs не заменяет экспорт пользовательской библиотеки.


## Граница приватности

Companion слушает только `127.0.0.1:8799`. Pairing token, проверка Origin/PNA/CORS и лимит тела запроса остаются обязательными. Медиа и результаты Local ASR хранятся в управляемых каталогах текущего пользователя Windows.

Local ASR не означает, что весь LinguistPro работает без сети: сама веб-страница и другие выбранные вами функции могут использовать сеть. Для этой ASR-задачи cloud upload не выполняется, пока вы сами не выберете Gemini и не подтвердите переход.
