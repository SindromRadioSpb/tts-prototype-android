# AGENTS.md — точка входа для Codex и других агентов

Этот файл — Codex-специфичная надстройка, НЕ дубликат `CLAUDE.md`. Раньше здесь
лежала механическая копия CLAUDE.md с заменой `claude`→`Codex` — она разошлась
бы с оригиналом при первом же обновлении конвенций и содержала битые пути
(`.Codex/PROD_OPS_PRIVATE.md` — такого файла нет, реальный путь `.claude/PROD_OPS_PRIVATE.md`).
Вместо дублирования (dual-write двух копий одних конвенций — то, что сам проект
запрещает себе на уровне данных, см. R12 ниже) этот файл только **указывает**,
что и в каком порядке прочитать.

## Порядок чтения перед началом работы

1. **`CLAUDE.md`** (этот же каталог) — единственный источник истины по стеку,
   конвенциям, ролям-линзам R1–R17, деплою, CSS-ловушкам. Обновляется чаще, чем
   этот файл — читай его целиком, не полагайся на память о нём из прошлых сессий.
2. **`docs/PROJECT_ROLES.md`** — полные определения ролей R1–R17, упомянутых в
   CLAUDE.md. Применяй их автоматически ко всем содержательным
   продукт/код-решениям (см. правило в CLAUDE.md §«Роли проекта»).
3. **`docs/planning/*.md`** — канон-доки по конкретным программам/решениям
   (обычно `<ТЕМА>_RECON_<дата>.md` или `<ТЕМА>_PLAN_<дата>.md`). Ищи по теме
   своей задачи — они точнее и свежее любого общего пересказа. Живой код
   первичен по отношению к докам, если они разошлись (доки могут отставать).
4. **`docs/planning/AGENT_MEMORY_EXPORT_2026_07_15.md`** — дистиллированная
   долговременная память по проекту (правила процесса с обоснованием + снимок
   статуса программ на дату экспорта). Это единственная часть памяти агента
   Claude Code, которая **закоммичена в репозиторий** и переживает смену машины
   или облачное исполнение без доступа к диску. Датирована — при явном
   конфликте со свежим кодом/докой верь свежему источнику.
5. **`.remember/recent.md`, `.remember/archive.md`, `.remember/today-*.md`**
   (этот каталог репозитория, но не в git — есть только на этой машине) —
   сырой ежедневный лог разработки за последние недели. Полезно для
   хронологии «что было вчера/на прошлой неделе», но не структурировано.
6. **Живая долговременная память Claude Code по этому проекту** — она хранится
   ВНЕ репозитория, в профиле пользователя на этой машине:
   `C:\Users\lletp\.claude\projects\E--projects-tts-prototype-android\memory\MEMORY.md`
   Это индекс; каждая строка ссылается на отдельный `.md` в той же папке
   (`feedback_*.md` — подтверждённые/отвергнутые подходы с обоснованием,
   `project_*.md` — статус инициатив, `reference_*.md` — внешние координаты).
   Формат: YAML-frontmatter `name/description/metadata.type` + текст с
   перекрёстными ссылками `[[name]]` на другие файлы той же папки.
   **Если пути нет (песочница/облачный Codex без доступа к диску пользователя)
   — прямо скажи об этом и работай по пункту 4 (`AGENT_MEMORY_EXPORT_2026_07_15.md`),
   не выдумывай контекст.**

## Что не читать без необходимости

`.claude/PROD_OPS_PRIVATE.md` — боевые креды/IP/имена прод-ресурсов. Открывай
**только** если задача прямо требует прод-операций, и никогда не пересылай его
содержимое туда, откуда оно может утечь (внешний API, публичный артефакт,
облачный лог провайдера).

## После восстановления контекста

Прежде чем переходить к задаче, коротко перескажи (5–10 строк): что уже
сделано в проекте, что в работе, какие открытые решения ждут владельца. Это
даёт владельцу шанс поймать пробел до того, как ты начнёшь действовать.
